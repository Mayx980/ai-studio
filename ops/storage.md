# 公司 HTTP 云存储运行

当前源码与Compose支持以下配置；尚未连接目标OSS验证。复用已存在的公司 storage HTTP 服务，不再部署另一套 OSS 或 Go 网关。外部协议、用户授权、删除缺口和兼容规则唯一维护在 [mediaStorage](../contracts/data/mediaStorage.md)；MySQL/密钥运行见 [database](database.md)。

## 配置来源

用户明确选择服务地址与 bucket 后填。支持一个可选 JSON 配置文件，并允许 Docker Compose 环境变量覆盖；环境变量优先于配置文件。显式空环境变量视为缺失并报错，不静默沿用旧值。以下变量须部署当前版本镜像后配置，旧镜像不会自动获得这些能力：

| 环境变量 | 配置文件字段 | 含义 |
| --- | --- | --- |
| `AFXEN_STORAGE_CONFIG` | 无 | 可选配置文件绝对路径；用统一文件入口读取，文件须为 JSON 对象 |
| `AFXEN_STORAGE_BASE_URL` | `baseUrl` | HTTP/HTTPS 服务根地址，可含明确网关前缀；不含用户密码、query 或 fragment |
| `AFXEN_STORAGE_BUCKET` | `bucket` | 实际桶名，单路径段，不含分隔符或控制字符 |
| `AFXEN_STORAGE_PREFIX` | `prefix` | 实例隔离前缀；缺省 `afxen`，不含 `..`、空段或控制字符 |

地址和 bucket 不提供猜测的默认值；地址只由部署人员配置，不能由普通浏览器请求修改。提供配置文件路径却无法读取/解析时明确失败，不把该错误忽略后继续；环境变量不需要填写虚构 Token，HTTP边界不发送任何模型凭据。单次传输超时120秒、单媒体100 MiB，不自动重试未知上传。媒体生成每用户最多20个在途、实例最多保留1000个任务状态，完成状态保留一小时；进程重启不恢复任务。

配置未齐时云上传/读取能力明确不可用，保留输入和旧本地资料；不得声称上传成功、自动创建默认bucket、偷偷写回本地或触发供应商生成后才发现无法存储。部署启用云媒体前健康/能力检查核对配置，健康检测本身不发起上传或删除请求；外部连通性与真实保存需人工另行验证。

## 网络与媒体访问

后端需能访问配置的 HTTP 服务；浏览器访问 AFXEN 自己的媒体入口。当前 OSS 无鉴权，部署侧须限制其可达范围；本页不更改现有 APISIX 路由，也不把它发布为对所有用户开放的文件接口。用户能直接访问 OSS 时，应用内用户隔离不能保护该旁路，目标机必须如实核实此条件。

原生本机文件模式和旧数据卷保留；新云对象与SQL媒体记录共同保存，画布/对话/模板JSON仍在原卷。Compose复用实际应用数据卷并另加mysqlData，不给媒体目录做无关搬迁，不新增Go容器。对象读取不依赖过期签名URL，URL不作为持久索引。

## 备份、删除与恢复

云媒体启用后的完整恢复材料为：同一时点数据库、仍在本地的业务文件卷、模型凭据根密钥，以及所用bucket/prefix中的云对象及其保留策略。数据库备份不能代替媒体备份；保存bucket名称也不等于对象已备份。具体云端备份能力由公司storage运维确认，本轮不修改其云厂商配置。

当前HTTP没有物理删除接口。note 131807 已确认仅逻辑解除本用户关联、保留实际对象；不执行伪造DELETE，不把SQL回滚或移除卡片写成对象已清理。上传成功但SQL失败的未发布对象需保留待处理位置，不能静默堆积或无依据删除已有对象。后续清理须具备真实删除协议、引用核对、对象清单和目标授权。

旧媒体迁移、真实OSS联调、目标机发布与恢复不因保存本方案而获授权；配置由部署人员后填，验证结果与构建结果分别交接。

## 模型接口和结果地址

多用户模式通过统一模型传输限制出站地址，拒绝userinfo、重定向、编码路径逃逸及与本实例OSS相同的origin。默认包含本仓已有供应商的公共HTTPS API主机、阿里云业务空间和已登记媒体CDN；精确列表见 `services/server/src/utils/ai/network.ts`。未登记域名明确403，保留输入，不回退其它供应商。

内部LLM、额外供应商及结果CDN由部署管理员通过 `AFXEN_MODEL_ALLOWED_BASES` 配置JSON字符串数组，例如：

```sh
export AFXEN_MODEL_ALLOWED_BASES='["https://models.example.com/v1","https://media.example.com/results"]'
```

每项为受信任origin及可选路径前缀，不能带凭据、query、fragment或编码路径。管理员确认其范围不提供任意代理、存储或其它用户文件读取；不要登记整个混合业务网关来代替精确模型前缀。直接内网HTTP仅限明确受信任服务。本实例OSS的origin即使列入也拒绝；OSS本身仍须网络隔离，不能依赖此规则防止用户从应用外绕过。默认模型API允许不代表已有Key、模型权限或已验证生成。

## 媒体处理和后台结果

FFmpeg从统一媒体入口临时物化输入，输出完成后先保存OSS及SQL映射，再返回成功；正常清理临时文件。发布失败保留结果目录并明确报错，不能重提模型当作恢复。多用户只开放当前节点所需编码参数、裁剪/变速/拼接音频滤镜和受控文件路径，拒绝任意raw参数、文件清单和间接读取滤镜；可信原生local模式保持原工厂行为。

应用内切画布沿用现有后台节点保存。HTTP断开不取消已接受媒体任务；结果绑定原账号、项目和节点，原节点已删除则不重建。显式停止仍取消等待，不能承诺供应商撤费或取消其已提交任务。任务记录只保存在进程内，关闭浏览器后已接受媒体结果可以由Server保存，但不承诺服务重启后的任务恢复或离线续跑专业流程。
