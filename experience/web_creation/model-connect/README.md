# 公司模型独立联调

本目录是本次用户明确委托的本地模型联调工具，不是生产服务，也不进入 UIUX 场景或生产装配。使用现有 Web 工程的 `connected` 构建期装配，由 Vite 的 loopback 服务提供固定路由中转，不建设数据库、SSO、部署或 MR。

`corepack pnpm models` 在 `127.0.0.1:5174` 启动本地联调。页面的“真实模型设置”有四个密码输入框，分别对应文本、图片、视频和音频。Key 只保留在当前页面内存；刷新、退出登录和“清除全部 Key”会移除。不记入项目快照、localStorage、sessionStorage、文件或日志。每次调用将 Key 和输入发给当前本地中转，再由固定适配器访问其提供的供应商域名。生成需要用户确认；图生视频在生成前展示去重后的实际图片清单，不再重复打开独立确认图片步骤。

## 输入文件与接入方式

四个 `providers/*.ts` 为用户本次上传文件的原样副本：

| 原文件 | 本地副本 | 行为 |
|---|---|---|
| aliyun_bailian_qwen_text.ts | providers/text.ts | 描述公司 OpenAI 兼容文本接口；中转补充通用 chat/completions 调用 |
| aliyunBailianQwenImage30Pro (2).ts | providers/image.ts | 调用原 generateImage，支持文生图与至多3张图片参考 |
| aliyun_wan3_video_v3.ts | providers/video.ts | 调用原 generateVideo，单图输入由原适配器申请临时上传、提交与轮询任务 |
| seed-audio.ts | providers/audio.ts | 调用原 generateAudio，返回音频 Base64 |

公司业务空间域名沿用上传文件，不提供任意地址代理。网关限制 loopback Host、同源调用、固定能力和请求体大小；不读取本机凭证。仅接受公司模型域名及适配器所需的阿里云临时存储域名，不跟随 HTTP 重定向。

## 模型参数和输入

图片使用 `qwen-image-3.0-pro`，PNG、1K/2K，生成数量1–4；本地粘贴图片作为 Base64 传入。图片画质和背景要求拼入提示词，不传适配器不支持的 quality 字段。
视频使用适配器中的 `wan3Video`，文生模式不发送图片；图生模式固定生成确认清单中实际图片的版本；1张使用单图，2–10张使用多图参考。调用、上传与轮询沿用适配器实现；一次多结果按已确认数量逐次提交。音频的音色、期望时长作为文字要求，格式和音量按适配器字段映射，不保证其硬性时长或音色ID控制。
分镜及优化调用文本模型。分镜 JSON 经字段校验后才替换旧表；失败保留旧表、输入与错误。优化仅更新预览，应用才替换节点提示词。生成结果保留具体输出，参考面板展示图片或视频实际首帧。

## 验证边界

`corepack pnpm test:models` 用注入的替身传输验证四个原始适配器的请求、视频任务轮询和错误脱敏，不调用供应商。`connected-current-check.mjs`和`connected-guide-check.mjs`用替身响应验证节点调用、完整助手阶段、图生输入、部分失败和 Key 不持久化。只有填入有效 Key 并实际调用后，才能核验公司账号权限、额度、地域、供应商生成质量和结果URL可达性。
关闭页面或停止本地进程不保证已提交的远端视频任务被取消；请求失败或等待结束时先检查供应商任务状态，避免重复提交。临时结果应及时保留，当前项目数据没有服务端持久化。

视频界面统一显示“图生视频”，生成前合并分镜及节点引用并去重，1张采用单图、2–10张采用多图参考输入。输入@可选择已引用图片，生成确认后固定快照。分阶段灵感助手通过文本接口生成方向解析、推荐方案、结构化剧情、分镜和具名提示词，通过图片/视频接口生成预览。用户确认后才保存节点并关联分镜行；失败不伪造成功，部分失败允许仅重试失败项，原成功结果保留。修改媒体保留此前版本，返回参数新建批次时保留原预览。

## 当前限制

没有有效Key时不发送供应商请求。只有用户填入有效Key并实际生成后，才能确认权限、额度、供应商结果和媒体地址可达性。文本输出经过结构校验，不符合剧情模块、分镜JSON或提示词关联要求时保留原稿并显示错误，不自动重试。

本地Word/PDF正文解析仍为模拟；文本方向解析不包含图片视觉理解。当前助手视频请求支持文字与图片，适配器未提供外部音频参考字段；存在音频/视频文件引用时明确提示移除，不静默丢弃。音效要求可写入文字，音频节点仍可单独调用真实音频接口。
