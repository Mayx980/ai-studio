# AI Studio 创作空间

基于《AI生成视频平台PRD V3.0》的深色 Web 创作原型，Vue 3 + Vite。需要 Node 24、pnpm。

## UIUX 场景预览

在仓库根运行：
```bash
python3 experience/preview/start.py --entity web_creation --runtime local --port 5173
```
打开 `http://127.0.0.1:5173`，状态导航在 `/_uiux`；按 Ctrl-C 或加 `--down` 停止。此入口只使用场景数据。

## 真实模型联调入口

用户已恢复真实模型联调。在本目录执行 `corepack pnpm models`，打开 `http://127.0.0.1:5174`。此入口使用 connected 装配并启用本地中转，页面顶部有真实调用提示。通过“设置 API Key”填入文本、图片、视频或音频 Key，点击生成并确认后才调用供应商。Key只保留在页面内存，刷新、退出登录或“清除全部 Key”会清除，不写项目、浏览器存储、仓库或日志。不要把 Key 写进源码。

## 交互与边界

支持项目卡片、抓手/移动、捏合缩放、图片粘贴、节点和分镜行连线、右键断开、实时参考封面、个人资产、优化预览应用与参数摘要。支持 @ 分类引用封面、分镜图片按行分配、反向拖线；视频统一显示图生视频，生成前汇总图片参考清单：1张单图输入，2–10张多图参考；`@`可指定已引用图片。节点右上角和右键菜单均可删除，统一二次确认。重新生成分镜采用当前输入，确认成功后替换旧表；失败保留原表和输入。
UIUX支持本地示例PNG/WebM/WAV下载，单个素材直接保存，选定镜头的多素材打包ZIP；示例文件不代表真实模型输出。
引用支持本地MD/Word/PDF和图片（Word/PDF解析模拟）；分镜可导出本地XLSX。
项目数据保留在本次浏览器会话中，刷新重置。UIUX场景中的助手仍为规则演示，真实入口按供应商返回内容推进；PDF导出、正式生成素材下载和服务端持久化未接入。UIUX场景入口继续隔离模拟数据，只有显式启动`models`才允许真实接口调用。真实入口同时接入灵感助手的方向解析、方案、剧情、分镜、提示词提取及图片/视频预览，确认后才保存节点。调用失败保留草稿，媒体批次保留成功结果，仅重试失败项；不会用模拟内容代替真实响应。有效 Key、账号权限、额度和供应商结果仍需实测。

## 验证

在本目录执行 `corepack pnpm test`、`corepack pnpm test:models`、`corepack pnpm build`、`corepack pnpm build:scenario`、`corepack pnpm build:connected`。三个构建分别输出并执行隔离检查。浏览器回归脚本需要启动对应入口和 Chromium，可用 `CHROMIUM_PATH` 指定浏览器。`connected-current-check.mjs`和`connected-guide-check.mjs`使用替身供应商响应验证节点及完整助手流程，不能证明供应商实测成功。

### Mentor 汇报演示

通过项目 Preview 启动 Scenario 后，访问 `http://127.0.0.1:5173/?demo=1`。
首页可选择「画布工作流」或「灵感助手」，共用香水广告案例。画布预置剧情、三镜头分镜、三张图片、三段本地示意视频和旁白节点；底部导航可按剧情→分镜→图片→视频定位。助手会带入完整需求，方案、剧情、分镜、媒体仍由演示者逐步确认。提示条可收起，随时切换演示；重新进入会创建新项目，刷新重置全部内存数据。无需 Key，不发送模型请求；图片/视频/声音仅用于展示交互，不作为生成效果样片。

### 灵活模式补充版 Demo

Scenario 默认首页现为对话创作入口：`http://127.0.0.1:5173/`。可演示案例预览与应用、草稿冲突保护、首尾帧、五类产出、媒体引用／选帧、区域修改新版本、剪辑参数、保存至画布／资产和三种外观。切换灵感模式可使用原有阶段确认流程。旧汇报导航仍可通过 `/?demo=1` 访问。

本轮仅为 UIUX 本地模拟：视频使用已有短示例，图片为 SVG，音频为提示音。视频合成、真实局部重绘和模型质量尚未实现，不作为实际可用性验收；页面有相应标识。主题偏好在浏览器保存，作品与任务仅在本次内存中保存，刷新重置；无需 API Key。浏览器检查命令：`CHROMIUM_PATH=<chromium路径> node studio-check.mjs`。
