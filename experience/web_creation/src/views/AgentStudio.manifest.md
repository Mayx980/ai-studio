# Agent 对话创作

入口：Scenario 默认首页及项目 Agent 会话；共享页面只消费 creation port 的 studio 能力。真实模型 composition 未装配本轮灵活模式，不发送供应商请求。

| 产品规则 | 可观察行为 | 检查 |
|---|---|---|
| 默认灵活／切换灵感 | 输入框右下角模式和说明，历史不因切换删除 | studio-check.mjs |
| 创意单卡预览与应用 | 悬浮播放、放大气泡、使用填充文字与用途图片，不生成 | studio-check.mjs |
| 保护已有草稿 | 保留／采用／取消；替换图片先选择，取消不删除原图 | studio.test.js |
| 首尾帧 | 双框上传／粘贴／资产选择、交换，缺帧禁止发送 | studio-check.mjs、studio.test.js |
| 共享参数 | MediaParameters 与节点字段一致；关闭取消配置草稿 | 构建、浏览器检查 |
| 图片／视频／音频／剧情／分镜 | 明确发送才模拟规划，支持暂停和停止 | studio-check.mjs |
| 引用与局部修改 | 历史引用、选帧、区域标记，新版本不覆盖旧版本 | studio-check.mjs |
| 剪辑与音画 | 选镜头、排序、时长、音量、色彩；渲染使用本地示意 | 浏览器手动检查 |
| 保存边界 | 主动添加画布；个人资产仅媒体 | studio-check.mjs |
| 会话恢复与重试 | 同次运行内项目重开恢复；失败重试使用固定请求参数与引用 | studio.test.js |
| 外观 | 账号附近设置、三种主题、本机偏好保留 | studio-check.mjs |

状态：正常创作、等待、暂停、停止、失败、重试、缺少首尾帧、草稿冲突、无引用素材、只读提交保护均有可观察反馈。案例列表 loading/error/empty 随 Scenario 展示，重试不清空输入。

边界：图片是本地 SVG，视频为两秒示意 WebM，音频为提示音。字幕／配乐合成、真实区域重绘、跨帧追踪、供应商生成和服务端持久化均不在本轮实现；原型不得作为上述能力验收证据。案例及素材仅验证交互，不代表正式案例供给或内容质量。
