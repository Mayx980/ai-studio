## 最新 PRD 的 Agent Demo

Scenario 首页和项目对话共用 AgentStudio：灵活模式默认开启，输入框右下角双模式附悬浮／聚焦说明。卡片单预览区悬浮播放、点击放大，文字区浮现使用入口；使用只带入提示词、人物／商品示例图，允许原样发送或编辑。已有草稿先选择保留／采用／取消；素材替换选定前不删除原素材。首尾帧双框提供上传、粘贴、资产选择及交换，缺帧阻止发送。参数复用 MediaParameters，关闭不提交配置草稿。

灵活模式可模拟图片、视频、三种音频、剧情和分镜，展示可暂停／停止的四步规划；失败保留请求快照并主动重试。结果可引用、选帧、下载、添加画布和保存媒体资产。剧情小气泡编辑，分镜编辑全屏；图片区域或视频同对象圈选生成新版本。剪辑面板可调整镜头顺序、时长、音量及色彩；预览音量和色彩支持本地变化，重新生成／合成仍为示意。历史会话保存在当前进程内存，项目重开可恢复，不代表服务器持久化。

外观设置位于账号附近，浅色／深色／跟随系统，偏好保存在本机浏览器，未保存作品内容或密钥。所有生成与重绘均为本地替身：视频为已有短示例、图片为本地 SVG 示意、三类音频共用短提示音；不得将其视为真实成片质量、配音／音乐／环境音生成、视频对象追踪或实际剪辑渲染的证据。默认不会发送供应商请求；真实联调入口未扩展灵活模式。
