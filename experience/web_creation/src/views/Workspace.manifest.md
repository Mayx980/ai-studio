本轮交互约束：移动模式可选中和拖动节点；抓手模式拖动画布。右键菜单区分节点与画布，删除仍需额外确认。表格支持拖动调整宽高，脚本输入位于表格下方。分镜行连接后自动作为节点来源；所有参考在输入框左上方展示，悬浮或键盘聚焦时出现取消按钮，移除只解除引用，保留手写输入和结果。输入工具按钮提供功能名提示。

提示词优化：上方可编辑预览，下方填写要求。生成更新预览；“生成并应用”只替换节点输入，不自动生成媒体。取消不应用。

真实模型期望覆盖分镜、优化、图片、视频；需要公司服务接入文件核对。场景版保持无网络，真实调用不混入该装配。

本轮补充：新节点在当前视野附近避开已有节点放置，可拖动。分镜重新生成需确认，采用最新输入并形成新版本。节点连接自动引用上游内容，禁止自连和循环；取消引用解除对应连线。当前画布引用面板实时读取已就绪的文字及媒体内容，并显示版本。每次媒体生成固定当次输入快照。

场景助手可按需求创建并连接节点、按指令整理布局；它是规则驱动的交互演示，不是真实 Agent 推理。媒体调用仍经用户确认。触控板捏合缩放以指针为中心，普通双指滑动仍平移；文字右键菜单在剪贴板未授权时明确提示快捷键回退。

图片参数摘要仅保留比例、画质、清晰度、背景、生成数量；用户已确认删除误填的“脚本”。视频和音频摘要使用各自适用字段，点击展开统一参数面板，取消不写入。参数候选是设计示意，正式支持范围待模型接入文件核对。

本轮更新：画布原生粘贴图片创建实际图片节点，图片可连线、被引用和保存为资产；新建/复制节点统一避让已存在节点，优先采用鼠标空白位置。四类普通节点取消右上角删除入口，右键删除仍需确认。节点连线支持右键取消，行连线也同步解除该行引用。

重新生成使用明确的“确定并重新生成”动作，固定最新输入，成功后才替换。真实模式失败保留原表及输入。图片引用展示实际封面；视频引用使用视频元素解码首帧，失败显示不可用状态。

用户已单独授权真实模型联调：独立 connected 装配，浏览器临时输入 Key，通过本地中转复用四个 .ts 适配器；UIUX 不发出真实模型调用。Key 不进入项目快照、浏览器存储或仓库。真实供应商调用及费用由用户在联调界面确认，供应商效果待有效 Key 验证。

## 确认与缩放规则

节点四边与四角可调整大小，最小尺寸保证操作区可用，输入和媒体随容器调整。抓手及只读状态不允许缩放。引用面板和 @ 面板支持跨分类多选，确认前不增加引用，取消不应用。

分镜编辑采用草稿，文字、排序、新增和删除点击“确定”后同步到画布，保留行 identity 与下游生成结果；修改已有成功节点的引用正文后提示结果过期。保存后编辑页保留，仍仅由右上角关闭；未保存关闭需确认放弃。默认生成文本为简体中文，明确指定语言时尊重用户选择。
