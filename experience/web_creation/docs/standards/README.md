## 归属原则

- 通用页面布局、Drawer/Modal、loading、重复提交与旧响应保护由物化后的项目规范约束。
- admin 只记录本工程仍然特殊的目录、Port/Provider 装配、基础页面和组件边界。
- 具体业务方案不放在本目录，由项目自己的知识源维护。
