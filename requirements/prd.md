# PRD

## 1. 产品概览

### 1.1 产品名称与目标

AFXEN 面向内部运营人员与短视频创作新手，支持提示词创作、节点编排、素材管理和创作过程复用。使用者可以快速生成单份内容，也可以在画布中精细调整文字、分镜、图片、视频和音频之间的依赖。

### 1.2 端侧矩阵

产品入口为浏览器中的创作工作台，使用者连接同一个共享实例，完成 §3 的创作与内容管理操作。无需在每个浏览器分别建立一套项目资料。

### 1.3 北极星指标

可观察的成功结果是：使用者完成输入、引用、明确提交生成、采用结果和保存；重新打开项目后仍能继续创作。是否成功生成以真实供应商结果和保存结果分别判断，不以示例展示替代。没有另行约定成功率、耗时或费用目标。

### 1.4 产品边界

范围包括共享实例内的项目与对话、简单创作、专业创作、节点和分镜编辑、实例素材与生成历史、模板与创作优选、模型配置、教学及快捷键。保存的业务内容可从连接同实例的另一个浏览器重新打开。

不提供账号注册或登录、公司统一身份、角色权限、个人内容隔离、实时多人协同、完整团队后台、成片拼接或合成导出。关闭浏览器或服务重启后的生成任务持续执行与恢复不作承诺。浏览器原型资料不自动搬入共享实例，也不自动删除。已有项目与素材保留其原有内容和关联。

## 2. 通用业务规则

### 2.1 术语

| 术语 | 定义 |
| --- | --- |
| 共享实例 | 提供同一份已保存业务资料的创作环境；访问者不按个人账号区分 |
| 项目 | 组织画布、对话和创作素材的业务容器 |
| 画布 | 通过节点及连线表达内容与引用关系的创作空间 |
| 简单模式 | 通过提示词和可选参考快速生成、预览并采用内容 |
| 专业模式 | 使用画布及创作助手逐步确定方案、编辑内容并组合素材 |
| 引用 | 在当前创作中使用已有内容；建立引用本身不发起生成 |
| 个人资产 | 沿用的产品名称；本范围内指共享实例保存的素材，不代表按用户隔离 |
| 创作优选 | 可以查看实际创作过程并复制为独立项目的作品展示 |
| 示例 | 已有素材或教学资料，明确用于展示，不代表本次模型调用产出 |

### 2.2 主要业务对象

| 业务对象 | 定义 | 是否分多类 |
| --- | --- | --- |
| 项目 | 已保存的创作资料及其名称、封面和画布 | 单一 |
| 节点 | 承载输入、引用、生成配置和结果的创作单元 | 文字、脚本、图片、视频、音频 |
| 对话 | 用户输入、助手回复、创作阶段及对应产出的连续记录 | 简单创作、专业创作、素材自定义子对话 |
| 素材 | 可预览、采用或复用的媒体 | 图片、视频、音频 |
| 分镜 | 可独立编辑及引用的镜头内容 | 镜头构成有顺序的分镜表 |
| 模板 | 可应用提示词或复制创作过程的内容快照 | 视频模板、项目流程模板 |
| 模型配置 | 当前实例可用的模型、适用参数及服务凭据 | 文字、图片、视频、音频能力 |

### 2.3 对接通道

| 通道 | 方向 | 接收方 | 用途 |
| --- | --- | --- | --- |
| 创作工作台 | 双向 | 共享实例 | 创建、编辑、保存和恢复业务资料 |
| 模型服务 | 双向 | 使用者配置并启用的供应商 | 按明确提交的要求生成内容并返回结果 |
| 文件导入与下载 | 双向 | 使用者 | 引入支持的文档和素材，下载已保存内容 |

## 3. 创作工作台能力

### 3.1 共享保存与恢复

**BR-shared-content**：项目、画布、媒体、对话、生成历史、素材标签和模板在共享实例中保存。另一浏览器连接同实例，可以读取已经保存的同一份资料。页面内选中项、展开状态和首次提示偏好不作为业务资料的唯一来源。

保存成功才表示共享资料已更新。保存失败保留当前输入和已成功部分，明确提示原因；取消不写入。多个页面基于不同内容保存时，旧内容不能静默覆盖较新的保存结果，应提示重新读取或另存。没有实时协作或自动合并他人编辑的承诺。

验收场景 **SC-reopen-project**：保存包含对话与媒体的项目，在另一浏览器打开并在服务重新启动后再次读取，已保存资料保持一致。验收场景 **SC-conflicting-save**：两个页面先后保存不同编辑，旧页面不得无提示覆盖新内容。

### 3.2 首页与项目管理

**BR-project-lifecycle**：首页提供新建画布及文字、脚本、图片、视频、音频的快捷创作入口。项目默认使用未命名名称，之后可以重命名；已有课程的首次进入规则见 §3.10。最近项目展示实际项目名称、最近打开时间和可用媒体封面。

项目支持搜索、时间排序、网格或列表查看、打开、重命名、修改封面、创建副本、文件夹分类及移除列表项。文件夹分类不等于移动或删除原项目资料。移除项目列表项保留项目文件，复制项目的资料独立于原项目。

创建成功后才显示可打开项目；失败保留输入，不登记残缺项目。重复点击、重复应用或失败重试不能重复登记同一份已经成功的结果。从子页面返回时回到来源板块。

验收场景 **SC-project-management**：创建项目后修改名称和封面，再复制并编辑副本，原项目保持不变；移除列表项不会删除已有项目文件。

### 3.3 简单创作与结果应用

**BR-mode-roundtrip**：默认进入简单模式，切换入口位于输入框外部上方。简单模式的解释为“输入提示词，也可以添加角色或首尾帧参考，快速生成图片、视频等内容。”；专业模式的解释为“在画布中连接节点、组合素材和调整参数，精细控制创作流程。”。解释支持鼠标悬浮或键盘聚焦查看。

两种模式共享同一项目、画布和对话中的输入、参考、参数、节点、连线及结果。切到专业模式可以查看并继续编辑简单创作对应内容，不重复创建项目或发起生成；切回简单模式仍保留专业编辑。简单视图不能表达的复杂编排继续保留，不能因切换、编辑或保存简单视图而被静默覆盖。重新打开后仍遵循同一份已保存内容。

**BR-explicit-generation**：使用者选择产物、填写提示词并可添加参考；只有明确发送或点击生成才请求模型。上传、连接、切换参考、调整参数、应用模板、预览和下载均不自动生成。含糊输入默认生成图片，明确的文字、剧情、分镜、音频或视频目标按对应能力处理。

Enter 发送，Shift+Enter 换行；中文输入法选词不触发发送。发送中的操作提供等待和主动停止，停止等待不能被误报为供应商已经撤销任务。失败保留输入、参考和已有成功结果，不无条件重试。

**BR-result-application**：生成结果可预览、引用并应用到画布。应用使用已获得的结果，不再次调用模型；保存失败不得报告应用成功。该轮用户要求、实际提示词、参考、模型和适用参数与结果保持对应；多个结果复用该轮输入，重复应用定位已有内容，不重复建图。

验收场景 **SC-simple-creation**：提交一次创作、停止等待或遇到失败后仍可编辑输入；成功结果重复应用不增加重复节点，也不发起第二次生成。

验收场景 **SC-mode-roundtrip**：简单创作后切到专业模式，输入、参考、参数和结果仍属于同一项目；在专业画布增加节点与连线，再切回简单模式编辑、保存并重新打开，复杂编排与已保存结果仍保留，整个往返不额外生成或创建项目。

### 3.4 引用与素材自定义

**BR-reference-integrity**：引用可来自本地、实例素材、当前画布或允许的其他项目。引用保持真实媒体或已保存文字的对应关系，不能以名称、缩略图或示意文件冒充实际内容。来自其他项目的资料复制为当前项目可用内容，不形成依赖原项目继续存在的隐性引用。

简单创作区分参考图和首尾帧，切换后保留原组资料，发送时只使用当前选择组。参考图按角色、道具、背景和其他等用途保留编号；删除某项不改变其余项已保存的编号。首帧、尾帧、中间帧保留自己的用途。当前产物不展示的入口不因此丢弃已有附件；实际可提交组合始终按模型能力校验，不支持时说明原因并保留资料，不把尾帧静默改作普通参考。

自定义素材保留原创作内容，在独立素材对话中生成或编辑，明确应用后回填到发起入口及对应用途；拒绝应用可继续素材对话。应用已有结果不要求再次生成。

验收场景 **SC-reference-application**：从不同来源添加参考，切换用途后再次打开，编号与内容正确；应用子对话结果只替换发起位置，不覆盖原项目的其他输入。

### 3.5 专业创作与阶段确认

**BR-professional-confirmation**：助手依据当前语境和已有内容询问尚未明确的关键事项，最多五题，每题含推荐项在内最多五个选项；明确给出的内容不重复询问。支持从想法、已有剧情或已有分镜开始，并可在所需产物完成后停止。

方案可选择、剧情可编辑后应用，分镜与对应画布脚本保持同一份内容。进入下一阶段使用当前已保存正文，不使用旧回复中的副本覆盖新编辑。参考图和视频的生成各自取得明确选择；媒体候选先保留在对话中，采用后创建对应节点并保存文件。部分失败保留成功候选、选择和已有节点，重试不重复创建成功部分。

历史记录保留方案、剧情、分镜及媒体产出；重新打开不自动调用模型。只有新聊天建立新会话，路由往返继续当前会话。素材自定义子对话仍属于原项目。

验收场景 **SC-professional-creation**：修改剧情和分镜后进入媒体阶段，模型使用修改后的内容；重新打开会话仍能查看此前产出，不重复生成或丢失阶段选择。

### 3.6 画布与分镜

**BR-canvas-dependencies**：画布支持节点创建、引用、编辑、连线、分组、撤销、重做、整理、适应视图与层级定位。连线表达内容依赖，不执行下游；禁止自连接、重复连接和循环依赖，不兼容连接说明原因。断开引用不删除已有原素材或下游已保存结果。

**BR-script-input**：脚本生成允许只提供有效参考而不填写提示词；文字与有效参考至少有一项。两者都有时按当前输入和参考生成；两者都空时不发起生成，提示补充内容并保留当前编辑。脚本生成入口沿用同一输入规则，不因从画布或创作助手进入而改变。

**BR-storyboard-identity**：脚本以可编辑的完整分镜表呈现，包含镜头号、时长、景别、运镜、画面、台词或音效、角色反应、环境及图像、视频提示等已确认内容。末列提示词按场景、角色和道具分别编辑，生成提示词使用中文，既有角色形象描述不丢失。

镜头行在排序、改号和编辑后保持原有引用身份；复制行是新的镜头。图片可以引用到单行，或选择应用到多行；每行可以连接一个或多个兼容下游，下游取得该行完整内容与关联图片。删除行先提示连接影响，不删除下游已有素材；重新生成整表需要明确覆盖选择并保留原内容保护。

导入支持已有的 TXT、Markdown、CSV、单工作表 XLSX 和 DOCX 范围，单文件最多 8 MB，解压内容最多 32 MB，最多 1000 行镜头。解析预览和列映射确认后才应用；取消或失败不改原表。公式、多工作表、PDF/OCR 和图像角色识别不被冒充支持。Excel 导出使用同一份已保存分镜与关联描述，不导出画布连接或凭据，也不触发生成。

验收场景 **SC-storyboard-editing**：导入、排序、改号后，下游仍引用原镜头；取消导入不改表，导出内容与保存的表格一致。

验收场景 **SC-script-input**：提示词为空但有有效参考时，明确提交可以按参考生成；仅有文字或两者都有时使用当前内容；文字与有效参考都空时提交不调用模型，页面提示补充内容且原编辑不丢失。画布与创作助手中的脚本生成均按此核对。

### 3.7 模型配置与生成结果

**BR-model-credentials**：模型由共享实例统一配置和调用。服务凭据在实例中保存，不随通用配置读取回传，不进入项目、对话、模板、历史或可见错误；更新、保留原值和显式清除的操作含义可区分。保存无关设置不能清空既有凭据。

只列出并使用已配置、已启用且支持对应能力的模型，不回退到其他供应商。文字、图片、视频、音频均按实际接入协议与参考能力执行；填入模型名称不代表已验证供应商权限或真实生成效果。图片数量、比例与尺寸，视频时长、分辨率及音频选项按真实支持展示，手动值优先，不静默丢弃不兼容值。

**BR-generation-lifecycle**：提交后使用该次确定的输入与参考。应用内切换画布或项目不自动取消已提交生成，成功结果保存到原项目和节点；已删除的节点不自动重建。明确停止、删除节点及连接中断的结果如实展示，不保证已受理的远端任务立即撤销。成功、失败、部分成功及取消等待分别说明，成功部分继续保留。

验收场景 **SC-model-configuration**：配置模型后保存其他设置，已有凭据仍可使用且不会被通用读取返回；缺配置或无效配置明确不可用。验收场景 **SC-generation-navigation**：提交生成后切换项目，返回时结果属于原项目，不出现在新项目；供应商真实产出与文件保存分别核实。

### 3.8 素材与生成历史

**BR-asset-preservation**：素材仅支持图片、视频和音频，支持预览、搜索、类型与标签过滤、文件夹管理、上传、命名、移动、下载和删除。保存前可核对名称、实际文件夹、适用预览及多选标签；图片和视频必须位于素材文件夹内。标签保留角色、场景、物品、风格和音效等既有用途。

同名不覆盖，取消不写入，失败保留填写内容及已成功项。文件移动或改名后标签与来源对应到正确素材，不能只更新展示而丢失实际文件。批量操作逐项体现成功和失败，重试不重复处理已成功部分。

生成历史按日期展示并支持排序、预览、下载、删除展示、加入当前画布、创建独立画布或保存到素材。删除历史只移除相应展示，不破坏已有画布或对话引用；跨项目采用保留独立副本。历史来源或模型信息缺失时不编造。

验收场景 **SC-asset-management**：保存、改名、移动并重新打开素材，文件、标签和来源一致；部分失败后重试不覆盖同名素材，也不重复保存成功部分。

### 3.9 模板与创作优选

**BR-template-snapshot**：模板中心提供视频模板及项目流程模板，按产品展示、达人种草、短剧带货、真实测评等当前分类浏览。预览失败保留可用封面。分类与搜索共同生效；使用真实模型的语义检索在缺配置或失败时明确提示，不用静态结果冒充语义评估。

简单模式模板提供可编辑的提示词和适用参考，一键同款替换本轮模板内容但不自动提交生成。专业模式只展示确有项目快照的模板；查看创作过程可访问实际节点、内容、参数、分组与连接，不能编辑、生成或写回源项目。

项目可以制作独立模板快照，复制成功后才能登记并打开新项目；素材缺失、复制失败或来源变化时停止并说明，不能登记残缺副本。编辑副本不影响原模板。模板管理属于共享实例的内容管理，不依赖演示管理员、账号切换或角色审核。

用户提供素材的使用范围需获确认；获准示例明确标识，不冒充本次生成，也不自动恢复已经被用户移除的展示。

验收场景 **SC-template-copy**：在另一个浏览器预览共享实例模板并复制为项目，预览无源写入或模型请求，编辑副本不影响模板；缺少依赖素材时不创建可见的残缺项目。

### 3.10 教学、设置与操作辅助

**BR-onboarding-controls**：首页画布、图片和视频入口区分首次教学与后续普通创作；手动引导可以反复打开。课程内容属于对应项目，不向普通创作项目强行注入示例。首次提示偏好可按当前浏览器保存，不依赖不存在的账号身份。

画布教学最多八步，依次介绍人物图片创建与生成、视频节点、图片连接、视频提示词与参数以及生成查看。保留指定教学参考和提示词，不重复建立节点或连线，不自动调用模型。支持上一页、下一页、跳过和关闭，刷新恢复教学项目时不因临时入口信息丢失而缺少引导。弹窗在当前视口内可见且内容可达。

**BR-ui-preferences**：主要产品页面使用 AFXEN 品牌，保留必要版权和许可证。支持既有明暗主题与强调色偏好。快捷键说明与当前绑定一致，文字编辑保留系统输入和编辑快捷键；图标操作可通过悬浮说明或键盘访问名称识别。参数选择不会因鼠标移出或操作内部选项而自动丢失；关闭画布对话侧栏保留当前会话，不创建新对话。

验收场景 **SC-onboarding**：首次课程和手动重开都能完成八步前后操作，关闭或跳过不发起生成、不覆盖普通项目。验收场景 **SC-workbench-controls**：修改主题与快捷键后重新打开，已保存偏好与实际行为一致，关闭侧栏后可继续原会话。
