# 产品需求

本目录维护 AFXEN 创作工作台的产品边界、业务规则和验收场景，不代表相应功能已经实现或验证。

- [产品规格](prd.md)：当前有效的产品范围和业务规则。
- [验收索引](outline.md)：产品入口、对象、规则及场景与规格章节的对应关系。
- [Issue #7](https://git.aimall-tech.com/yuxin.ma/ai-studio/-/issues/7)：本次实施需求及有效人工补充。
- [实施计划](../.wf-prod/plans/issue-7/plan.md)与[任务](../.wf-prod/plans/issue-7/tasks.md)：服务端方案、依赖、当前停点及验证安排。

修改规则或场景时同步维护规格与索引，范围决定以 Issue 中有效人工意见为准。产品规格不承载代码结构、接口字段或实体登记；这些内容应由相应设计文档维护。

文档变更使用当前 workflow 提供的 PRD 检查，并核对导航和规则、场景对应关系；这类检查不能代替业务功能验证。业务代码的类型检查、构建和人工验证要求见[全仓开发规范](../AGENTS.md)。
