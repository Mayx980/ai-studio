# 映造 Studio 交互原型 V1.0

对应产品设计方案 V2.0。离线包为 `yingzaoStudioV1.zip`，解压后打开 `index.html`。

直接用 Chrome、Safari 或 Edge 打开 `index.html`，无需服务器、安装依赖或 API Key。建议桌面窗口宽度至少 1200px。

可演示：首页和我的项目新建项目、四类节点、拖动连线、分组、个人资产自动收录、提示词优化、提示词与配置收藏、媒体收藏及默认命名、跨项目引用、撤销恢复、导入和导出演示数据。

所有“演示生成”“演示优化”“演示命名”均为浏览器本地效果，不调用真实 AI。视频演示生成预览片段，音频为本地合成音，不代表模型能力；真实媒体请通过上传演示。

项目与资产保存在浏览器本地。不同浏览器及不同文件路径可能有不同存储空间；浏览器清理数据后会丢失，请通过首页“导出演示”备份。原型限制单个上传文件为 2MB，超额明确提示；不保存任何 API Key。

本原型参考 Toonflow 上游 commit `d2e94aca7b59659ff6b4ca15f03cf134ec7f0e1d` 的画布、分离的媒体/生成节点、参考区和素材复用机制，按已确认的产品方案 V2.0 重新组织用户界面。未复制或导入 Toonflow 代码，不是 Toonflow 实际运行版本。

上游：https://github.com/HBAI-Ltd/Toonflow-app

## 推荐演示路线（约 3 分钟）

1. 打开内置“山野来信”项目，查看文字、图片、视频节点及连线。
2. 点击图片输入框的星光图标，填写风格、生成优化结果，再点击应用。
3. 点击星形收藏图标，同时收藏提示词与配置；右键图片，选择收藏媒体。
4. 回到首页，新建另一个项目。右键画布 → 引用资产 → 我的收藏 → 图片 → 确定引用。
5. 在新节点输入框点击引用图标，分别应用收藏的提示词、配置；观察参考素材区。
6. 点击撤销和恢复，核对提示词与配置变化。可再添加音频节点或视频节点，点击演示生成，进入资产库查看新增内容。

连线：点击来源节点右侧圆点，再点击目标左侧圆点。Shift＋点击节点标题多选；右键节点分组、解除分组、复制或删除。拖动空白画布平移，工具栏缩放或适应视图。

## 验证结果

使用 Chromium 直接通过 `file://` 打开原型，完成 25 个浏览器交互场景：两入口创建、提示词优化、分别收藏、媒体命名保护、跨项目引用、提示词和配置预览应用、模型不兼容拦截、四类演示生成、分组、撤销恢复、刷新保留、资产移除、拖动、循环连线拦截、停止任务、真实文件上传、导出备份及备份导入。浏览器无运行错误。

真实模型调用未接入；Safari 的本地视频录制能力未实测，不支持时可上传真实视频演示其余流程。
