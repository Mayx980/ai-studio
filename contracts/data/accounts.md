# 独立账号数据与认证候选

所属 entity 为 `server`，调用方为 `web`。需求依据为 Issue #7 [note 131174](https://git.aimall-tech.com/yuxin.ma/ai-studio/-/issues/7#note_131174)。本版供计划审阅，尚未实现；当前运行代码仍是共享实例。

## 身份和数据

- 服务端分配不可变随机用户 ID；用户名规范化后唯一，显示名不能用作磁盘目录或授权依据。角色仅 `admin`、`user`；可信管理员管理账号与实例可执行扩展，普通用户管理自己的资料。停用替代删除，本版无开放注册或跨用户分享。
- 实例根 `accounts.json` 保存版本、用户记录及会话记录，通过统一文件入口以 `0o600` 原子保存并协调并发；密码只保存 Argon2id 哈希。会话仅保存高熵随机 token 的 SHA-256 摘要、用户 ID、有效期、认证版本及 CSRF 校验材料，不保存明文 token 或密码。损坏、权限异常或写入失败不得重建空白账号表、回退匿名或返回成功。
- 用户记录含用户名、显示名、角色、启用状态、密码哈希、认证版本、强制改密标记及创建时间。管理员创建/重置的密码要求首次登录改密，改密完成前只允许会话、改密和退出操作。密码采用 15–128 字符，允许粘贴和密码管理器，不作无意义组合限制或截断。
- Session 有效期候选为登录后 12 小时；登录及权限/密码变化轮换会话。退出撤销当前会话，停用、改密和管理员重置撤销该用户全部旧会话。跨标签页不能因 Cookie 换成另一账号就继续写旧页面草稿。
- 初始管理员是唯一允许引用实例旧数据位置的账号；该关联由受控初始化建立，不接受客户端提交。其它账号根为 `users/<userId>/`，个人配置、索引、workspaces、assets、templates 均在其内。系统插件与账号记录不属于用户可访问目录。

## HTTP 安全边界

沿用 `{ code, data, message }` 与 Zod 校验。新增接口在 `routes/auth/` 和 `routes/accounts/` 按单接口单文件定义，实施前在当前 Contract 补齐最终字段与方法；实现与文档不建立第二套路由事实源。

认证使用服务端 opaque Session 与 `HttpOnly; SameSite=Lax; Path=/` Cookie；HTTPS 部署启用 `Secure`。当前内网 HTTP 可用于测试，不能宣称密码和 Cookie 具有链路保密性。只信明确配置的可信代理/公开地址，不因任意请求伪造转发头认定安全连接。Cookie 不进入 localStorage/sessionStorage，登录、配置和个人业务响应禁止共享缓存。

除登录与必要的会话状态外，所有业务 API 默认要求登录。修改和生成请求校验同源、会话绑定的 CSRF token 及账号身份；登录本身也校验来源。媒体标签 GET 使用同源 Cookie，读取仍核对 owner 并保留 Range；不能为了媒体播放放开匿名目录。账号 ID、角色、绝对路径、旧演示身份或任意自定义 header 均不能证明权限。

前端每次业务请求携带页面已加载的身份标识，服务端只将其用于与 Cookie 身份比较，绝不据此选择用户。两者不一致返回 401 并拒绝操作；媒体 URL 同样有身份一致性校验。初始化、登录和改密的窄范围例外由明确路由控制，不提供“任意账号操作”参数。

登录错误统一提示，避免暴露账号是否存在；按来源和规范化账号限制失败尝试与并发密码哈希数，记录和过期清理有上限。限速不信任未配置代理的 `X-Forwarded-For`。401 表示未认证、会话失效或身份改变；403 表示操作无权/CSRF 拒绝；409 保留同名和 revision 冲突；429 表示暂时限速。错误、日志和管理列表不返回密码哈希、Session 摘要、CSRF 材料或原始 Key。

## 兼容和验收

受控本地初始化只在没有账号时创建首个管理员并建立旧数据归属；不对外提供“谁先打开谁成为管理员”的入口。重复执行失败而不重置旧密码或重新分配资料；初始化与登录不能因旧数据缺失而初始化第二套共享资料。备份和恢复包含实例账号记录及所有用户目录，密码/会话与项目备份不入 Git。

不同用户不能查询、修改或借用对方项目、素材、模板、对话、模型凭据、任务和事件流。同用户多页面保留冲突保护；服务重启保留账号与未过期会话，用户停用/改密之后旧会话仍无效。文件安全和密码参数的实际校验以实现与手动验证分别证明，文档不表示已通过。
