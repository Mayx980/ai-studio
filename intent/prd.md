# AIGC视频生成平台PRD（灵活模式补充版）

文档状态：待评审（含归档后确认的需求修订）
更新日期：2026-10-26
目标用户：公司内部运营人员、短视频创作新手
内部首批试用规模：约 5～20 人；创作新手的试用招募与登录方式待确认

## 1. 产品定位与目标

### 1.1 产品背景

公司各部门存在产品介绍、活动宣传等视频制作需求。目前通常依赖设计团队或外包排期，员工难以自主完成常规宣传视频。

平台基于 Toonflow 的节点画布、模型接入和素材复用能力，为内部员工提供文字、图片、视频、音频创作，以及素材管理和素材交付能力。

### 1.2 产品目标

让内部运营人员及短视频创作新手通过自然语言、参考素材和创意案例完成创作，无需进入画布即可获得图片、音频、剧情、分镜，或包含画面、配音、字幕、配乐和剪辑的完整短视频，并通过连续对话修改。

Agent 灵活模式为默认入口；灵感模式提供完整阶段引导，节点画布保留为可选的精细编排入口。用户可以按需导出文本 PDF、分镜 Excel、媒体素材和成片，外部软件可用于进一步制作，发布仍在平台外完成。

核心成功标准：用户无需设计人员代操作，能表达或借助案例补齐需求，获得可用结果，并在同一会话继续修改、下载。

### 1.3 典型场景

| 场景 | 主要输入 | 预期结果 |
|---|---|---|
| 产品宣传 | 产品卖点、图片、上传视频及宣传要求 | 剧情、分镜、素材或完整宣传视频 |
| 活动宣传 | 活动主题、时间地点、亮点、参与方式及素材 | 剧情、分镜、素材或完整活动视频 |
| 个人创作 | 自然语言、已有剧情／分镜、照片或创意案例 | 生活记录、搞笑故事、萌宠、知识分享、封面海报等作品 |
| 宣传素材制作 | 文本描述、参考图片或视频 | 可供本次或后续项目使用的图片、视频、音频 |

### 1.4 本期范围

本期包含：

- 公司统一登录。
- 服务端项目存储与个人内容隔离。
- Agent 灵感／灵活双模式、连续对话创作、自动规划、精确修改及可选画布操作。
- 新会话创意案例预览与应用；视频和图片案例按使用场景分类。
- 完整成片生成、对话剪辑、音量与色彩调整，以及图片区域和视频镜头对象局部修改。
- 首尾帧图片输入，一句话及一句话加图片生成音频。
- 浅色、深色及跟随系统的外观设置。
- 空白画布及文字、图片、视频、音频、脚本五类节点。
- 逐节点手动生成、Agent 调用生成工具，以及分镜表按行连接下游节点。
- 文档面板创作，以及 Office、PDF 文档读取。
- 图片、视频、音频个人资产及跨项目引用。
- 节点连线、分组、撤销与恢复。
- 文本节点 PDF 导出、脚本节点 Excel 导出。
- 音频节点配音与音乐生成。
- 单素材下载和按选定镜头批量下载。
- 线下脚本确认及成片审核结果、修改意见记录。
- 后台任务状态与生成结果管理。
- 管理员模型配置和任务故障查看。

本期不包含：

- 独立收藏和提示词资产能力。
- 专业多轨时间轴；对话成片、剪辑和合成能力见第 3.8 节。
- 脚本节点内图片／视频生成、资产准备向导及一键生成镜头媒体。

- 仅因连线或修改参数触发的整张画布自动执行。
- 积分发放、余额、预占、扣减、退还和预计积分提示。
- 平台用量统计页面。
- 多人协作、企业公共资产库、公开作品发布。
- 专业多轨时间轴、声音克隆。
- 模板市场、用户自建模板、员工发布或另存个人流程模板、技能交易。
- 视频文件链接输入、短视频平台分享链接解析。
- 平台内业务审核及外部渠道自动发布。
- 网页内容自动抓取与解析。

文字节点可生成普通脚本文本；结构化分镜表由脚本节点管理，媒体由连接的图片、视频或音频节点生成。

## 2. 用户、权限与资料边界

### 2.1 员工

内部员工通过公司统一身份登录。创作新手也属于目标用户，但内部身份以外的登录、试用准入及是否开放注册尚待确认，不据此默认开放注册。侧栏账号按钮展开退出登录菜单，退出后隐藏账号项目与画布，返回登录入口；退出不删除项目、资产或已提交任务。侧栏不再展示“我的工作空间／内容仅自己可见”说明模块。

用户在获准登录后可以：

- 创建、编辑、复制和删除自己的项目。
- 使用管理员开放的模型。
- 上传素材，生成文字、图片、视频和音频。
- 管理自己的资产和任务。
- 编辑文本及分镜，导出 PDF 和 Excel，下载媒体素材。
- 在对话中生成、预览、局部修改和下载成片；按需记录线下确认意见。

项目、文档、会话、资产及反馈记录按账号隔离，其他用户不可见、不可编辑。

内容保存于服务端，同一员工换电脑登录后可以继续制作。

### 2.2 管理员

管理员可以：

- 配置模型服务及 API Key。
- 设置开放模型与适用参数。
- 查看媒体生成及批量下载任务的状态和故障信息。

管理员默认不能浏览员工的创作正文、参考素材及反馈内容。故障信息不应直接暴露内容或服务密钥。

本期不建设积分管理和用量统计页面。

### 2.3 资料使用范围

仅允许上传已公开或获准外发的资料。上传入口说明适用范围。

产品主体优先使用真实素材。Logo、价格、日期、活动地点等关键信息，优先通过原始素材或可编辑排版呈现。

AI 可用于背景、氛围及辅助镜头。员工在采用结果和下载前检查产品外观与宣传信息。

## 3. 产品结构与主流程

### 3.1 页面结构

| 模块 | 主要功能 |
|---|---|
| 首页 | 最近项目、新建项目、Agent 创作入口 |
| 我的项目 | 搜索、打开、重命名、复制、删除项目 |
| 项目画布 | 节点、连线、分组、模型参数及生成 |
| Agent 对话 | 双模式、创意案例、自然语言生成与修改、素材引用、成片及工具反馈 |
| 设置 | 浅色／深色／跟随系统 |
| 文档面板 | 文档创作、编辑与 Office、PDF 内容读取 |
| 资产库 | 个人资产 |
| 素材交付 | 单素材下载、按选定镜头批量下载 |
| 确认与反馈 | 员工记录线下脚本确认、成片审核结果与修改意见 |
| 任务入口 | 查看媒体生成和批量下载状态、失败原因及结果 |
| 回收站 | 恢复删除未满 30 天的项目与个人资产 |
| 管理后台 | 模型及任务故障管理 |

### 3.2 主流程

默认灵活模式：**输入需求或选择创意案例 → 补充主题与素材 → 明确发送 → 自动规划与生成 → 预览结果 → 在原会话继续修改 → 下载，或主动添加到画布／保存个人资产。**

灵感模式：**提出想法 → 确认方向 → 选择方案 → 确认剧情 → 确认分镜 → 生成并确认素材。** 保留阶段确认规则，不强制用户改用直接生成。

用户也可以从已有剧情或分镜继续，或直接进入画布逐节点制作。工作文件夹为服务端项目工作文件夹，按账号隔离，不要求选择电脑上的本地目录。

### 3.3 项目约定

- 首页与“我的项目”使用同一新建流程。
- 默认名称为“未命名项目”。
- 手动新建画布项目后进入空白画布；Agent 入口创建成功后带入需求及引用，进入项目内对话，不要求进入画布。项目列表同步更新。
- 创建失败保留名称，重试不产生重复记录。
- 项目支持搜索、重命名、复制和删除。项目列表内名称不重名，冲突时在末尾添加数字区分。
- 每项目采用一种画幅：横屏 `16:9` 或竖屏 `9:16`。
- 另一画幅通过复制项目制作，复用兼容素材，并提示检查裁剪与画面适配。
- 不同创意方案通过复制项目制作。
- 推荐目标视频时长为 15～60 秒，超出提醒，不单独阻止素材生成和下载。

产品、活动模板是否保留为纯节点示例，尚待确认，不作为本期已确定功能。

### 3.4 灵感创作入口

用户选择已有工作文件夹，或者创建空文件夹，在对话框输入创作需求后开始创作。选择已有工作文件夹时，延续该文件夹所属项目的历史对话，不自动新建会话；仍可通过会话管理切换历史会话或主动创建新会话。创建空文件夹时，创建对应项目并产生新对话，带入本次输入的需求和引用。该入口与手动画布共用项目、节点、资产和生成记录。

对话框支持上传、粘贴及引用当前项目画布、本人其他项目画布、历史对话及个人资产库中已有的图片、音频、视频，不接受视频文件链接。可搜索和预览，明确展示来源及具体媒体版本；其他员工的项目和资产不可选。引用其他项目媒体不要求先保存为个人资产。

引用不会自动修改来源节点或启动生成。移除对话引用不删除来源媒体；已有引用遵循第 8 节的版本和保留规则。

### 3.5 项目内 Agent 对话

支持多轮对话、流式回复和工具执行反馈，展示执行中的工具、操作对象、成功结果或失败原因。生成任务关联本次会话、操作对象和实际结果，不要求先创建画布节点，不能仅显示聊天中的成功文字。

支持查看对话历史，创建、切换、重命名、删除会话。图标按钮支持鼠标悬浮及键盘聚焦查看功能名。会话按项目保存并受账号权限约束。

支持编辑已发送消息并重新发送。重发不是撤销，删除会话也不连带删除已创建的节点、已保存资产或已提交任务。重发后的工具调用读取当前项目状态，避免重复创建和无提示覆盖。

助手面板默认加宽，支持鼠标拖拽边缘或角落调整宽高，对话区独立滚动；长剧情及分镜表使用紧凑预览。只有分镜脚本表格修改使用全屏气泡，剧情等其他内容展示和编辑均使用就近小气泡；选择待生成的镜头也使用小气泡。表格单元格按字体和内容自适应宽高，短内容不保留多余空白，长内容完整显示。表单突出当前阶段所需字段。

Agent 支持通过选项、表单等结构化方式向用户提问，保留填写内容并明确提交状态。取消、跳过、未填写或未回复均不视为确认；依赖答案的操作等待用户作答，其他独立操作不受影响。

#### 灵感模式的视频创作阶段确认

问题与选项根据上下文生成，不固定套用示例。出方案前必须确认制作目的、风格、参考时长、画面比例、核心内容和目标受众；用户需求或引用材料已明确的信息直接采用并允许纠正，不重复提问。根据题材补充角色、品牌事实、素材使用限制、台词语言及其他必要问题；未知事实不作为已知内容编造。

方向完整后，提供多种可选方案，按推荐度降序展示，并结合目标与受众说明推荐理由。方案列表末尾提供“其他方案”，用户在表单填写修改要求后重新生成方案。用户选择方案后才生成剧情脚本。

剧情脚本包含以下大模块：故事定义（故事、地点、规则）；剧情结构（行动动机、冲突推进、各阶段变化）；创作约束层（用户指定内容、已有事实、AI自行判断及改写权限）。同时包含参考时长、角色形象、道具、场景、剪辑方式、画面与动作设计、台词/音效，以及后续素材所需提示词。

剧情在对话的可编辑预览中展示。用户可直接改写，也可选择修改并在表单填写要求，或发送文字要求重新生成。未确认草稿不写入节点；选择“确定剧情脚本，创建并保存文字节点，进入下一步”后才保存到文字节点，并进入分镜设计。

分镜根据已确认剧情生成，在对话内以表格预览并支持展开编辑。用户可通过修改表单或聊天重新生成草稿；确认后创建并保存脚本节点，进入生图阶段。剧情保存在文字节点，分镜表保存在脚本节点，不将分镜另存到文字节点。

生图前提取主要角色、道具和场景的具名提示词，供用户预览、修改并选择适用镜头。支持生成全部、在表单指定部分内容、调整提示词或暂不生图。选择生图后确认模型、比例、清晰度等参数。调整提示词时询问是否一键替换对应剧情和分镜中的提示词；确定才同步，取消则保留原脚本，仅用调整结果作为生图参考。同步前展示受影响内容，发生手改冲突时等待处理。

图片按场景地点、角色名（“XXX角色图”）或道具名命名。生成结果先预览，可按修改表单重新生成；确认图片后才创建并保存同名图片节点，进入视频阶段。图片节点作为相关分镜的上游连接，并出现在对应行的引用列；无关镜头不自动附加该图片。

视频阶段提供选择部分镜头或暂不生成。暂不生成即结束，不再追问。选择生成时在小气泡展示分镜选择表，勾选镜头号后确认模型、画质、时长等参数，依据所选行完整内容及引用列的图片、音频、文本生成。生成前固定镜头与引用版本快照；图生模式继续遵守图片数量及版本确认规则。视频按镜头号命名，支持预览播放；用户可在表单指定视频号/名及修改要求。确认视频后才创建并保存视频节点，作为对应分镜行的下游；重复确认不得重复创建。

所有阶段的创建与保存均指项目画布，不自动保存个人资产。取消不推进阶段，跳过生图仍可进入视频，跳过视频结束当前流程；已确认节点和结果保留，后续覆盖遵守额外确认规则。生成失败保留当前草稿并供用户重试，不把失败或未回复作为确认。

### 3.6 Agent 操作画布与资产

Agent 可创建、删除、移动、重命名节点，连接节点并调用生成工具。操作遵循与手动编辑相同的节点兼容性、权限、版本、保存及撤销规则；连线本身不触发下游生成。

用户手动编辑与 Agent 操作共用同一份画布和脚本数据；执行前校验对象当前状态，发生冲突时说明，不静默覆盖手动修改。已提交生成固定输入快照，撤销画布编辑不取消任务。

Agent 可查询、读取和导入个人资产，按名称、资产类型、保存位置和标签检索。导入项目只增加项目引用或副本，不移动、覆盖原资产。

Agent 修改资产库前必须展示对象和拟修改内容，用户确认后执行；包括新增保存、重命名、调整保存位置或标签、替换及删除。取消或未确认不得修改；操作范围变化时重新确认。删除仍遵循回收站与引用保护规则，不因 Agent 操作绕过手动保存要求。

灵感模式调用图片、视频、音频生成工具前，展示本次生成对象、模型、输入及参考版本、关键参数和数量，由用户确认单次或整个批次后执行。灵活模式按第 3.8 节以用户明确发送为执行起点，自动填入参数并规划执行，不增加每阶段确认。上传、引用、选择创意或修改参数本身不构成发送。失败重试由用户主动发起，不自动重试。Agent 删除或覆盖画布内容前，须额外展示受影响的节点、连线和内容以及拟执行的变更，用户明确确认后才执行。生成批次确认不替代删除或覆盖确认；取消或未回复时保留原内容，变更范围扩大时重新确认。

### 3.7 文档创作与读取

项目提供文档面板，支持创建、查看、编辑和保存文档，Agent 可结合文档内容辅助创作。文档与对话、画布可以相互引用，不重复维护不同版本的同一创作对象。

支持读取 Office（含 Word、Excel、PowerPoint）及 PDF 文档，将可读取内容用于需求理解、文案和脚本创作。展示来源和读取结果；解析失败或部分内容不可读时明确提示，不清空原文件，不编造缺失内容。读取不自动生成媒体、不自动保存为个人媒体资产。

支持的具体格式、文件大小、扫描版 PDF 的 OCR、版式和图表还原程度须技术验证，不默认承诺完整还原原始排版。

#### 模式与输入

输入框内部右下角切换灵感／灵活模式，默认灵活模式；各模式图标后附解释图标，悬浮或键盘聚焦可查看功能说明。切换保留历史对话、用户输入、引用和已有结果，不自行提交任务。

| 输入 | 可请求产出 |
|---|---|
| 一句话 | 图片、视频、音频、剧情或分镜 |
| 一句话＋上传／粘贴／引用图片 | 图片、视频、音频、剧情或分镜 |
| 首帧图片＋尾帧图片＋一句话 | 短视频 |
| 已有剧情或分镜＋继续创作要求 | 按指定环节继续生成或修改 |

按用户指定产物执行；已有剧情／分镜先识别结构，保留原文，不擅自改写，缺少关键内容或指代不清时询问。图片作为音频创作的视觉语境，与自然语言要求共同参与，不据图片推断真实声音、身份或声音授权。音频首批同时支持旁白配音、背景音乐和环境音效；一句话及一句话加图片两类输入均适用。旁白根据主题和图中可见内容形成可查看、可修改的文案并配音；背景音乐按情绪、节奏和用途创作；环境音效按画面场景及用户要求创作，不声称还原图片拍摄现场的真实声音。产物类型和用途不明确时先澄清，不将三类音频无提示混为单一结果。具体服务支持能力仍需技术验证。

素材支持上传、剪贴板粘贴、引用栏、个人资产库及历史素材，不支持输入视频文件链接或解析平台分享链接。用户上传的视频仍可整体参考，也可选择其中一帧作为图片参考；用户明确指定时可取用上传视频片段加入成片。

#### 首尾帧输入

<!-- BR-first-last SC-first-last -->

首尾帧模式在输入区域并列显示带“+”的首帧、尾帧框，中间提供交换操作，首帧与尾帧身份清晰可辨。点击任一“+”，可上传或粘贴图片，也可从引用栏或资产库选择；选定后显示缩略图和首／尾帧身份，允许替换、移除和交换，不自动生成。

首尾帧不能按普通多图参考顺序隐式推断；提交固定两张图片的角色和版本。缺少任一帧、上传未完成、图片失效或模型不支持首尾帧时明确提示补齐或调整，不能静默降级成单图或普通参考模式。仅当用户明确改选其他模式后按相应输入规则执行。已有草稿或创意案例与首尾帧要求冲突时先处理冲突，不清空原内容。

#### 自动规划与生成

简单请求直接生成；多步请求展示简要流程并自动组织图片、视频、音频生成和合成，允许暂停调整，已提交任务的停止规则见第 10 节。参数按语境自动识别并填入默认值，允许修改；图片、视频复用对应画布节点的参数配置气泡、字段、校验和可用能力，不要求新手理解专业参数。

用户明确发送创作指令后才启动。进入页面、引用素材、应用创意、补充表单、预览和修改参数不提交生成。缺少必需信息时给出下一步指引或由 Agent 澄清，已明确的信息不重复询问。

短视频默认交付包含画面、配音、字幕、配乐和剪辑的可播放、可下载成片；用户明确要求单镜头时生成单镜头。既有逐阶段规则仅约束灵感模式，灵活模式不要求先进入画布或每阶段人工确认。

#### 连续修改与结果保存

结合上下文，通过引用、`@`、素材名、镜头号、时间段定位修改对象；指代不唯一时先询问。支持选择部分分镜重新生成、调整片段顺序／时长、背景音乐音量及镜头色彩。修改前说明影响范围，不改无关内容；延长镜头允许重新生成，产出实际修改后的完整视频，不仅回复建议。

历史图片／视频卡片右下角提供引用和编辑入口。图片可圈选区域并描述修改；视频在某帧圈选对象后，对整个镜头中的同一对象执行修改，保持跨帧连续一致。圈选与备注用于实际生成新版本，不仅保存标记。结果支持预览、对比和恢复旧版本；失败不覆盖原结果，不扩大修改范围。

灵活模式结果先保留在会话中，剧情／分镜可展开编辑和保存；“添加到画布”创建对应五类节点，“保存到个人资产”仅用于图片、视频和音频。生成不自动保存资产，不自动要求用户管理节点。同名及重复操作遵循项目命名与保存规则。

### 3.9 创意案例预览与应用

<!-- BR-creative SC-creative -->

#### 目标、展示与预览

在 Agent 新会话空状态的输入框下方提供创意案例，同时保留直接输入需求。案例帮助新手理解可创作的内容和素材要求，不作为必选步骤；案例应用面向灵活模式，灵感模式现有阶段规则保留。

案例支持视频、图片，按使用场景分类。分类可涵盖生活记录、搞笑故事、萌宠、知识分享、封面海报，以及公司运营的产品展示、活动宣传；首批案例由产品方团队制作和提供，包含效果素材、名称说明、适用条件、参考特征、可替换内容及必需／可选输入。具体上线分类和案例清单由团队确定，不将示例分类视为必须全部上线的清单；案例上下架维护入口与账号可用范围仍待确认。

卡片上方为单个案例效果预览块，不提供多个角色预览块；下方展示案例名称与简介，例如“达人口播种草”“达人对镜真心分享，朋友式安利可信度高”。较长简介可截断，在案例详情中可查看完整内容。卡片仅展示效果预览、案例名称和简介；产出类型、所需素材（如无需素材／一张照片／商品图）、适用时长和画幅等必要条件放在放大播放气泡及应用后的输入区域中展示。案例较多时提供“查看更多”。

桌面端鼠标悬浮上方角色预览块时播放对应案例视频；点击该区域打开可放大播放的气泡，关闭后返回原位置并保留草稿。悬浮下方名称／简介区域时，其右侧浮现唯一主操作“使用”。按钮支持键盘聚焦访问；移动端保留点击预览和可直接访问的“使用”入口，不依赖悬浮。默认静音，仅由用户主动开启声音。预览及打开气泡不选择案例、不触发生成。实际移动端交付范围见第 14 节。

#### 应用流程与准备状态

**浏览 → 悬浮／放大预览 → 使用 → 提示词与关键素材带入输入框 → 编辑或替换 → 确认发送 → Agent 生成 → 原会话继续修改。**

点击“使用”将案例提示词自动填入上方输入框，并将案例中的人物、商品等关键图片素材同步带入该输入区域，进入准备状态；已有草稿时仍按下文冲突规则处理。输入区域显示“创意：案例名”，图片以带缩略图及用途名称的素材卡展示，如“商品1”“角色1”，与可编辑需求文本同时可见。用户可替换、删除、增加图片，也可直接修改提示词并补充自然语言，不要求理解专业提示词。当前创意仍支持查看、替换及移除。允许直接保留案例人物、商品图片、产品信息与提示词发送生成，不强制替换或增加单独的示例采用确认。自动填入只进入准备状态，仍以用户明确发送为生成起点。

例：选择“萌宠搞笑故事”后填写故事主题，宠物照片可以为可选项；时长、画幅按案例适用条件展示并允许调整。每个案例必须区分必需与可选信息，不能将可选照片误判为缺失阻断。

明确发送后才启动生成；仅应用案例不生成、不调用付费生成、不扣费。本期仍不建设积分、余额或充值体系。必需信息缺失时，指出具体缺项及补充入口；不能反复提出用户已回答的问题。

#### 业务规则与草稿保护

应用案例是参考表达方式并结合用户内容重新创作，不承诺逐帧复现效果。案例须说明可替换内容及会保留为参考的特征。自动带入的案例人物、商品及营销描述须能识别为案例提供的示例内容，用户可以原样发送，也可以替换或修改。原样发送表示按该案例素材和信息创作，不表示这些是用户自身品牌或产品的事实；团队提供的素材仍须符合既有资料使用范围，不据此扩大素材使用授权。

已有文字和素材时不静默清空。应用或替换前展示与当前需求冲突的部分，由用户选择保留当前内容、采用案例对应内容，或取消本次操作；未选择时保留原草稿，不提交生成。无冲突内容继续保留，不要求用户重复填写。

替换案例保留用户提供的信息，提示不再适用的素材或要求，由用户明确保留、移除或修改，不擅自删除。移除案例只解除案例关联，不清空用户输入、上传或引用；用户仍可自由创作，若有必要条件变化则提示。

案例应用不创建新会话；发送后的结果、引用和版本在原会话继续管理和修改，沿用第 3.8 节。未发送的准备状态不计为生成任务。

#### 与技能的关系及范围

案例是用户可见的创意选择入口，不要求用户先选 Skill，也不预设案例与 Skill 一一绑定。若生成需要系统已有技能，用户看到正常的执行步骤、对象、进度和结果，不承担技能选择或交易操作。具体绑定关系未确定，保留为第 14 节待确认项。

第一版仅“使用”一个主入口，不增加“使用／复刻”双按钮。不扩展模板市场、用户自建模板或技能交易。案例维护入口与职责待确认，不预设新增运营后台。

#### 异常处理

| 场景 | 预期行为 |
|---|---|
| 案例列表为空或加载失败 | 保留直接输入创作；提供清晰空状态或重试，不以示例冒充已加载案例 |
| 预览加载失败 | 显示失败和重试；保留名称、素材要求等可读信息，不自动换用其他效果或播放声音 |
| 自动带入的案例素材加载失败 | 保留提示词和其他成功图片，标明失败素材及替换／重试入口；必需素材不可用时不提交依赖生成 |
| 必需素材缺失／上传失败／上传中 | 指明素材与状态，允许补充或重试，不能以未完成素材提交依赖生成；已成功内容保留 |
| 有草稿时应用、替换或移除 | 按草稿保护规则处理，不静默覆盖，不重复上传已有可用素材 |
| 案例下架或当前账号不可用 | 应用及发送前核验；明确提示，不暗中替换案例，保留用户内容，可换用可用案例或移除后自由创作；不得继续使用无权访问的案例内容 |
| 生成失败 | 保留创意选择、需求、参数、已上传素材及已有成功结果；主动重试只处理失败范围，不自动重新收费生成 |

#### 验收标准

- 用户能从卡片预览效果，并识别产出类型、必需／可选素材及适用条件；默认静音，失败可重试。
- 悬浮角色块播放对应视频，点击可放大气泡播放；悬浮文字区域右侧出现“使用”，键盘及触屏不依赖悬浮也可访问。
- 点击“使用”后，案例提示词与人物／商品关键图片进入上方输入区域；创意名称和素材用途可识别，图片可替换、删除、增加，文本可修改；仅应用不生成、不扣费。
- 每张卡片仅有一个效果预览块，并展示名称和简介；放大气泡及应用后的输入区可查看产出类型、素材条件、时长和画幅。
- 应用后允许不替换案例人物、商品和提示词而直接发送；不增加强制替换或额外采用确认，但已有草稿冲突与必需素材有效性校验仍保留。
- 已有草稿和素材不被无提示覆盖；取消冲突处理后原内容保留，切换案例显示不再适用项。
- 必需信息缺失或上传失败有具体下一步；可选内容缺失不阻断，无法访问案例不绕过权限执行。
- 明确发送后才创建任务；生成后可在原会话继续修改，失败保留需求与素材供主动重试。

## 5. 五类节点创作

### 5.1 节点能力

| 节点 | 输入与操作 | 结果 |
|---|---|---|
| 文字 | 手写、粘贴、引用兼容内容，模型生成与改写 | 文案、脚本、分镜描述、提示词等普通文本 |
| 图片 | 上传或引用图片，提示词生成，模型支持时编辑参考图 | 图片与历史候选 |
| 视频 | 上传或引用兼容媒体，提示词生成 | 视频与历史候选 |
| 音频 | 上传、引用，按服务能力选择配音或音乐生成 | 音频与历史候选 |
| 脚本 | 输入故事情节，上传参考、生成并编辑分镜表、按行连接节点 | 画布完整分镜表及 Excel |

画布仅允许文字、脚本、图片、视频、音频五类节点，不新增独立文档、剧情、方案或参考节点类型；这些内容归入对应节点。画布内节点名称不重名，创建、复制、重命名及助手生成时，冲突自动添加数字后缀；个人资产名称在资产列表、会话名称在项目会话列表内分别去重。

不要求用户区分“展示节点”和“生成节点”。

文字正文支持 Markdown；结构化脚本由脚本节点承载。

配音模式区分“配音正文”和“声音／表达要求”，提示词优化作用于后者。

### 5.2 文本节点交互与 PDF 导出

复用 Toonflow 文本节点能力。空输入时默认文案引导用户填写“目标设定、风格”，例如“请输入创作目标、受众、核心信息和期望风格”。默认文案为提示，不作为用户输入提交模型。

文字节点输入框上方的正文区域可直接手写或粘贴完整剧情，编辑即更新正文，支持后续引用；模型输入和已保存正文分别保留。文本节点输入大致剧情后，点击“生成”，按上述故事定义、剧情结构、创作约束层和制作设计内容整理为剧情脚本，在就近气泡中预览并允许编辑。只有点击“确定”才保存为文字节点正文；取消保留原正文。文本节点不提供优化提示词入口。

点击文本节点卡片，弹出文本节点输入框面板，用于输入需求和模型生成。点击卡片右下角“详情”，进入编辑面板，查看、编辑完整文本并导出。

编辑面板右下角“确定”用于保存，成功后同步文本节点正文和卡片预览；保存失败保留编辑内容并允许重试。关闭有未保存修改的面板时提醒保存或放弃，不静默丢失。画布自动保存不代替编辑面板“确定”的正文提交。

编辑面板右上角提供“导出”图标，鼠标悬浮或键盘聚焦显示功能名；点击弹出“导出为PDF格式”选项，选择后导出当前编辑面板可见正文。导出不代替“确定”保存，存在未保存修改时提示导出内容尚未保存到节点。

PDF 保留可支持的标题、段落及列表，不包含模型密钥或对话工具日志。空正文不能导出并提示填写；导出失败不清空正文，可主动重试。

| 图片 | 保留 | 保留 |
| 视频 | 保留 | 保留 |
| 音频 | 保留 | 保留 |
| 脚本 | 不展示 | 保留 |

### 5.4 粘贴媒体

文字、图片、视频、音频节点输入框支持粘贴剪贴板中可读取的图片和视频文件：

**粘贴 → 校验 → 上传并保留在项目中 → 加入节点参考区。**

- 混合粘贴时，文字插入光标处，媒体进入参考区。
- 媒体不自动创建独立节点，不转换成提示词。
- 多文件逐项处理，部分失败不影响成功项。
- 不兼容、超数量或上传失败时明确说明，保留已有内容。
- 普通视频网址作为文本，不自动下载。
- 粘贴、上传和引用均不自动生成。
- 移除参考或撤销粘贴，不删除已保留的媒体；未手动保存的媒体不进入个人资产库。

### 5.5 参数摘要与面板

输入框下方通过紧凑摘要打开参数面板。助手的图片、视频生成使用与对应节点一致的模型及参数选择逻辑：相同字段、选项、默认值、校验和保存行为，不另建助手专属参数集。模型候选与可用参数按实际接入能力校验。

| 节点 | 按模型能力展示 |
|---|---|
| 图片 | 比例、画质、清晰度、背景、生成数量 |
| 视频 | 比例、画质、清晰度、时长、生成数量等适用参数 |
| 音频 | 音色、格式、时长、音量、生成数量等适用参数 |
| 文字 | 适用的文本模型配置 |

画质、清晰度、比例分别表达不同参数，不混为同一概念。

只展示模型实际支持的选项，不承诺所有模型均支持上述字段。

参数在面板内作为草稿，保存后更新节点摘要，取消不写入，不自动生成。灵感模式确认参数后提交批次；灵活模式以明确发送为起点，按第 3.8 节自动填入并采用参数；参数修改本身不触发生成，支持撤销、恢复。

切换模型后出现不兼容值时，明确标记并要求处理，不静默替换。

### 5.6 生成

支持员工逐节点点击生成及 Agent 调用生成工具。脚本节点只生成分镜表，不提供图片／视频生成或按镜头批量生成入口。Agent 的执行起点与范围按第 3.5、3.8 节区分模式；灵活模式可以先保存会话产物，不依赖创建媒体节点。上传、引用、连线和参数修改均不自动发起生成。

提交前检查模型、输入、参数、参考类型与数量。检查不通过时说明原因并保留输入。

视频支持文生视频、图生视频；首尾帧输入遵循第 3.8 节，不将首尾帧当普通多图参考。文生视频仅提交文字；图生视频统一从分镜行引用及节点引用汇总图片，按来源、版本和输出索引去重，不再设置独立“确认图片”入口。生成前统一展示图片清单并允许移除；移除只解除当前生成节点的引用，不删除原图。图生视频必须有1～10张可用图片，超过10张先删减；1张采用单图输入，2～10张采用多图参考输入，界面均称图生视频，不解释为按图片顺序拼接视频。

图片、视频节点输入 `@` 时，下拉卡片展示该节点已引用的图片并支持选择；确定后在输入内容中插入带封面的 `@图片名` 标签，用于指定某个场景或动作参考哪张图片。此操作不重复添加引用，也不改变输入之外的脚本内容；未引用的图片先通过引用按钮添加。移除最后一条该图引用时同步清理对应标签，保留其他手写内容。

手动节点及灵感模式生成前的图片清单确认代替独立图片确认；灵活模式在发送时固定所列图片角色与版本，不额外要求清单确认。需要确认的流程中，待确认期间图片版本、提示词或参数改变时，展示更新后的内容并再次确认，不能直接沿用旧确认。

每次提交固定输入及参考快照。任务执行期间编辑节点或切换上游采用版本，不改变已提交任务。

成功后：

- 保留历史结果，最新成功结果默认采用。
- 支持切换采用版本。
- 成功媒体保留在项目与生成记录中，由用户手动保存为个人资产。
- 多结果任务部分失败时保留成功项，显示失败原因。
- 不自动重试。

失败不清空输入，也不覆盖已有成功结果。

### 5.7 优化提示词

图片、视频、音频节点使用以下流程：

**打开优化面板 → 带入当前提示词 → 填写风格要求 → 生成 → 编辑结果 → 应用。**

应用前不改变原文，应用后支持编辑与撤销。

优化期间原输入发生变化时，应用前确认替换。失败保留面板内容，允许主动重试。

### 5.8 脚本节点（分镜）

脚本节点用于根据故事、文档或表格等参考内容生成、编辑和导出分镜脚本。“分镜节点”指该节点，不新增第六类节点。

#### 输入与生成

输入框支持输入故事情节和策划内容，上传文件、表格，并通过“引用”添加兼容参考内容。文档用于剧情理解，表格可导入已有镜头；上传后展示解析结果及列对应关系，确认后应用。解析失败保留原文件和已有内容，允许补充，不编造或静默丢弃。

输入框保留“引用”，不提供“优化提示词”。有可读取的有效参考内容时，输入文字可以为空，直接依据参考生成分镜；文字和有效参考均为空时不提交生成并提示补充。附件正在上传、解析失败或内容不可读不视为有效参考。

有文字及参考内容时共同用于生成。具体文件格式、大小及参考数量待验证。剧情脚本可先在文本节点创作并引用至脚本节点。

#### 分镜表及画布展示

输出在画布上以完整 Excel 式表格展示，所有列、所有行均可通过表格区域滚动访问，不仅展示摘要卡片或文件附件。表格使用同一份数据支持查看、逐项编辑、增删行及调整顺序；修改保存状态明确可见，失败保留输入。保留节点容器以移动、分组及缩放，完整表格为默认输出展示。

| 表头 | 内容 |
|---|---|
| 镜头号 | 镜头标识及顺序 |
| 时长 | 目标镜头时长 |
| 景别 | 远景、全景、中景、近景、特写等 |
| 运镜方式 | 固定、推、拉、摇、移等 |
| 画面 | 主体、动作及构图描述 |
| 台词/音效 | 对白、旁白及音效要求 |
| 角色表情反应 | 角色情绪、表情及动作反应 |
| 环境场景 | 地点、环境及光影氛围 |
| 分镜图提示词 | 图片节点可参考的镜头图片提示词 |
| 视频运动提示词 | 视频节点可参考的动作、运镜及变化要求 |

角色形象描述继续作为关联角色设定在详情中查看和编辑，与角色表情反应区分。引用角色图片时可结合其可见外观辅助更新描述，保留姓名、性格、背景，不修改其他角色；覆盖手改内容前确认，识别失败保留原文并支持重试，多模态能力待验证。脚本节点不负责生成角色图片。

#### 按行连接和引用

每一行提供独立连接出口，可连接一个或多个兼容节点。下游可以直接读取该行的镜头号、画面、台词、场景及提示词等内容，不默认引用整张表或其他行。

图片节点可参考该行分镜图提示词、画面及角色环境描述；视频节点可参考视频运动提示词、运镜及镜头内容；音频节点可参考台词/音效；文本节点可参考该行文本。字段作为可查看的来源参考，不静默覆盖下游已有手写输入，也不承诺模型支持全部字段或参数。表格文本不能代替图生视频所需参考图片。

连线时显示来源脚本节点及镜头号，点击可定位来源行。同一行可供多个节点使用；与普通连线共用兼容性、去重和循环依赖校验。

调整排序或修改镜头号不改变已有连接对应的镜头行。删除行前提示影响的下游连接，确认后移除该行引用，不删除下游节点、手写内容和已生成媒体。复制行作为新镜头处理，不默认继承原行下游连线。

修改行内容后，下游显示来源已更新，用户可查看新内容；已有生成结果保留并标记待更新，不自动重新生成。下一次提交固定当次采用的行内容与参考版本。重新生成整表前，若会覆盖手改内容或影响行连接，展示影响并确认；保留旧表及关联结果，不能按新行号静默连接到不同镜头。

#### Excel 导出

支持将当前表格导出为 Excel（.xlsx），保留上述十列表头、所有行、当前顺序和文本修改结果；角色形象描述作为补充列保留。提示词为空时不编造补齐。

画布表格和 Excel 导出共用数据；导出不包含画布连线，不提交生成。失败保留表格并允许重试。

#### 与媒体生成的边界

脚本节点不提供图片或视频生成按钮，不内置准备资产、生成镜头图片、确认图片再生成视频或一键生成所有资产的向导。分镜图提示词和视频运动提示词作为表格内容保留，不提供独立“优化提示词”工具。

用户将某行连接到图片／视频节点后，在对应节点配置参考、模型和参数并发起生成。视频节点仍可按能力选择文生视频或图生视频；仅图生视频要求确认实际参考图片版本，文本行引用不能替代图片。Agent 执行起点按第 3.5、3.8 节区分模式；脚本节点自身不增加媒体生成按钮，删除覆盖仍须额外确认。

## 6. 模型配置与节点连接

### 6.1 模型

| 能力 | 当前指定 |
|---|---|
| 文本 | `qwen3.8-flash` |
| 视频 | 万相 3.0 |
| 图片 | 千问图像生成 3.0 Pro |
| 配音与音乐 | 火山引擎 Seed Audio1.0 |

模型名称按用户提供记录，准确接口标识和实际能力待技术验证。

管理员统一配置凭据。员工不需要提供 API Key。

没有可用服务时说明原因，不自动切换未授权模型，也不跳转充值。供应商额度不足作为任务失败原因提示，不展示个人积分余额。

### 6.2 连线

连线仅建立内容依赖，不自动执行下游节点。

- 支持拖动端点或点击端点连接。
- 支持删除、重新连接、一对多及多对一。
- 文字输出作为下游文本参考。
- 脚本表格按行输出，下游只引用所连接行；详细规则见第 5.8 节。
- 媒体输出根据目标模型能力作为参考素材。
- 禁止自连接、重复连接和循环依赖。
- 高亮兼容端点，不兼容时说明原因。
- 连线标明内容用途。
- 删除连线只移除其提供的参考，不删除媒体资产。
- 上游没有有效结果时，阻止依赖该结果的生成并提示处理。

## 7. 个人资产

### 7.1 资产库结构

资产库提供个人资产，不提供企业公共资产。

左侧资产面板直接展示相同内容，与资产库、节点引用面板同步，不维护多套记录。

复用 Toonflow 素材库的预览、搜索、导入和画布引用能力，产品规则以本节个人资产约定为准，不沿用冲突的文件夹、权限或删除规则。

支持按名称、资产类型、保存位置和标签搜索、筛选及预览。

### 7.2 个人资产

仅用户主动保存后的图片、视频、音频进入个人资产库。上传、粘贴和生成结果未保存时，仍保留在项目、会话及生成记录中。普通文字、剧情、分镜及提示词不属于个人资产。

记录名称、预览、类型、来源项目／会话／节点、创建时间及保存时的具体内容版本。资产独立于原节点保留，删除来源不破坏其他位置已保留的有效引用。

### 7.3 保存为资产

具体图片、视频或音频通过“保存到个人资产”或右键“保存为资产”打开配置面板。剧情、分镜和提示词不提供该入口。

| 字段 | 规则 |
|---|---|
| 预览 | 图片查看，视频／音频播放、暂停及进度；展示来源 |
| 资产名称 | 必填、可编辑，提供 AI 命名；失败可手动填写，不覆盖已修改名称 |
| 保存位置 | 必填、单选：角色、场景、物品、风格、音效 |
| 设置标签 | 多选：角色、场景、物品、风格、音效 |

保存绑定当时明确选择的具体媒体版本，不提交生成；取消不收录也不删除项目内容，失败保留字段并允许重试。

## 8. 引用与撤销恢复

### 8.1 引用入口

| 入口 | 媒体引用方式 |
|---|---|
| 画布右键引用 | 多选后创建对应节点 |
| 节点输入框引用 | 添加兼容媒体到参考区 |
| 左侧资产拖动 | 媒体在空白处创建节点，兼容参考区添加参考 |
| Agent 历史素材引用 | 选择图片／视频及具体版本，按第 3.8 节指定用途 |

引用不自动生成。同一媒体版本与用途不重复添加，不兼容目标说明原因，应用支持撤销。

引用绑定具体版本，来源资产改名或来源项目删除不影响已有有效引用。

### 8.2 撤销与恢复

支持 `Cmd/Ctrl＋Z`、`Cmd/Ctrl＋Shift＋Z`。

编辑历史覆盖节点、连线、分组、文本、模型参数、参考素材、优化结果应用及采用版本切换。

- 连续输入合并为一步。
- 批量引用记为一步。
- 撤销后新增编辑清空恢复记录。
- 每张画布当前打开期间保留最多 100 步。
- 重新打开后重新记录。

撤销不取消已提交任务，不删除生成资产，也不回滚上传或管理员设置。

## 9. 素材下载与线下反馈

### 9.1 单素材下载

支持从节点结果、个人资产及镜头结果下载图片、视频或音频，下载绑定用户选择的具体版本，不要求先保存为个人资产。

关联镜头的文件名包含镜头号和素材名称，例如“001_产品特写.mp4”；无镜头归属的独立素材使用素材名称，不虚构镜头号。同名文件追加类型或版本等区分信息，不覆盖已有文件。具体命名补零位数和特殊字符处理在实现中验证，保持镜头顺序可识别。

### 9.2 按选定镜头批量下载

用户选择一个或多个分镜行，查看所连接下游节点的素材及版本后下载；一行连接多个节点时明确选择本次下载的结果。默认采用当前已选用的结果，不混入未采用候选。支持选择本次需要的图片、视频和关联音频，文件名包含镜头号和素材名称，便于在剪映中排序。

下载清单中每个可用结果均可独立勾选或取消，下载只包含本次勾选的结果；未勾选任何结果时禁用下载。移除选定镜头数量说明和“仅下载当前可用素材，跳过缺失项”选项，缺失项不阻止用户下载已勾选的可用素材。下载前检查文件可读性，列出缺失、生成中、失败或无采用版本的镜头，不将这些项目显示为已下载。文字正文可选择作为文本文件下载，媒体按所选版本下载。批量下载不提交模型生成，不修改节点或个人资产。

批量下载文件的打包形式、大小和数量限制待技术验证。后台准备结果可重新获取，不声称浏览器关闭后本地文件传输仍继续。

### 9.3 来源版本与返工

下载绑定发起时选定的版本。后续修改节点或采用新结果，不改变已下载文件；重复下载前展示当前选用版本。

上游剧情脚本、镜头内容、参考资产及提示词变化时，相关下游内容标记待检查或待更新；不自动覆盖手改内容、不删除旧结果、不自动提交生成。更换图生视频采用图片后，保留原视频并提示其来源已变化。

### 9.4 线下确认与反馈记录

剧情脚本及成片在线下确认，由员工在项目内记录结果和修改意见。平台不向客户提供登录、外部分享审核链接或审批流程，不代替线下确认。

记录包含确认对象的版本说明、确认结果、修改意见和记录时间；成片意见可关联具体镜头。结果区分待确认、需修改、已确认。脚本新版本不自动继承旧版本的确认结果，保留历史记录。

外部成片以名称或版本说明关联反馈；本期不承诺外部成片上传和预览。反馈不直接触发返工生成，由员工或 Agent 根据意见定位镜头并确认修改范围。

Agent 对话内的剪辑、字幕、配音配乐与成片输出按第 3.8 节完成；外部软件可继续加工，发布仍通过平台外渠道完成。线下确认记录不构成必须经过的生成阶段。

## 10. 任务、异常与数据保留

### 10.1 后台任务

媒体生成、成片合成和批量下载准备在服务端执行。文本 PDF 和分镜 Excel 的导出状态单独反馈，不与媒体生成混为同一任务。

切换项目、关闭页面或退出登录，不自动取消任务。重新登录后可查看状态和结果。

界面区分等待、执行、成功、失败、申请停止和最终取消等状态，避免将申请停止误报为已经取消。

本期仅提供任务状态和结果，不建设调用用量统计页面。

### 10.2 停止与重试

员工可以申请停止生成，但不能保证供应商立即撤销。

- 未提交供应商的任务可以停止。
- 已提交任务等待供应商最终状态。
- 停止申请后仍成功返回时，保留结果并说明状态。
- 失败保留输入与已有结果。
- 重试由员工主动发起。
- 多结果任务部分失败时保留成功项，重试不自动重生成成功项。

平台不展示个人积分扣减、退还或充值交互。

### 10.3 回收站

项目与个人资产删除后进入回收站，保留 30 天。

期限内支持恢复；期限结束后清理对应对象。

删除个人资产不连带删除其他项目仍使用的媒体内容。共享引用尚未解除时，不删除底层所需文件。

## 11. 核心验收

| 场景 | 通过标准 |
|---|---|
| 统一登录 | 内部员工可使用公司身份进入；外部新手准入待确定，不默认开放注册 |
| 双模式 | 默认灵活模式，说明可查看，切换保留历史和结果；灵感模式保留阶段确认 |
| 直接创作 | 一句话及一句话＋图片可产出图片、视频、音频、剧情或分镜，无需进入画布 |
| 音频创作 | 两类输入均可分别请求旁白配音、背景音乐、环境音效；旁白文案可查看修改，结果可播放下载，类型不明时澄清 |
| 首尾帧 | 两帧角色明确，各框可上传／粘贴／引用／选资产，支持交换；缺帧和不支持时不静默降级 |
| 创意案例 | 按第 3.9 节验证预览、应用、草稿保护、权限、缺项及失败重试 |
| 成片与连续修改 | 实际输出可播放下载的成片，局部修改保留无关内容，支持新旧版本对比和恢复 |
| 外观 | 浅色／深色／跟随系统立即生效并记住选择，无字号设置 |
| 内容隔离 | 员工无法访问其他员工内容，管理员默认不能浏览创作内容 |
| 跨设备使用 | 同一账号换电脑后可继续打开项目 |
| 新建项目 | 两个入口行为一致，失败重试不产生重复项目 |
| 五类节点 | 可完成兼容内容的输入、上传、引用和生成 |
| 输入框工具 | 文字和脚本不展示优化提示词，图片／视频／音频保留；五类节点保留引用，提示正确 |
| 粘贴媒体 | 成功项保留于项目并进入参考区，未手动保存不进入资产库 |
| 参数能力 | 只展示真实能力，不兼容项阻止生成 |
| 手动执行 | 连线、上传、参数修改均不自动触发生成 |
| 保存资产 | 配置面板支持图片查看、视频和音频播放预览；仅手动收录，绑定具体版本，保存位置单选、标签多选 |
| 灵感入口 | 选择已有工作文件夹延续项目历史对话，创建空文件夹产生新对话；可引用本人当前项目、其他项目及资产库媒体 |
| Agent 对话 | 多轮流式回复、工具反馈、会话管理、悬浮提示及编辑消息重发可用 |
| Agent 画布 | 可创建、删除、移动、重命名、连接；删除／覆盖额外确认，生成起点按两种模式区分 |
| 结构化提问 | 选项及表单可提交，取消或未答复不视为确认 |
| 文本节点 | 卡片打开输入面板，详情进入编辑面板；确定保存，导出图标提供PDF选项，失败保留正文 |
| 分镜表 | 有有效参考可空文字生成；无优化工具；画布完整展示十列表格并可编辑，Excel与当前数据一致 |
| 按行连接 | 每行可连多个节点，下游仅引用该行；排序改号不串行，删除行不删除下游结果 |
| 个人资产范围 | 仅图片、视频、音频；剧情／分镜可添加画布，提示词不提供资产入口 |
| 单素材下载 | 下载选定版本，关联镜头的文件名含镜头号及素材名称 |
| 批量下载 | 选定镜头后校验，默认采用版本，缺失项明确，可确认仅下载可用项 |
| 线下反馈 | 员工记录脚本及成片确认意见并关联版本，不自动生成返工素材 |
| 文档 | 可创作、编辑、读取受支持 Office／PDF，解析异常明确提示 |
| Agent 资产 | 可按分类标签查询和导入，修改必须先获用户确认 |
| 脚本边界 | 只生成编辑导出分镜表，不内置媒体生成；图片视频由下游节点执行 |
| 跨项目引用 | 删除来源后，已有引用仍可用 |
| 撤销恢复 | 可恢复画布编辑，不重复生成或删除资产 |
| 中英文 | 音频节点支持中英文配音，配音和镜头提示词可按创作语言设置 |
| 来源更新 | 保留旧版，员工确认后才替换 |
| 后台任务 | 离开页面后继续，重新登录可恢复查看 |
| 部分失败 | 成功结果保留，失败原因明确，无自动重试 |
| 回收站 | 30 天内可恢复，删除不破坏其他已有引用 |

模拟模型响应可以验证交互、异常和状态流转，不能替代真实模型生成及实际素材下载验收。

## 12. 试用评价

邀请约 5～20 名有真实宣传需求的员工，覆盖：

- 产品与活动场景。
- 中文、英文创作及音频节点中英文配音。
- 横屏与竖屏。
- 已有素材与 AI 生成素材混用。

单次任务成功标准：

**用户无需设计人员代操作，独立完成并下载目标素材或完整成片，并能在原会话继续修改。**

试用记录：

- 是否独立完成，以及需要帮助的步骤。
- 素材／成片是否可用，创意案例是否帮助理解需求，是否愿意继续使用及原因。
- 人工操作时间、生成等待时间。
- 重生成次数与失败情况。
- 产品外观、宣传信息、镜头连贯性、音频及画面问题。

不预设未经确认的成功率、耗时或质量达标数值。
