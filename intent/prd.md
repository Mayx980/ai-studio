# AIGC视频生成平台PRD V1.0

文档状态：待评审（含归档后确认的需求修订）
更新日期：2026-10-16  
目标用户：公司内部员工  
首批试用规模：约 5～20 人

## 1. 产品定位与目标

### 1.1 产品背景

公司各部门存在产品介绍、活动宣传等视频制作需求。目前通常依赖设计团队或外包排期，员工难以自主完成常规宣传视频。

平台基于 Toonflow 的节点画布、模型接入和素材复用能力，为内部员工提供文字、图片、视频、音频创作，以及素材管理和成片制作能力。

### 1.2 产品目标

让员工通过节点创作和素材复用，自主完成常规宣传视频，减少对专业制作人员排期的依赖。

首版以节点画布为主要创作界面，通过独立成片工作区完成素材编排、声音与字幕设置，以及完整视频导出。

试用阶段的核心成功标准：

**员工无需设计人员代操作，独立完成视频导出，并表示愿意实际使用。**

### 1.3 典型场景

| 场景 | 主要输入 | 预期结果 |
|---|---|---|
| 产品宣传 | 产品卖点、图片、已有视频及宣传要求 | 信息准确、突出产品价值的宣传视频 |
| 活动宣传 | 活动主题、时间地点、亮点、参与方式及素材 | 清晰传达活动信息的宣传视频 |
| 宣传素材制作 | 文本描述、参考图片或视频 | 可供本次或后续项目使用的图片、视频、音频 |

### 1.4 本期范围

本期包含：

- 公司统一登录。
- 服务端项目存储与个人内容隔离。
- 灵感创作入口、项目内 Agent 对话、结构化提问及画布操作。
- 空白画布及文字、图片、视频、音频、脚本五类节点。
- 逐节点手动生成、Agent 调用生成工具及脚本流程内按镜头批量生成。
- 文档面板创作，以及 Office、PDF 文档读取。
- 个人资产、收藏及跨项目引用。
- 节点连线、分组、撤销与恢复。
- 独立成片工作区。
- 配音、背景音乐、字幕、预览和 MP4 导出。
- 后台任务状态与生成结果管理。
- 管理员模型配置、任务故障查看和预设曲库管理。

本期不包含：

- 仅因连线或修改参数触发的整张画布自动执行。
- 积分发放、余额、预占、扣减、退还和预计积分提示。
- 平台用量统计页面。
- 多人协作、企业公共资产库、公开作品发布。
- 专业多轨时间轴、声音克隆。
- 模板市场、员工发布或另存个人流程模板。
- 平台内业务审核及外部渠道自动发布。
- 网页内容自动抓取与解析。

文字节点可生成普通脚本文本；结构化镜头、资产准备及关联生成由脚本节点管理。

## 2. 用户、权限与资料边界

### 2.1 员工

员工通过公司统一身份登录，不提供开放注册。

员工可以：

- 创建、编辑、复制和删除自己的项目。
- 使用管理员开放的模型。
- 上传素材，生成文字、图片、视频和音频。
- 管理自己的资产、收藏和任务。
- 编排、预览和导出成片。
- 查看历史导出版本。

项目、资产、收藏及成片按账号隔离，其他员工不可见、不可编辑。

内容保存于服务端，同一员工换电脑登录后可以继续制作。

### 2.2 管理员

管理员可以：

- 配置模型服务及 API Key。
- 设置开放模型与适用参数。
- 查看生成、导出任务的状态和故障信息。
- 维护获准使用的背景音乐曲库。

管理员默认不能浏览员工的创作正文、参考素材和成片内容。故障信息不应直接暴露内容或服务密钥。

本期不建设积分管理和用量统计页面。

### 2.3 资料使用范围

仅允许上传已公开或获准外发的资料。上传入口说明适用范围。

产品主体优先使用真实素材。Logo、价格、日期、活动地点等关键信息，优先通过原始素材或可编辑排版呈现。

AI 可用于背景、氛围及辅助镜头。员工在采用结果和导出前检查产品外观与宣传信息。

## 3. 产品结构与主流程

### 3.1 页面结构

| 模块 | 主要功能 |
|---|---|
| 首页 | 最近项目、新建项目、灵感创作入口 |
| 我的项目 | 搜索、打开、重命名、复制、删除项目 |
| 项目画布 | 节点、连线、分组、模型参数及生成 |
| Agent 对话 | 会话管理、多轮对话、素材引用、结构化提问及工具反馈 |
| 文档面板 | 文档创作、编辑与 Office、PDF 内容读取 |
| 资产库 | 个人资产与我的收藏 |
| 成片工作区 | 选素材、编排镜头、配置声音与字幕、预览导出 |
| 任务入口 | 查看生成和导出状态、失败原因及结果 |
| 回收站 | 恢复删除未满 30 天的项目与个人资产 |
| 管理后台 | 模型、任务故障及曲库管理 |

### 3.2 主流程

**选择／创建项目工作文件夹 → 灵感对话或手动画布创作 → 节点生成／脚本流程 → 手动保存资产、收藏和引用 → 手动编排成片 → 调整声音与字幕 → 预览 → 导出。**

工作文件夹为平台内的项目工作文件夹，随项目保存在服务端并按账号隔离；不要求用户选择员工电脑上的本地目录。

员工可以只生成和管理素材，不强制进入成片制作。

### 3.3 项目约定

- 首页与“我的项目”使用同一新建流程。
- 默认名称为“未命名项目”。
- 手动新建成功后进入空白画布；灵感入口创建成功后带入需求及引用，进入项目内 Agent 对话和画布。项目列表同步更新。
- 创建失败保留名称，重试不产生重复记录。
- 项目支持搜索、重命名、复制和删除。
- 每项目采用一种画幅：横屏 `16:9` 或竖屏 `9:16`。
- 另一画幅通过复制项目制作，复用兼容素材，并提示检查裁剪与画面适配。
- 每项目维护一份当前可编辑成片草稿。
- 不同创意方案通过复制项目制作。
- 推荐成片时长为 15～60 秒，超出提醒，不单独阻止导出。

产品、活动模板是否保留为纯节点示例，尚待确认，不作为本期已确定功能。

### 3.4 灵感创作入口

用户选择已有工作文件夹，或者创建空文件夹，在对话框输入创作需求后开始创作。选择已有工作文件夹时，延续该文件夹所属项目的历史对话，不自动新建会话；仍可通过会话管理切换历史会话或主动创建新会话。创建空文件夹时，创建对应项目并产生新对话，带入本次输入的需求和引用。该入口与手动画布共用项目、节点、资产和生成记录。

对话框支持选择并引用当前项目画布、本人其他项目画布及个人资产库中已有的图片、音频、视频。可搜索和预览，明确展示来源及具体媒体版本；其他员工的项目和资产不可选。引用其他项目媒体不要求先保存为个人资产。

引用不会自动修改来源节点或启动生成。移除对话引用不删除来源媒体；已有引用遵循第 8 节的版本和保留规则。

### 3.5 项目内 Agent 对话

支持多轮对话、流式回复和工具执行反馈，展示执行中的工具、操作对象、成功结果或失败原因。生成任务关联对应节点及结果，不能仅显示聊天中的成功文字。

支持查看对话历史，创建、切换、重命名、删除会话。图标按钮支持鼠标悬浮及键盘聚焦查看功能名。会话按项目保存并受账号权限约束。

支持编辑已发送消息并重新发送。重发不是撤销，删除会话也不连带删除已创建的节点、已保存资产或已提交任务。重发后的工具调用读取当前项目状态，避免重复创建和无提示覆盖。

Agent 支持通过选项、表单等结构化方式向用户提问，保留填写内容并明确提交状态。取消、跳过、未填写或未回复均不视为确认；依赖答案的操作等待用户作答，其他独立操作不受影响。

### 3.6 Agent 操作画布与资产

Agent 可创建、删除、移动、重命名节点，连接节点并调用生成工具。操作遵循与手动编辑相同的节点兼容性、权限、版本、保存及撤销规则；连线本身不触发下游生成。

用户手动编辑与 Agent 操作共用同一份画布和脚本数据；执行前校验对象当前状态，发生冲突时说明，不静默覆盖手动修改。已提交生成固定输入快照，撤销画布编辑不取消任务。

Agent 可查询、读取和导入个人资产，按名称、媒体类型、保存位置和标签检索。导入项目只增加项目引用或副本，不移动、覆盖原资产。

Agent 修改资产库前必须展示对象和拟修改内容，用户确认后执行；包括新增保存、重命名、调整保存位置或标签、替换及删除。取消或未确认不得修改；操作范围变化时重新确认。删除仍遵循回收站与引用保护规则，不因 Agent 操作绕过手动保存要求。

Agent 调用图片、视频、音频生成工具前，先展示本次生成对象、模型、输入及参考版本、关键参数和数量，用户确认单次或整个批次后执行。确认批次后，不要求逐节点重复确认；新增对象、改变已确认输入或扩大范围时重新确认。取消或未回复不提交生成。失败重试由用户主动发起，不自动重试。Agent 删除或覆盖画布内容前，须额外展示受影响的节点、连线和内容以及拟执行的变更，用户明确确认后才执行。生成批次确认不替代删除或覆盖确认；取消或未回复时保留原内容，变更范围扩大时重新确认。

### 3.7 文档创作与读取

项目提供文档面板，支持创建、查看、编辑和保存文档，Agent 可结合文档内容辅助创作。文档与对话、画布可以相互引用，不重复维护不同版本的同一创作对象。

支持读取 Office（含 Word、Excel、PowerPoint）及 PDF 文档，将可读取内容用于需求理解、文案和脚本创作。展示来源和读取结果；解析失败或部分内容不可读时明确提示，不清空原文件，不编造缺失内容。读取不自动生成媒体、不自动保存为个人媒体资产。

支持的具体格式、文件大小、扫描版 PDF 的 OCR、版式和图表还原程度须技术验证，不默认承诺完整还原原始排版。

## 4. 节点画布

### 4.1 布局

| 区域 | 设计 |
|---|---|
| 顶部 | 项目名称及重命名，成片工作区入口 |
| 左侧 | “画布”“资产”入口，面板可收起 |
| 中央 | 无限画布，支持节点、连线和分组 |
| 右侧 | 不设置固定面板 |
| 工具栏 | 撤销、恢复、缩小、放大、适应画布 |

节点内部展示输入、参考素材、模型、参数及生成结果。

画布空白处右键可以新增文字、图片、视频、音频、脚本节点，或引用媒体。新增节点位于右键位置。

### 4.2 编辑与保存

节点支持移动、多选、复制、删除、分组和解除分组。

保留自动保存。保存失败时提示并允许重试，不清空编辑内容；离开前仍未保存成功时提醒员工。

默认使用一张主画布。需要支持多个画布时，从“画布”面板切换，具体旧项目兼容范围待评审。

## 5. 五类节点创作

### 5.1 节点能力

| 节点 | 输入与操作 | 结果 |
|---|---|---|
| 文字 | 手写、粘贴、引用兼容内容，模型生成与改写 | 文案、脚本、分镜描述、提示词等普通文本 |
| 图片 | 上传或引用图片，提示词生成，模型支持时编辑参考图 | 图片与历史候选 |
| 视频 | 上传或引用兼容媒体，提示词生成 | 视频与历史候选 |
| 音频 | 上传、引用，按服务能力选择配音或音乐生成 | 音频与历史候选 |
| 脚本 | 输入故事情节，编辑镜头、准备资产、合成提示词 | 结构化镜头及关联图片／视频节点 |

不要求用户区分“展示节点”和“生成节点”。

文字正文支持 Markdown；结构化脚本由脚本节点承载。

配音模式区分“配音正文”和“声音／表达要求”，提示词优化作用于后者。

### 5.2 输入框工具

| 节点 | 优化提示词 | 收藏 | 引用 |
|---|---|---|---|
| 文字 | 不展示 | 保留 | 保留 |
| 图片 | 保留 | 保留 | 保留 |
| 视频 | 保留 | 保留 | 保留 |
| 音频 | 保留 | 保留 | 保留 |

悬停或键盘聚焦时显示工具名称，不可用时说明原因。

文字节点仍支持模型生成与改写。

### 5.3 粘贴媒体

文字、图片、视频、音频节点输入框支持粘贴剪贴板中可读取的图片和视频文件：

**粘贴 → 校验 → 上传并保留在项目中 → 加入节点参考区。**

- 混合粘贴时，文字插入光标处，媒体进入参考区。
- 媒体不自动创建独立节点，不转换成提示词。
- 多文件逐项处理，部分失败不影响成功项。
- 不兼容、超数量或上传失败时明确说明，保留已有内容。
- 普通视频网址作为文本，不自动下载。
- 粘贴、上传和引用均不自动生成。
- 移除参考或撤销粘贴，不删除已保留的媒体；未手动保存的媒体不进入个人资产库。

### 5.4 参数摘要与面板

模型选择独立展示。输入框下方通过紧凑摘要打开参数面板。

| 节点 | 按模型能力展示 |
|---|---|
| 图片 | 比例、画质、清晰度、背景、生成数量 |
| 视频 | 比例、画质、清晰度、时长、生成数量等适用参数 |
| 音频 | 音色、格式、时长、音量、生成数量等适用参数 |
| 文字 | 适用的文本模型配置 |

画质、清晰度、比例分别表达不同参数，不混为同一概念。

只展示模型实际支持的选项，不承诺所有模型均支持上述字段。

点击选项立即更新摘要，但不自动生成。参数修改支持撤销、恢复。

切换模型后出现不兼容值时，明确标记并要求处理，不静默替换。

### 5.5 生成

支持员工逐节点点击生成、Agent 调用生成工具及脚本节点内按镜头批量生成。上传、引用、连线和参数修改均不自动发起生成。

提交前检查模型、输入、参数、参考类型与数量。检查不通过时说明原因并保留输入。

每次提交固定输入及参考快照。任务执行期间编辑节点或切换上游采用版本，不改变已提交任务。

成功后：

- 保留历史结果，最新成功结果默认采用。
- 支持切换采用版本。
- 成功媒体保留在项目与生成记录中，由用户手动保存为个人资产。
- 多结果任务部分失败时保留成功项，显示失败原因。
- 不自动重试。

失败不清空输入，也不覆盖已有成功结果。

### 5.6 优化提示词

图片、视频、音频节点使用以下流程：

**打开优化面板 → 带入当前提示词 → 填写风格要求 → 生成 → 编辑结果 → 应用。**

应用前不改变原文，应用后支持编辑与撤销。

优化期间原输入发生变化时，应用前确认替换。失败保留面板内容，允许主动重试。

### 5.7 脚本节点

输入故事情节后生成可编辑镜头表，包含镜号、时长、画面描述、角色形象描述、景别、光影氛围、对白／旁白、音效、运镜、最终提示词及操作。支持添加、删除和修改镜头。

流程为：确认镜头 → 准备资产 → 合成提示词 → 生成镜头图片 → 用户确认图片 → 图生视频。支持生成关联图片／视频节点及按镜头批量生成，最终由用户进入成片工作区编排。

准备资产页面支持补充、删除、替换角色、场景、道具图片，来源包括本地上传及粘贴、AI 生成、当前画布和个人资产库。复用图片节点参数面板，结合脚本设定、全局风格及用户补充输入生成图片。参考资产在准备页面管理，用户需要时再放入画布。

一键生成资产默认仅补齐缺失项；全部重新生成须单独确认并保留旧版本。生成或选取参考图不自动保存为个人资产。

角色形象描述先根据脚本生成。上传或替换对应角色图片后，参考图片更新其可见外观描述，并同步该角色关联镜头；保留姓名、性格和背景等设定，不修改其他角色。识别失败保留图片和原文，支持重试及手动修改；多模态能力待验证。

结合镜头及对应资产合成分镜图提示词、视频运动提示词。点击“查看提示词”打开编辑面板，修改自动保存，失败明确提示并允许重试。一键合成默认仅处理缺失或未手改项；覆盖用户手改内容须另行确认。

先生成镜头图片，用户确认后才可对相应镜头图生视频。批量任务部分失败保留成功项，允许重试失败项，不重复生成成功项。上游脚本或资产变化只将相关提示词标记为待更新，不自动覆盖或重新生成。

## 6. 模型配置与节点连接

### 6.1 模型

| 能力 | 当前指定 |
|---|---|
| 文本 | `qwen3.8-flash` |
| 视频 | 万相 3.0 |
| 图片 | 千问图像生成 3.0 Pro |
| 配音与音乐 | 火山引擎 Seed Audio1.0 |

模型名称按用户提供记录，准确接口标识和实际能力待技术验证。

管理员统一配置凭据。员工不需要提供 API Key。

没有可用服务时说明原因，不自动切换未授权模型，也不跳转充值。供应商额度不足作为任务失败原因提示，不展示个人积分余额。

### 6.2 连线

连线仅建立内容依赖，不自动执行下游节点。

- 支持拖动端点或点击端点连接。
- 支持删除、重新连接、一对多及多对一。
- 文字输出作为下游文本参考。
- 媒体输出根据目标模型能力作为参考素材。
- 禁止自连接、重复连接和循环依赖。
- 高亮兼容端点，不兼容时说明原因。
- 连线标明内容用途。
- 删除连线只移除其提供的参考，不删除媒体资产。
- 上游没有有效结果时，阻止依赖该结果的生成并提示处理。

## 7. 个人资产与收藏

### 7.1 资产库结构

资产库包含“个人资产”和“我的收藏”，不提供企业公共资产。

左侧资产面板直接展示相同内容，与资产库、节点引用面板同步，不维护多套记录。

复用 Toonflow 素材库的预览、搜索、导入和画布引用能力，产品规则以本节个人资产约定为准，不沿用冲突的文件夹、权限或删除规则。

支持按名称、媒体类型、保存位置和标签搜索、筛选及预览。收藏支持重命名与取消收藏。

### 7.2 个人资产

仅用户手动保存后的图片、视频、音频进入个人资产库。上传、粘贴和生成结果未保存时仍保留在项目及生成记录中。

记录名称、预览、类型、来源项目、创建时间及具体媒体版本。

文字结果保存在项目中，需要跨项目复用时收藏为文案。

资产独立于原节点保留。删除节点、来源项目或收藏，不破坏其他位置已保留的媒体引用。

### 7.3 提示词与文案收藏

输入框文本可以收藏为提示词，文字节点正文可以收藏为文案。

收藏保存当时的文本快照，后续修改节点不改变收藏内容。

支持 AI 默认命名和手动重命名。命名失败时使用文本前 20 个字，不阻塞收藏。

### 7.4 配置收藏

配置收藏保存模型及当前节点适用参数，包括：

- 模型。
- 画面比例。
- 画质。
- 清晰度。
- 背景。
- 生成数量。
- 时长。
- 音量。
- 其他已开放、可保存的节点参数。

**不包含参考图片、参考视频或参考音频。**

保存时只展示当前节点适用字段，由员工勾选保存项，不将示例字段强加给不支持的模型。

配置记录节点类型、模型和所选参数值，不绑定参考媒体。

同时收藏文本与配置时，分别创建记录。配置命名失败时使用“节点类型＋模型名称”。

### 7.5 保存为资产

右键具体图片、视频或音频，菜单展示“保存为资产”图标及名称，点击打开配置面板。

| 字段 | 规则 |
|---|---|
| 预览 | 支持图片、视频、音频预览并展示来源；图片可查看，视频和音频可播放、暂停并查看播放进度 |
| 资产名称 | 必填、可编辑，提供“AI生成”图标；失败可手动填写，AI 不覆盖已修改名称 |
| 保存位置 | 必填、单选：角色、场景、物品、风格、音效 |
| 设置标签 | 多选：角色、场景、物品、风格、音效 |

保存绑定具体媒体版本，切换节点采用结果不改变已保存资产。保存失败保留已填字段并允许重试。取消不收录、不删除项目媒体。

媒体收藏统一改为保存资产，不再保留独立媒体收藏入口；提示词、文案及配置收藏继续保留。

## 8. 引用与撤销恢复

### 8.1 引用入口

| 入口 | 媒体 | 提示词与配置 |
|---|---|---|
| 画布右键引用 | 多选后创建对应节点 | 不直接应用，提示先选择节点 |
| 节点输入框引用 | 添加兼容媒体到参考区 | 预览后应用到当前节点 |
| 左侧资产拖动 | 空白处创建节点，兼容参考区添加参考 | 应用到已有节点前预览 |

同一次选择不混选媒体与提示词／配置。

引用不自动生成。同一媒体版本与用途不重复添加。

引用绑定具体版本，来源资产改名或来源项目删除不影响已有引用。

### 8.2 应用规则

提示词整体替换当前输入；已有内容时展示替换前后内容并确认。

配置应用时：

- 预览字段并选择应用项。
- 仅替换勾选参数，其他参数不变。
- 不添加、替换或移除当前参考媒体。
- 校验与现有参考媒体组成的完整配置。
- 不兼容时说明原因，允许调整选择。
- 校验通过后整体应用，不先部分覆盖再报告失败。

### 8.3 撤销与恢复

支持 `Cmd/Ctrl＋Z`、`Cmd/Ctrl＋Shift＋Z`。

编辑历史覆盖节点、连线、分组、文本、模型参数、参考素材、优化结果应用、收藏内容应用及采用版本切换。

- 连续输入合并为一步。
- 批量引用、整体配置应用记为一步。
- 撤销后新增编辑清空恢复记录。
- 每张画布当前打开期间保留最多 100 步。
- 重新打开后重新记录。

撤销不取消已提交任务，不删除生成资产，也不回滚上传、收藏或管理员设置。

## 9. 成片工作区

### 9.1 创建成片

每项目一份当前成片草稿，员工手动从节点结果或个人资产中选择素材。

不依赖脚本或分镜，不自动安排镜头。

支持：

- 添加、删除、排序镜头。
- 替换素材、设置裁剪范围与画面适配。
- 编辑镜头对应的旁白和宣传文字。
- 配置字幕、配音与背景音乐。
- 预览完整成片。

本期不提供专业多轨时间轴。

### 9.2 来源变化

素材加入成片后绑定具体版本。

画布采用结果变化时，成片保留原版本，并提示来源已有新版本。员工可确认更新或继续沿用。

节点输入变化后，已有生成结果保留并标记待更新。员工可重生成，也可明确确认沿用。

任何同步操作不自动发起新的模型生成。

### 9.3 配音与字幕

项目可以选择有配音或无配音。

有配音时：

- 按镜头组织旁白，整片使用统一音色。
- 配音通过音频节点生成，并关联到对应镜头。
- 修改旁白后，仅需主动重生成对应音频。
- 不因修改文字自动提交生成任务。

配音和字幕分别选择中文或英文。

跨语言字幕根据旁白翻译，允许逐镜头修改。仅修改字幕不重生成配音；旁白变化后提示字幕待更新。

无配音项目仍可包含画面宣传文字和背景音乐，不因缺少旁白音频阻止导出。

### 9.4 背景音乐及原声

背景音乐支持：

- 管理员维护的获准使用曲库。
- 音频节点生成的音乐。

AI 音乐服务未配置时明确显示不可用，预设曲库仍可使用。

镜头原声默认静音，可逐镜头开启并调整音量。

配音播放时，背景音乐自动降低音量。

### 9.5 时长匹配

系统根据内容适配字幕和时长，无法匹配时明确标记。

配音长于可用画面时，员工可缩短旁白、调整画面时长或补充镜头。

不自动发起生成，不默认通过末帧定格补足缺口。

音画时长问题未解决时可继续编辑和预览，但不能正式导出。

### 9.6 导出与版本

输出：

- 1080p MP4。
- 横屏 `16:9` 或竖屏 `9:16`。
- 字幕直接写入画面。

输出分辨率不等于所有素材具备原生 1080p 画质。首版不包含独立字幕文件导出。

导出检查：

| 情况 | 处理 |
|---|---|
| 必需素材缺失、文件不可读等导致无法合成 | 阻止导出并定位问题 |
| 音画时长不匹配 | 阻止导出，提示调整 |
| 来源存在新版本、内容待更新 | 提示后允许确认继续 |
| 清晰度不足 | 提示，不单独阻止 |
| 品牌资料未设置 | 不阻止 |
| 超出 15～60 秒推荐范围 | 提示，不单独阻止 |

每次成功导出保留文件、时间及对应内容快照。修改当前草稿不改变历史成片。

员工自行预览、导出，审核与发布沿用公司现有流程。

## 10. 任务、异常与数据保留

### 10.1 后台任务

生成和导出在服务端执行。

切换项目、关闭页面或退出登录，不自动取消任务。重新登录后可查看状态和结果。

界面区分等待、执行、成功、失败、申请停止和最终取消等状态，避免将申请停止误报为已经取消。

本期仅提供任务状态和结果，不建设调用用量统计页面。

### 10.2 停止与重试

员工可以申请停止生成，但不能保证供应商立即撤销。

- 未提交供应商的任务可以停止。
- 已提交任务等待供应商最终状态。
- 停止申请后仍成功返回时，保留结果并说明状态。
- 失败保留输入与已有结果。
- 重试由员工主动发起。
- 多结果任务部分失败时保留成功项，重试不自动重生成成功项。

平台不展示个人积分扣减、退还或充值交互。

### 10.3 回收站

项目与个人资产删除后进入回收站，保留 30 天。

期限内支持恢复；期限结束后清理对应对象。

删除个人资产不连带删除其他项目、收藏和历史成片仍使用的具体媒体。共享引用尚未解除时，不删除底层所需文件。

取消收藏仅移除收藏记录，不进入项目或个人资产的连带删除流程。

| 粘贴媒体 | 成功项保留于项目并进入参考区，未手动保存不进入资产库 |
| 参数能力 | 只展示真实能力，不兼容项阻止生成 |
| 手动执行 | 连线、上传、参数修改均不自动触发生成 |

| Agent 对话 | 多轮流式回复、工具反馈、会话管理、悬浮提示及编辑消息重发可用 |
| Agent 画布 | 可创建、删除、移动、重命名、连接节点；删除或覆盖须额外确认，媒体生成先确认单次或整个批次，未确认不执行 |
| 结构化提问 | 选项及表单可提交，取消或未答复不视为确认 |
| 文档 | 可创作、编辑、读取受支持 Office／PDF，解析异常明确提示 |
| Agent 资产 | 可按分类标签查询和导入，修改必须先获用户确认 |
| 脚本流程 | 镜头表、资产准备、可编辑提示词、确认图片后图生视频，手改与旧版本保留 |
| 跨项目引用 | 删除来源后，已有引用仍可用 |
| 撤销恢复 | 可恢复画布编辑，不重复生成或删除资产 |
| 手动成片 | 可选择素材、增删排序、设置声音字幕并导出 |
| 中英文 | 支持配音和字幕独立选择语言 |
| 无配音 | 可完成文字、画面和音乐成片 |
| 时长问题 | 问题明确定位，未解决时阻止正式导出 |
| 来源更新 | 保留旧版，员工确认后才替换 |
| 后台任务 | 离开页面后继续，重新登录可恢复查看 |
| 部分失败 | 成功结果保留，失败原因明确，无自动重试 |
| 导出版本 | 历史成功成片可下载且不随编辑变化 |
| 回收站 | 30 天内可恢复，删除不破坏其他已有引用 |

模拟模型响应可以验证交互、异常和状态流转，不能替代真实模型生成及完整成片导出验收。

## 12. 试用评价

邀请约 5～20 名有真实宣传需求的员工，覆盖：

- 产品与活动场景。
- 中文、英文及跨语言配音字幕。
- 横屏与竖屏。
- 已有素材与 AI 生成素材混用。

单次任务成功标准：

**员工无需设计人员代操作，独立导出，并表示愿意实际使用。**

试用记录：

- 是否独立完成，以及需要帮助的步骤。
- 是否愿意使用成片及原因。
- 人工操作时间、生成等待时间。
- 重生成次数与失败情况。
- 产品外观、宣传信息、字幕、声音及画面问题。

不预设未经确认的成功率、耗时或质量达标数值。
