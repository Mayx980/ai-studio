# AI生成视频平台PRD V3.0

文档状态：待评审（含归档后确认的需求修订）
更新日期：2026-10-19
目标用户：公司内部员工  
首批试用规模：约 5～20 人

## 1. 产品定位与目标

### 1.1 产品背景

公司各部门存在产品介绍、活动宣传等视频制作需求。目前通常依赖设计团队或外包排期，员工难以自主完成常规宣传视频。

平台基于 Toonflow 的节点画布、模型接入和素材复用能力，为内部员工提供文字、图片、视频、音频创作，以及素材管理和素材交付能力。

### 1.2 产品目标

让员工通过 Agent 对话、节点创作和素材复用，独立完成宣传视频所需的脚本、分镜与镜头素材，交由剪映等外部软件完成剪辑。

首版以节点画布为主要创作界面，提供文本 PDF、分镜 Excel 导出和媒体素材下载。脚本与成片在线下确认，员工在平台记录结果和修改意见；剪辑、成片合成、字幕和发布在外部完成。

试用阶段的核心成功标准：

**员工无需设计人员代操作，独立完成可用于外部剪辑的镜头素材并下载交付，表示愿意实际使用。**

### 1.3 典型场景

| 场景 | 主要输入 | 预期结果 |
|---|---|---|
| 产品宣传 | 产品卖点、图片、已有视频及宣传要求 | 产品宣传脚本、分镜及镜头素材 |
| 活动宣传 | 活动主题、时间地点、亮点、参与方式及素材 | 活动宣传脚本、分镜及镜头素材 |
| 宣传素材制作 | 文本描述、参考图片或视频 | 可供本次或后续项目使用的图片、视频、音频 |

### 1.4 本期范围

本期包含：

- 公司统一登录。
- 服务端项目存储与个人内容隔离。
- 灵感创作入口、项目内 Agent 对话、结构化提问及画布操作。
- 空白画布及文字、图片、视频、音频、脚本五类节点。
- 逐节点手动生成、Agent 调用生成工具，以及分镜表按行连接下游节点。
- 文档面板创作，以及 Office、PDF 文档读取。
- 图片、视频、音频、提示词个人资产及跨项目引用。
- 节点连线、分组、撤销与恢复。
- 文本节点 PDF 导出、脚本节点 Excel 导出。
- 音频节点配音与音乐生成。
- 单素材下载和按选定镜头批量下载。
- 线下脚本确认及成片审核结果、修改意见记录。
- 后台任务状态与生成结果管理。
- 管理员模型配置和任务故障查看。

本期不包含：

- 独立收藏功能；提示词通过“保存为资产”复用。
- 平台内剪辑、成片工作区、音视频合成、字幕编辑及成片导出。
- 脚本节点内图片／视频生成、资产准备向导及一键生成镜头媒体。

- 仅因连线或修改参数触发的整张画布自动执行。
- 积分发放、余额、预占、扣减、退还和预计积分提示。
- 平台用量统计页面。
- 多人协作、企业公共资产库、公开作品发布。
- 专业多轨时间轴、声音克隆。
- 模板市场、员工发布或另存个人流程模板。
- 平台内业务审核及外部渠道自动发布。
- 网页内容自动抓取与解析。

文字节点可生成普通脚本文本；结构化分镜表由脚本节点管理，媒体由连接的图片、视频或音频节点生成。

## 2. 用户、权限与资料边界

### 2.1 员工

员工通过公司统一身份登录，不提供开放注册。

员工可以：

- 创建、编辑、复制和删除自己的项目。
- 使用管理员开放的模型。
- 上传素材，生成文字、图片、视频和音频。
- 管理自己的资产和任务。
- 编辑文本及分镜，导出 PDF 和 Excel，下载媒体素材。
- 记录线下脚本确认、成片审核结果和修改意见。

项目、文档、资产及反馈记录按账号隔离，其他员工不可见、不可编辑。

内容保存于服务端，同一员工换电脑登录后可以继续制作。

### 2.2 管理员

管理员可以：

- 配置模型服务及 API Key。
- 设置开放模型与适用参数。
- 查看媒体生成及批量下载任务的状态和故障信息。

管理员默认不能浏览员工的创作正文、参考素材及反馈内容。故障信息不应直接暴露内容或服务密钥。

本期不建设积分管理和用量统计页面。

### 2.3 资料使用范围

仅允许上传已公开或获准外发的资料。上传入口说明适用范围。

产品主体优先使用真实素材。Logo、价格、日期、活动地点等关键信息，优先通过原始素材或可编辑排版呈现。

AI 可用于背景、氛围及辅助镜头。员工在采用结果和下载前检查产品外观与宣传信息。

## 3. 产品结构与主流程

### 3.1 页面结构

| 模块 | 主要功能 |
|---|---|
| 首页 | 最近项目、新建项目、灵感创作入口 |
| 我的项目 | 搜索、打开、重命名、复制、删除项目 |
| 项目画布 | 节点、连线、分组、模型参数及生成 |
| Agent 对话 | 会话管理、多轮对话、素材引用、结构化提问及工具反馈 |
| 文档面板 | 文档创作、编辑与 Office、PDF 内容读取 |
| 资产库 | 个人资产 |
| 素材交付 | 单素材下载、按选定镜头批量下载 |
| 确认与反馈 | 员工记录线下脚本确认、成片审核结果与修改意见 |
| 任务入口 | 查看媒体生成和批量下载状态、失败原因及结果 |
| 回收站 | 恢复删除未满 30 天的项目与个人资产 |
| 管理后台 | 模型及任务故障管理 |

### 3.2 主流程

**选择／创建项目 → 整理需求 → 剧情脚本 → 记录线下确认 → 分镜设计 → 分镜表按行连接下游节点 → 在下游节点设置参考与参数 → 生成镜头素材 → 下载 → 外部剪辑 → 记录成片反馈 → 外部发布。**

工作文件夹为平台内的项目工作文件夹，随项目保存在服务端并按账号隔离；不要求用户选择员工电脑上的本地目录。

员工可只生成、管理和下载素材，不强制完成整套脚本流程。

### 3.3 项目约定

- 首页与“我的项目”使用同一新建流程。
- 默认名称为“未命名项目”。
- 手动新建成功后进入空白画布；灵感入口创建成功后带入需求及引用，进入项目内 Agent 对话和画布。项目列表同步更新。
- 创建失败保留名称，重试不产生重复记录。
- 项目支持搜索、重命名、复制和删除。
- 每项目采用一种画幅：横屏 `16:9` 或竖屏 `9:16`。
- 另一画幅通过复制项目制作，复用兼容素材，并提示检查裁剪与画面适配。
- 不同创意方案通过复制项目制作。
- 推荐目标视频时长为 15～60 秒，超出提醒，不单独阻止素材生成和下载。

产品、活动模板是否保留为纯节点示例，尚待确认，不作为本期已确定功能。

### 3.4 灵感创作入口

用户选择已有工作文件夹，或者创建空文件夹，在对话框输入创作需求后开始创作。选择已有工作文件夹时，延续该文件夹所属项目的历史对话，不自动新建会话；仍可通过会话管理切换历史会话或主动创建新会话。创建空文件夹时，创建对应项目并产生新对话，带入本次输入的需求和引用。该入口与手动画布共用项目、节点、资产和生成记录。

对话框支持选择并引用当前项目画布、本人其他项目画布及个人资产库中已有的图片、音频、视频和提示词。可搜索和预览，明确展示来源及具体媒体版本；其他员工的项目和资产不可选。引用其他项目媒体不要求先保存为个人资产。

引用不会自动修改来源节点或启动生成。移除对话引用不删除来源媒体；已有引用遵循第 8 节的版本和保留规则。

### 3.5 项目内 Agent 对话

支持多轮对话、流式回复和工具执行反馈，展示执行中的工具、操作对象、成功结果或失败原因。生成任务关联对应节点及结果，不能仅显示聊天中的成功文字。

支持查看对话历史，创建、切换、重命名、删除会话。图标按钮支持鼠标悬浮及键盘聚焦查看功能名。会话按项目保存并受账号权限约束。

支持编辑已发送消息并重新发送。重发不是撤销，删除会话也不连带删除已创建的节点、已保存资产或已提交任务。重发后的工具调用读取当前项目状态，避免重复创建和无提示覆盖。

Agent 支持通过选项、表单等结构化方式向用户提问，保留填写内容并明确提交状态。取消、跳过、未填写或未回复均不视为确认；依赖答案的操作等待用户作答，其他独立操作不受影响。

### 3.6 Agent 操作画布与资产

Agent 可创建、删除、移动、重命名节点，连接节点并调用生成工具。操作遵循与手动编辑相同的节点兼容性、权限、版本、保存及撤销规则；连线本身不触发下游生成。

用户手动编辑与 Agent 操作共用同一份画布和脚本数据；执行前校验对象当前状态，发生冲突时说明，不静默覆盖手动修改。已提交生成固定输入快照，撤销画布编辑不取消任务。

Agent 可查询、读取和导入个人资产，按名称、资产类型、保存位置和标签检索。导入项目只增加项目引用或副本，不移动、覆盖原资产。

Agent 修改资产库前必须展示对象和拟修改内容，用户确认后执行；包括新增保存、重命名、调整保存位置或标签、替换及删除。取消或未确认不得修改；操作范围变化时重新确认。删除仍遵循回收站与引用保护规则，不因 Agent 操作绕过手动保存要求。

Agent 调用图片、视频、音频生成工具前，先展示本次生成对象、模型、输入及参考版本、关键参数和数量，用户确认单次或整个批次后执行。确认批次后，不要求逐节点重复确认；新增对象、改变已确认输入或扩大范围时重新确认。取消或未回复不提交生成。失败重试由用户主动发起，不自动重试。Agent 删除或覆盖画布内容前，须额外展示受影响的节点、连线和内容以及拟执行的变更，用户明确确认后才执行。生成批次确认不替代删除或覆盖确认；取消或未回复时保留原内容，变更范围扩大时重新确认。

### 3.7 文档创作与读取

项目提供文档面板，支持创建、查看、编辑和保存文档，Agent 可结合文档内容辅助创作。文档与对话、画布可以相互引用，不重复维护不同版本的同一创作对象。

支持读取 Office（含 Word、Excel、PowerPoint）及 PDF 文档，将可读取内容用于需求理解、文案和脚本创作。展示来源和读取结果；解析失败或部分内容不可读时明确提示，不清空原文件，不编造缺失内容。读取不自动生成媒体、不自动保存为个人媒体资产。

支持的具体格式、文件大小、扫描版 PDF 的 OCR、版式和图表还原程度须技术验证，不默认承诺完整还原原始排版。

## 4. 节点画布

### 4.1 布局

| 区域 | 设计 |
|---|---|
| 顶部 | 项目名称及重命名、素材下载入口 |
| 左侧 | “画布”“资产”入口，面板可收起 |
| 中央 | 无限画布，支持节点、连线和分组 |
| 右侧 | 不设置固定面板 |
| 工具栏 | 撤销、恢复、缩小、放大、适应画布 |

节点内部展示输入、参考素材、模型、参数及生成结果。

画布空白处右键可以新增文字、图片、视频、音频、脚本节点，或引用媒体。新增节点位于右键位置。

### 4.2 编辑与保存

节点支持移动、多选、复制、删除、分组和解除分组。

保留自动保存。保存失败时提示并允许重试，不清空编辑内容；离开前仍未保存成功时提醒员工。

默认使用一张主画布。需要支持多个画布时，从“画布”面板切换，具体旧项目兼容范围待评审。

## 5. 五类节点创作

### 5.1 节点能力

| 节点 | 输入与操作 | 结果 |
|---|---|---|
| 文字 | 手写、粘贴、引用兼容内容，模型生成与改写 | 文案、脚本、分镜描述、提示词等普通文本 |
| 图片 | 上传或引用图片，提示词生成，模型支持时编辑参考图 | 图片与历史候选 |
| 视频 | 上传或引用兼容媒体，提示词生成 | 视频与历史候选 |
| 音频 | 上传、引用，按服务能力选择配音或音乐生成 | 音频与历史候选 |
| 脚本 | 输入故事情节，上传参考、生成并编辑分镜表、按行连接节点 | 画布完整分镜表及 Excel |

不要求用户区分“展示节点”和“生成节点”。

文字正文支持 Markdown；结构化脚本由脚本节点承载。

配音模式区分“配音正文”和“声音／表达要求”，提示词优化作用于后者。

### 5.2 文本节点交互与 PDF 导出

复用 Toonflow 文本节点能力。空输入时默认文案引导用户填写“目标设定、风格”，例如“请输入创作目标、受众、核心信息和期望风格”。默认文案为提示，不作为用户输入提交模型。

点击文本节点卡片，弹出文本节点输入框面板，用于输入需求和模型生成。点击卡片右下角“详情”，进入编辑面板，查看、编辑完整文本并导出。

编辑面板右下角“确定”用于保存，成功后同步文本节点正文和卡片预览；保存失败保留编辑内容并允许重试。关闭有未保存修改的面板时提醒保存或放弃，不静默丢失。画布自动保存不代替编辑面板“确定”的正文提交。

编辑面板右上角提供“导出”图标，鼠标悬浮或键盘聚焦显示功能名；点击弹出“导出为PDF格式”选项，选择后导出当前编辑面板可见正文。导出不代替“确定”保存，存在未保存修改时提示导出内容尚未保存到节点。

PDF 保留可支持的标题、段落及列表，不包含模型密钥或对话工具日志。空正文不能导出并提示填写；导出失败不清空正文，可主动重试。

### 5.3 输入框工具

| 节点 | 优化提示词 | 引用 |
|---|---|---|
| 文字 | 不展示 | 保留 |
| 图片 | 保留 | 保留 |
| 视频 | 保留 | 保留 |
| 音频 | 保留 | 保留 |
| 脚本 | 不展示 | 保留 |

悬停或键盘聚焦时显示工具名称，不可用时说明原因。

文字节点仍支持模型生成与改写。

### 5.4 粘贴媒体

文字、图片、视频、音频节点输入框支持粘贴剪贴板中可读取的图片和视频文件：

**粘贴 → 校验 → 上传并保留在项目中 → 加入节点参考区。**

- 混合粘贴时，文字插入光标处，媒体进入参考区。
- 媒体不自动创建独立节点，不转换成提示词。
- 多文件逐项处理，部分失败不影响成功项。
- 不兼容、超数量或上传失败时明确说明，保留已有内容。
- 普通视频网址作为文本，不自动下载。
- 粘贴、上传和引用均不自动生成。
- 移除参考或撤销粘贴，不删除已保留的媒体；未手动保存的媒体不进入个人资产库。

### 5.5 参数摘要与面板

模型选择独立展示。输入框下方通过紧凑摘要打开参数面板。

| 节点 | 按模型能力展示 |
|---|---|
| 图片 | 比例、画质、清晰度、背景、生成数量 |
| 视频 | 比例、画质、清晰度、时长、生成数量等适用参数 |
| 音频 | 音色、格式、时长、音量、生成数量等适用参数 |
| 文字 | 适用的文本模型配置 |

画质、清晰度、比例分别表达不同参数，不混为同一概念。

只展示模型实际支持的选项，不承诺所有模型均支持上述字段。

点击选项立即更新摘要，但不自动生成。参数修改支持撤销、恢复。

切换模型后出现不兼容值时，明确标记并要求处理，不静默替换。

### 5.6 生成

支持员工逐节点点击生成及 Agent 调用生成工具。脚本节点只生成分镜表，不提供图片／视频生成或按镜头批量生成入口。Agent 可在用户确认范围后调用连接的媒体节点。上传、引用、连线和参数修改均不自动发起生成。

提交前检查模型、输入、参数、参考类型与数量。检查不通过时说明原因并保留输入。

每次提交固定输入及参考快照。任务执行期间编辑节点或切换上游采用版本，不改变已提交任务。

成功后：

- 保留历史结果，最新成功结果默认采用。
- 支持切换采用版本。
- 成功媒体保留在项目与生成记录中，由用户手动保存为个人资产。
- 多结果任务部分失败时保留成功项，显示失败原因。
- 不自动重试。

失败不清空输入，也不覆盖已有成功结果。

### 5.7 优化提示词

图片、视频、音频节点使用以下流程：

**打开优化面板 → 带入当前提示词 → 填写风格要求 → 生成 → 编辑结果 → 应用。**

应用前不改变原文，应用后支持编辑与撤销。

优化期间原输入发生变化时，应用前确认替换。失败保留面板内容，允许主动重试。

### 5.8 脚本节点（分镜）

脚本节点用于根据故事、文档或表格等参考内容生成、编辑和导出分镜脚本。“分镜节点”指该节点，不新增第六类节点。

#### 输入与生成

输入框支持输入故事情节和策划内容，上传文件、表格，并通过“引用”添加兼容参考内容。文档用于剧情理解，表格可导入已有镜头；上传后展示解析结果及列对应关系，确认后应用。解析失败保留原文件和已有内容，允许补充，不编造或静默丢弃。

输入框保留“引用”，不提供“优化提示词”。有可读取的有效参考内容时，输入文字可以为空，直接依据参考生成分镜；文字和有效参考均为空时不提交生成并提示补充。附件正在上传、解析失败或内容不可读不视为有效参考。

有文字及参考内容时共同用于生成。具体文件格式、大小及参考数量待验证。剧情脚本可先在文本节点创作并引用至脚本节点。

#### 分镜表及画布展示

输出在画布上以完整 Excel 式表格展示，所有列、所有行均可通过表格区域滚动访问，不仅展示摘要卡片或文件附件。表格使用同一份数据支持查看、逐项编辑、增删行及调整顺序；修改保存状态明确可见，失败保留输入。保留节点容器以移动、分组及缩放，完整表格为默认输出展示。

| 表头 | 内容 |
|---|---|
| 镜头号 | 镜头标识及顺序 |
| 时长 | 目标镜头时长 |
| 景别 | 远景、全景、中景、近景、特写等 |
| 运镜方式 | 固定、推、拉、摇、移等 |
| 画面 | 主体、动作及构图描述 |
| 台词/音效 | 对白、旁白及音效要求 |
| 角色表情反应 | 角色情绪、表情及动作反应 |
| 环境场景 | 地点、环境及光影氛围 |
| 分镜图提示词 | 图片节点可参考的镜头图片提示词 |
| 视频运动提示词 | 视频节点可参考的动作、运镜及变化要求 |

角色形象描述继续作为关联角色设定在详情中查看和编辑，与角色表情反应区分。引用角色图片时可结合其可见外观辅助更新描述，保留姓名、性格、背景，不修改其他角色；覆盖手改内容前确认，识别失败保留原文并支持重试，多模态能力待验证。脚本节点不负责生成角色图片。

#### 按行连接和引用

每一行提供独立连接出口，可连接一个或多个兼容节点。下游可以直接读取该行的镜头号、画面、台词、场景及提示词等内容，不默认引用整张表或其他行。

图片节点可参考该行分镜图提示词、画面及角色环境描述；视频节点可参考视频运动提示词、运镜及镜头内容；音频节点可参考台词/音效；文本节点可参考该行文本。字段作为可查看的来源参考，不静默覆盖下游已有手写输入，也不承诺模型支持全部字段或参数。表格文本不能代替图生视频所需参考图片。

连线时显示来源脚本节点及镜头号，点击可定位来源行。同一行可供多个节点使用；与普通连线共用兼容性、去重和循环依赖校验。

调整排序或修改镜头号不改变已有连接对应的镜头行。删除行前提示影响的下游连接，确认后移除该行引用，不删除下游节点、手写内容和已生成媒体。复制行作为新镜头处理，不默认继承原行下游连线。

修改行内容后，下游显示来源已更新，用户可查看新内容；已有生成结果保留并标记待更新，不自动重新生成。下一次提交固定当次采用的行内容与参考版本。重新生成整表前，若会覆盖手改内容或影响行连接，展示影响并确认；保留旧表及关联结果，不能按新行号静默连接到不同镜头。

#### Excel 导出

支持将当前表格导出为 Excel（.xlsx），保留上述十列表头、所有行、当前顺序和文本修改结果；角色形象描述作为补充列保留。提示词为空时不编造补齐。

画布表格和 Excel 导出共用数据；导出不包含画布连线，不提交生成。失败保留表格并允许重试。

#### 与媒体生成的边界

脚本节点不提供图片或视频生成按钮，不内置准备资产、生成镜头图片、确认图片再生成视频或一键生成所有资产的向导。分镜图提示词和视频运动提示词作为表格内容保留，不提供独立“优化提示词”工具。

用户将某行连接到图片／视频节点后，在对应节点配置参考、模型和参数并发起生成。视频节点仍可按能力选择文生视频或图生视频；仅图生视频要求确认实际参考图片版本，文本行引用不能替代图片。Agent 调用媒体节点仍遵循确认范围和删除覆盖确认规则。

## 6. 模型配置与节点连接

### 6.1 模型

| 能力 | 当前指定 |
|---|---|
| 文本 | `qwen3.8-flash` |
| 视频 | 万相 3.0 |
| 图片 | 千问图像生成 3.0 Pro |
| 配音与音乐 | 火山引擎 Seed Audio1.0 |

模型名称按用户提供记录，准确接口标识和实际能力待技术验证。

管理员统一配置凭据。员工不需要提供 API Key。

没有可用服务时说明原因，不自动切换未授权模型，也不跳转充值。供应商额度不足作为任务失败原因提示，不展示个人积分余额。

### 6.2 连线

连线仅建立内容依赖，不自动执行下游节点。

- 支持拖动端点或点击端点连接。
- 支持删除、重新连接、一对多及多对一。
- 文字输出作为下游文本参考。
- 脚本表格按行输出，下游只引用所连接行；详细规则见第 5.8 节。
- 媒体输出根据目标模型能力作为参考素材。
- 禁止自连接、重复连接和循环依赖。
- 高亮兼容端点，不兼容时说明原因。
- 连线标明内容用途。
- 删除连线只移除其提供的参考，不删除媒体资产。
- 上游没有有效结果时，阻止依赖该结果的生成并提示处理。

## 7. 个人资产

### 7.1 资产库结构

资产库提供个人资产，不提供企业公共资产。

左侧资产面板直接展示相同内容，与资产库、节点引用面板同步，不维护多套记录。

复用 Toonflow 素材库的预览、搜索、导入和画布引用能力，产品规则以本节个人资产约定为准，不沿用冲突的文件夹、权限或删除规则。

支持按名称、资产类型、保存位置和标签搜索、筛选及预览。

### 7.2 个人资产

仅用户手动保存后的图片、视频、音频、提示词进入个人资产库。上传、粘贴和生成结果未保存时仍保留在项目及生成记录中。

记录名称、预览、类型、来源项目和节点、创建时间及保存时的具体内容版本。

普通文字结果保存在项目中；需要复用的提示词通过“保存为资产”保存，不恢复独立文案或配置收藏。

资产独立于原节点保留。删除节点或来源项目，不破坏其他位置已保留的媒体引用。

### 7.3 保存为资产

右键具体图片、视频或音频，选择“保存为资产”。提示词输入区域及分镜表提示词单元格也提供“保存为资产”入口，保存当前明确选定的一段提示词；为空时提示补充，不创建空资产。两类入口打开相同配置面板。

| 字段 | 规则 |
|---|---|
| 预览 | 图片查看，视频／音频播放、暂停及进度；提示词展示完整文本，可滚动查看；均展示来源 |
| 资产名称 | 必填、可编辑，提供“AI生成”图标；失败可手动填写，AI 不覆盖已修改名称 |
| 保存位置 | 必填、单选：角色、场景、物品、风格、音效 |
| 设置标签 | 多选：角色、场景、物品、风格、音效 |

保存绑定当时具体媒体版本或提示词文本快照。提示词资产不包含模型配置、参数或参考图片／视频／音频；源提示词后续修改不改变已保存资产。保存不提交生成，AI命名失败不阻止手动填写。保存失败保留已填字段并允许重试。取消不收录、不删除项目媒体。

## 8. 引用与撤销恢复

### 8.1 引用入口

| 入口 | 媒体引用方式 |
|---|---|
| 画布右键引用 | 多选后创建对应节点 |
| 节点输入框引用 | 添加兼容媒体到参考区 |
| 左侧资产拖动 | 媒体在空白处创建节点，兼容参考区添加参考 |
| 提示词资产引用 | 预览全文后应用到目标提示词输入框；已有文字时展示替换内容并确认 |

引用不自动生成。同一媒体版本与用途不重复添加。提示词资产仅应用文本，不改变当前模型、参数和参考媒体；不兼容的目标说明原因。应用支持撤销。

引用绑定具体版本，来源资产改名或来源项目删除不影响已有引用或已应用提示词文本。

### 8.2 撤销与恢复

支持 `Cmd/Ctrl＋Z`、`Cmd/Ctrl＋Shift＋Z`。

编辑历史覆盖节点、连线、分组、文本、模型参数、参考素材、优化结果应用及采用版本切换。

- 连续输入合并为一步。
- 批量引用记为一步。
- 撤销后新增编辑清空恢复记录。
- 每张画布当前打开期间保留最多 100 步。
- 重新打开后重新记录。

撤销不取消已提交任务，不删除生成资产，也不回滚上传或管理员设置。

## 9. 素材下载与线下反馈

### 9.1 单素材下载

支持从节点结果、个人资产及镜头结果下载图片、视频或音频，下载绑定用户选择的具体版本，不要求先保存为个人资产。

关联镜头的文件名包含镜头号和素材名称，例如“001_产品特写.mp4”；无镜头归属的独立素材使用素材名称，不虚构镜头号。同名文件追加类型或版本等区分信息，不覆盖已有文件。具体命名补零位数和特殊字符处理在实现中验证，保持镜头顺序可识别。

### 9.2 按选定镜头批量下载

用户选择一个或多个分镜行，查看所连接下游节点的素材及版本后下载；一行连接多个节点时明确选择本次下载的结果。默认采用当前已选用的结果，不混入未采用候选。支持选择本次需要的图片、视频和关联音频，文件名包含镜头号和素材名称，便于在剪映中排序。

下载前检查文件可读性，列出素材缺失、生成中、失败或无采用版本的镜头。不得将这些项目显示为已下载；用户可补齐后重试，或明确选择仅下载可用素材。批量下载不提交模型生成，不修改节点或个人资产。

批量下载文件的打包形式、大小和数量限制待技术验证。后台准备结果可重新获取，不声称浏览器关闭后本地文件传输仍继续。

### 9.3 来源版本与返工

下载绑定发起时选定的版本。后续修改节点或采用新结果，不改变已下载文件；重复下载前展示当前选用版本。

上游剧情脚本、镜头内容、参考资产及提示词变化时，相关下游内容标记待检查或待更新；不自动覆盖手改内容、不删除旧结果、不自动提交生成。更换图生视频采用图片后，保留原视频并提示其来源已变化。

### 9.4 线下确认与反馈记录

剧情脚本及成片在线下确认，由员工在项目内记录结果和修改意见。平台不向客户提供登录、外部分享审核链接或审批流程，不代替线下确认。

记录包含确认对象的版本说明、确认结果、修改意见和记录时间；成片意见可关联具体镜头。结果区分待确认、需修改、已确认。脚本新版本不自动继承旧版本的确认结果，保留历史记录。

外部成片以名称或版本说明关联反馈；本期不承诺外部成片上传和预览。反馈不直接触发返工生成，由员工或 Agent 根据意见定位镜头并确认修改范围。

剪辑、拼接、字幕、配音配乐编排、成片输出和发布均由剪映等外部软件及公司现有流程完成。

## 10. 任务、异常与数据保留

### 10.1 后台任务

媒体生成和批量下载的准备工作在服务端执行。文本 PDF 和分镜 Excel 的导出状态单独反馈，不与媒体生成混为同一任务。

切换项目、关闭页面或退出登录，不自动取消任务。重新登录后可查看状态和结果。

界面区分等待、执行、成功、失败、申请停止和最终取消等状态，避免将申请停止误报为已经取消。

本期仅提供任务状态和结果，不建设调用用量统计页面。

### 10.2 停止与重试

员工可以申请停止生成，但不能保证供应商立即撤销。

- 未提交供应商的任务可以停止。
- 已提交任务等待供应商最终状态。
- 停止申请后仍成功返回时，保留结果并说明状态。
- 失败保留输入与已有结果。
- 重试由员工主动发起。
- 多结果任务部分失败时保留成功项，重试不自动重生成成功项。

平台不展示个人积分扣减、退还或充值交互。

### 10.3 回收站

项目与个人资产删除后进入回收站，保留 30 天。

期限内支持恢复；期限结束后清理对应对象。

删除个人资产不连带删除其他项目仍使用的媒体或提示词内容。共享引用尚未解除时，不删除底层所需文件。

## 12. 试用评价

邀请约 5～20 名有真实宣传需求的员工，覆盖：

- 产品与活动场景。
- 中文、英文创作及音频节点中英文配音。
- 横屏与竖屏。
- 已有素材与 AI 生成素材混用。

单次任务成功标准：

**员工无需设计人员代操作，独立完成并下载可供外部剪辑使用的镜头素材，表示愿意实际使用。**

试用记录：

- 是否独立完成，以及需要帮助的步骤。
- 素材能否用于外部剪辑、是否愿意继续使用及原因。
- 人工操作时间、生成等待时间。
- 重生成次数与失败情况。
- 产品外观、宣传信息、镜头连贯性、音频及画面问题。

不预设未经确认的成功率、耗时或质量达标数值。

## 13. 与原方案的关系

上传的《产品设计方案 V2.0》是设计参考，不表示功能已实现。

| 原方案或前次候选 | 最新约定 |
|---|---|
| 个人本地使用 | 公司内部员工使用，服务端保存 |
| 不包含账号 | 公司统一登录，个人内容隔离 |
| 员工配置 API Key | 管理员统一配置 |
| 结构化脚本与分镜 | 脚本节点完整展示表格，按行连接下游节点 |
| 脚本内批量媒体生成 | 本期移除，分镜按行连接独立媒体节点 |
| 按分镜创建成片 | 生成并下载镜头素材，交外部软件剪辑 |
| 个人积分及用量管理 | 本期移除，仅保留任务状态 |
| 平台内成片制作 | 本期移除，使用外部软件剪辑和输出 |
