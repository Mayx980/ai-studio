# 创作原型的共享交互

本设计对应 Issue #7 的原生 `apps/web` 预览例外，采用 wf-prod 的 Experience 设计职责及项目 AGENTS.md。保留原生画布和节点插件，不构建第二套原型，不代表生产集成完成。

## 输入、模式和历史

Enter 提交，Shift+Enter 换行，中文输入法选词不提交。首页将已提交的提示词、引用和模式一次性交给当前工作区；初始化完成后执行，不要求重新输入。模式选择位于右上角，发送后绑定当前会话。简单模式未指定类型时生成图片；明确的方案、剧情、分镜、图片、视频和音频意图使用对应模型。简单模式每条 AI 输出下方以图标提供引用与加入画布，悬浮显示功能名；媒体加入对应图片／视频／音频节点，普通文字加入文字节点，分镜表加入脚本节点。输入引用封面下方提供还原到输入框图标。

专业模式使用 `components/agent/professionalCreation.vue`，与简单模式分离。首次发送由已接入的文本模型分析具体情景，询问尚未明确的目的、时长、受众、主体、风格、比例等关键细节；用户可选择剧情、分镜、图片、音频或视频目标，并选择从想法、已有剧情或已有分镜开始。确认细节后由真实文本模型返回多个方案，用户可多选；需要剧情时再生成多个脚本，单选后创建文字节点。分镜使用脚本节点与十列表格。剧情与分镜均嵌入原节点的文档编辑视图，修改与画布即时同步、沿用现有保存与冲突保护；下一步先刷新读取真实节点正文，不能使用旧消息副本。参考图生成前询问，先提供角色／场景提示词供选择；视频生成再次询问，使用当前剧情、分镜与参考图，创建视频节点并连接前序节点。可在任一目标完成后停止，无需强制执行完整视频流程。失败保留选择与已创建节点，不使用示例方案替代真实响应。

细节问题由模型给出情景选项，用户勾选回答并可选择“由你推荐”；自由补充选填，已明确的细节不重复提问。参考图提示词及图片候选均可多选，逐项生成，部分失败保留成功候选。图片、视频先保留在浏览器对话记录中预览，点击应用后分别创建对应媒体节点并保存实际文件；应用不再调用生成 API，也不依赖此时仍有 Key。媒体结果 ID 绑定已创建节点，失败重试复用成功节点。进入下一阶段前须完成全部所选素材的节点保存，只使用已采用图片作为后续视频参考。

会话名称单击编辑；历史会话保存在浏览器项目中，生成媒体只在所属会话展示。创作输入区下方只显示创意案例。删除消息同时移除该消息的显示关联，不删除其它会话或已保存的画布素材。引用和删除并列，均有功能名、键盘焦点和禁用状态。

## 模型与引用

浏览器 API 配置是预览节点的唯一模型来源。未启用或没有 Key 的能力不列出；普通生成、全景、打光、多角度通过相同 NodeAi adapter 调用已接入模型。允许添加多款模型，填写类型、显示名称、供应商模型 ID、HTTPS 接口地址及 Key；Agent 与五类节点均从同一配置解析实际模型。新增配置目前限定为已接入适配器的协议族：OpenAI Chat Completions、百炼 DashScope 图像、万相异步视频、火山 Seed-Audio；不宣称支持任意第三方供应商。API 配置仅填入模型不会产生请求，供应商模型权限、协议及参数能力仍需实际调用验证。Key 及追加的模型配置仅页面内存，不能进入画布、会话或设置文件；错误应隐藏 Key，不模拟生成成功。音频使用本轮上传的 Seed-Audio 协议与参数映射，默认 WAV。供应商不支持的引用类型明确报错，保留素材与输入。

宿主画布显式注入同一 NodeAi adapter。节点收到宿主 adapter 后，该 adapter 独占模型列表和生成路由：禁用或未配置时返回空列表／明确报错，不能回退到服务端默认供应商。关闭 API 配置后先保存当前节点，再刷新四类生成组件；加载器按实际脚本字节复核缓存，避免继续复用旧版本 UMD。默认服务端模型只供没有注入 adapter 的原生宿主使用。

原型内置的文字、图片、视频、音频及媒体生成节点通过各包公开的 `component` 入口加载，与 Web 页面共同构建，不执行服务端遗留的同名 UMD 插件；拉取源码后无需手工替换已安装插件即可使用当前模型读取逻辑。其它插件继续通过原有远端加载入口执行，启用状态及节点配置仍沿用原有列表。内置组件加载失败直接显示节点加载错误，不降级加载旧 UMD。

Vite 从内置节点包的 `package.json` 读取公开 `component` 导出并建立精确别名，开发预览和构建使用同一解析规则；新增 workspace 链接尚未生成时也能打开已有项目，不依赖机器上的旧包安装状态。

所有文字、脚本、图片、音频和视频节点的共享提示词组件提供引用入口。本地与个人资产引用导入为真实上游节点；当前画布资产直接连接已有输出；其他项目资产先读取内容并复制到当前浏览器工作区，不创建跨项目磁盘依赖。连接执行类型、重复和循环校验。上传不发起模型请求。节点菜单上传使用同一选择器。

图片全景补充 2:1 与 4:1 尺寸，按[百炼 Qwen 官方协议](https://www.alibabacloud.com/help/en/model-studio/qwen-image-generation-and-editing-api-reference)校验总像素与长宽比；明确比例不会因自动尺寸选项被忽略。

## 分镜表

表格末列为“提示词”，按场景、角色、道具分别编辑。三项作为独立字段随分镜保存、导入、行输出及 Excel 导出，旧镜头没有这些字段时留空，保持原行 identity 与引用连接。脚本节点、简单模式及专业模式复用同一表头和生成要求，所有提示词使用中文。排序、复制、删除操作置于镜头号单元格，末端仍保留行输出连接。

脚本仍为文字节点的内容变体。默认以可滚动表格展示十个业务字段和角色形象描述补充列，复用文本保存及字符串输出。行有稳定 UUID，移动、修改镜头号不会改变引用身份；复制行创建新 UUID。每行作为独立字符串输出可连接兼容下游。删除行需确认连接影响，保留下游节点与素材。重新生成整表前确认并备份已有内容。Excel 导出与画布使用同一行数据，输出实际 `.xlsx` 文件，保留空字段，不包含画布连接，不调用模型。

按 Issue #4 notes 120474、121079、121455、122108 的脚本要求补齐：画布脚本节点宽 3400px，展示全部镜头行，短字段窄列、长字段宽列、单元格保持接近统一高度，长内容在单元格内滚动；点击非控件区可全屏编辑同一表格。每行首端接受图片引用，末端可连接一个或多个兼容下游。图片连到整表后选择适用镜头，可多选；引用列展示可预览、移除的真实图片。下游接收该行完整文字与关联图片，排序和改号不改变行端口 ID；图片版本变化进入行内容的更新提醒。移除行引用只断开依赖，不删除原图或下游已有结果。Excel 追加角色描述及引用图片路径列，不导出画布连线。默认端口被自定义行端口替代时不保留同 ID 的隐藏 DOM，避免连线命中错误。

## 保存与画布工具

左侧气泡默认关闭，移除独立展开／收起按钮。“显示层级”和“个人资产”点击展开对应内容，再次点击同一入口收起，点击另一入口切换内容。引用素材弹窗的本地上传使用独立“选择文件”按钮触发隐藏文件输入，不显示浏览器原生“未选择任何文件”文案。

项目、素材、会话使用已有 `useWorkspaceFiles` 浏览器事务实现，刷新恢复，保留同名及版本保护。局部设置与标签保存在同源浏览器；清除站点数据会删除这些内容，Key 刷新清空。原目录不写入。

画布底部集中撤销、重做、整理、连线可见性、适应视图、添加节点和快捷键说明，操作继续调用原生历史及布局能力。项目重命名与展开、显示层级、个人资产合并为左上角工具栏，下方展开气泡内容。层级按文字／脚本／图片／视频／音频分类，提供真实封面或文本摘要、音频预览及节点定位。脚本节点使用独立影片图标。右侧 Agent 悬浮气泡复用当前项目已开启的同一对话实例；刷新或重新打开项目时沿用最近对话，不创建第二份对话数据。首页删除右上角重复设置按钮，保留侧栏设置入口。删除地图与吸附图标，操作名称不被裁切。

## 验证边界

按项目规则使用已有类型检查、构建及浏览器人工操作，不新增测试模块。实际供应商成功生成需要有效 Key；构建通过、失效 Key 的鉴权响应或示意素材导入均不能代替该验证。

脚本导入支持 TXT、Markdown、CSV、单工作表 XLSX 与 DOCX，单文件 8MB、解压内容 32MB、镜头导入最多 1000 行。原文件先保存在当前节点目录；解析预览、列映射确认后才应用，取消或失败不改原表。公式、多工作表、PDF/OCR 和角色图片多模态识别不冒充支持。角色形象描述融合至末列角色提示词，兼容读取旧角色详情内容；编辑后统一保存为角色提示词。层级与个人资产位于左侧可折叠栏，项目操作移至右上角，地图和吸附图标移除。每条 Agent 输出均可引用，文字转换为文本附件。

## 创作与管理细节

专业模式仅提问当前语境中最重要且尚未确认的问题，最多五题，每题包括“由你推荐”在内最多五个选项。用户已经给出的内容不重复询问。模式切换吸附于输入框外部上方，用户点击编辑器或开始输入后隐藏。模型参数面板不按时间或鼠标移出自动关闭，点击外部才关闭。

浏览器 Agent 未实现服务端技能执行，隐藏技能按钮及斜杠菜单，不将技能名称当成真实执行结果。五类节点共用输入框内部左上角的引用封面区域，回形针位于输入框内部下方，继续复用真实引用连接与预览、移除能力。

首页历史对话支持按对话名或项目搜索，并逐项重命名、确认删除。删除对话不删除已保存到画布的媒体。首页板块写入路由，进入工作区携带来源，退出恢复创作、历史对话、个人资产或我的项目板块；原地弹窗关闭保留所在板块。

“用户真实测评口播”“达人种草好物”使用用户提供的 AI 示例图作风格参考，提示词明确居家光线、机位、操作细节、口播结构及中文字幕。产品资料和真实体验由用户提供，不编造背书、功效或价格。

万相本地中转必须逐字保留 `X-DashScope-OssResourceResolve`。旧白名单误加连字符，导致该请求头被丢弃，OSS 临时地址未经解析即进入视频任务。现已按[百炼临时文件文档](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)修正；保留本机同源、HTTPS、供应商域名及方法限制，不将 OSS 地址强改为不可访问的公开地址。真实视频成功仍需有效 Key 验证。

## 按厂商管理 API 配置

API 设置参考原生 Toonflow 的供应商卡片、厂商选择和模型编辑结构。供应商统一管理 Key、HTTPS 基础地址及多项模型，支持添加、编辑、删除与主动获取模型列表，未列出时手工填写厂商模型 ID。保存前校验 Key、地址所属厂商、类型和重复模型；取消编辑不改已保存配置。旧配置按实际厂商地址归组，编辑时保留模型 identity，Key 仍仅页面内存。

阿里云百炼保留文字、图片、视频的既有协议；火山保留 Seed-Audio。DeepSeek、硅基流动、Kimi、智谱及 OpenAI 仅接入 Chat Completions 文字模型，不据供应商支持其它协议就宣称全部能力可用。列表由厂商实际返回，不以静态示例代替账号模型权限；智谱当前使用手动模型 ID。接口参考[DeepSeek 文档](https://api-docs.deepseek.com/)、[百炼文档](https://help.aliyun.com/zh/model-studio/)、[硅基流动文档](https://docs.siliconflow.cn/)。

本轮经人工确认只额外联动文字调用地址拼接及本地中转白名单：百炼根地址补兼容路径，其他厂商保留所填 API 基础路径；百炼专属参数不发给其它厂商。本机中转仅追加明确的厂商域名，继续限制本机同源、HTTPS 与请求方法，不开放任意代理。实际生成及模型权限仍需有效 Key 验证。

## 千问图片任务与参数气泡

Qwen 3.0／2.1 图像模型按[厂商异步协议](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)向 `image-generation/generation` 提交一次任务，设置 `X-DashScope-Async: enable`，随后通过同一基础地址的 `tasks/<task_id>` 查询状态。成功后仍解析原有 choices 图片结果并走原有保存链路，不改变提示词、参考图或参数。其它不支持异步的旧模型保留同步路由。

此改动避免长同步出图请求超过本机中转等待时间。只轮询查询，不自动重提生成；等待、查询或任务失败时保留任务编号，提示先核对厂商记录，防止重复消费。失败响应保留 HTTP 状态、厂商消息和请求编号；中转连接失败返回结构化错误，不泄露 Key，也不将未知失败映射成成功。

参数气泡使用显式可见状态，仅外部点击关闭。内部下拉留在气泡 DOM 内，选择参数、失焦、Esc、鼠标移出及点击内侧留白不关闭面板。面板和触发入口均属于外部点击的排除区域。

## 项目归档、生成参数与个人模板中心

本轮沿用 `issue-design/7` 的浏览器原型。用户已确认：项目文件夹继续保存在当前浏览器；个人模板跨项目可用；图片默认选择同一比例的小档尺寸与 9:16，视频默认 480p。

开始对话前可选择已有项目文件夹，或新建并命名浏览器项目。没有选择时，发送先打开项目选择弹窗；确认项目后才进入对话。对话、画布以及加入画布的生成素材沿用该项目目录，取消不发送。工作区继续使用已绑定项目，不在有未保存画布时切换目录。

图片数量为 1–6，默认 1。图片尺寸与视频清晰度分别保存，避免把 480P／720P 当作图片尺寸提交。图片比例与尺寸为：1:1 的 1024*1024；2:3 的 768*1152、1024*1536；3:2 的 1152*768、1536*1024；9:16 的 720*1280、1080*1920；16:9 的 1280*720、1920*1080。切换比例时采用该比例小档，已有合法尺寸保留。视频清晰度为 480P、720P、1080P，默认 480P。画布图片节点提交数量与尺寸，所有返回图片保存到节点素材目录，可通过历史记录选择。

模型仍只读取 API 配置中已启用且有 Key 的对应类型。简单模式依据输入意图或显式选择的图片／视频产物筛选，专业模式参数入口默认展示文字模型并允许切换参数类型；明确标明尚未接入的模型类型，不使用旧模型列表填充。简单模式新增可滚动风格选择，所选风格追加到实际媒体生成提示词；选择图片或视频后，该选择决定简单模式产物。

模板中心使用用户上传的六段真实视频，不再让不同案例共用一个示意视频；按后续确认移除图片模板和原图片素材。上传模板保存在浏览器独立 `personalTemplates` 工作区，跨项目显示；支持视频预览、名称、分类、提示词与可选的模型／比例／清晰度信息。模板列表采用版本校验保存，保存失败保留表单，避免覆盖其它页面的修改。清除浏览器站点数据会删除个人模板与项目，API Key 继续只存在页面内存。

模板详情适应视口，左侧媒体完整展示，右侧提示词及参数可滚动，底部仅保留“一键同款”，右上角关闭。窄屏上下排列。“一键同款”只填入提示词、参考图与明确提供的元数据，不自动生成。视频模板没有独立参考图时，从该真实视频读取参考帧；读取失败不替换草稿。有对应已配置模型时匹配模型，没有匹配时保留当前模型；未提供参数时沿用当前设置或默认值，不推断素材的生成模型。输入中的产品名称、核心卖点以深灰可编辑字段呈现。

等待时间优化仅针对本地额外延迟：视频首次查询由固定等待 15 秒改为立即查询，之后图片／视频任务间隔 5 秒查询；同一结果文件的并发读取或下载共用同一个进行中的请求。没有自动重新提交生成任务，不声称可消除厂商排队、渲染与网络传输时间。真实厂商成功生成和耗时仍需有效 Key 验证。

## 图片风格约束与专业对话留存

简单模式仅在选择图片产物时展示风格入口；切换视频隐藏入口，所选图片风格不传入视频或专业创作。每个风格对应独立的中文生成约束，除风格名称外明确线条、材质、色彩、光影或造型要求。例如卡通要求简化轮廓、适度夸张比例、明快色块与简洁阴影，避免真人摄影与写实皮肤，同时保留用户指定的主体和产品特征。“不指定风格”不追加约束。

专业模式在同一对话消息中持续展示已经给出的全部设计方案、剧情脚本、分镜脚本和设计提示词，不再随工作阶段切换而隐藏正文。正文使用 Markdown 展示，分镜表格可滚动阅读。每次产出按独立标识加入历史，后续生成不会覆盖之前的方案。剧情候选可在卡片内编辑自动保存；分镜仅保留当前同一份节点表格及会话快照，不再展示重复确认版本。旧对话已有的方案和脚本直接兼容展示，缺少快照的画布文档可从原节点恢复当前版本，读取失败明确报错，不编造缺失内容。

图片、视频和音频沿用真实生成结果文件及会话记录保存，所有结果（包括未采用的候选）在后续阶段与重新打开的对话中仍可预览；当前候选阶段继续提供选择控件。历史正文随现有会话保存队列写入浏览器项目，恢复不会自动重新调用生成接口。

## 视频模板卡片与右侧对话栏

本轮用户澄清为“仅保留视频模板素材，所有视频都保留，不保留图片素材内容”，不是只留下一个视频。中心展示全部六个原视频和个人视频模板，不再展示图片模板或提供图片模板上传；旧个人图片模板数据不做破坏性删除。卡片支持鼠标悬浮静音播放、移出暂停与键盘焦点预览，每张卡片提供“一键同款”、提示词摘要与参数。再次应用模板直接完整替换提示词和引用素材，不叠加旧模板，不弹出替换确认。图片参考来自对应真实视频的画面。

已逐个检查视频画面，并按本轮截图对应：`productShowcase` 为重庆溜达节落地签；`productShowcaseTwo` 为300ml补水喷雾产品高光展示；`creatorRecommendation` 为达人开箱逛买；`shortDramaSales` 为香氛蜡烛甜宠短剧；`personReview` 为冷萃咖啡口播；`authenticReview` 为维C精华对镜口播。提示词按截图提取，英文开箱文案保留原文，产品名称和核心卖点字段支持直接编辑。六个源视频均实际为720×1280，因此卡片采用9:16、720p；时长按实际视频约10秒／15秒同步到生成滑块；截图没有生成模型信息，不编造模型，沿用当前已接入模型。

简单模式未选择产物时展示“图片｜视频”；选中后变为可关闭的“图像生成／视频生成”标签，隐藏另一入口，关闭标签恢复选择。风格仅在明确选择图片时显示。视频时长改为3–30秒滑块，标注3、5、10、15、20、25、30，默认保留模型原先5秒推荐值，不声称支持截图中未接入的10张关键帧能力。图片参数下拉按反馈展示480p、720p、1080p并显示实际提交尺寸，默认保留此前720×1280对应720p。480p方形受现有图片适配器最小像素约束使用512×512，其余按比例换算；视频清晰度独立保存。视频比例补齐1:1、2:3、3:2、9:16、16:9，提交的比例仍由实际厂商型号验证。参数面板限制于视口、必要时内部滚动，只点击外部才关闭。

最近项目卡片显示最近打开时间及首个生成的图片／视频封面，视频显示实际画面帧。新生成时通过只允许首次创建的项目封面记录保留首个素材，后续生成不覆盖；旧项目优先读已保存生成结果，缺少记录时沿用首个画布可读媒体，无媒体时显示文件夹。项目选择改为可滚动下拉单选，悬浮及选中项高亮；“新建创作”直接打开命名新建文件夹界面，保存后回到空白创作输入。

画布上的同一对话实例固定在右侧，可调宽和关闭，删除悬浮拖动及悬浮／停靠切换入口；进入画布与导入素材后保留侧栏。画布宽度及工具位置避开侧栏，对话侧栏不展示模板中心。专业提问仍最多5个；多个设计方案、剧情／分镜脚本和图片提示词按横向“方案1／2／3”Tab卡片展示，默认第一项，点击或键盘切换后显示对应完整正文，历史内容与采用方案操作继续保留。

## 卡片内编辑与单份分镜表格

专业模式不再展示“本次创作目标”“从哪一步开始”这两组固定问题，由助手结合提示词和已有文字参考判断目标、起点和用户已经提供的正文。最多询问5个真正缺失的关键事项；没有待确认问题时直接生成方案。方案卡片右下角提供“应用”。剧情脚本的各个方案可直接编辑全文，输入时通过现有会话保存队列即时自动保存，切换方案不丢修改。应用使用当前编辑后的正文创建文本节点，随后直接生成分镜，不再另设“修改剧情脚本”的步骤；生成中失败可以在已创建文本节点基础上继续，不重复创建该节点。

分镜仅保留同一份可编辑节点表格，标题统一为“分镜脚本”，不再额外展示“画布版本／确认版本”正文副本。旧记录兼容恢复，重复版本收敛为当前分镜快照，其余历史候选内容仍保留。对话中的分镜文档视图隐藏通用顶部资产／下载工具栏、底部提示词和生成配置，以及表格外的导入／导出工具；画布中的正常节点工具不受影响。表格可放大全屏编辑，放大和缩小移动同一个节点视图，不创建第二份分镜数据。采用较宽的长文本列、接近统一的单元格高度，长内容在单元格内滚动，保留内容与行身份。完成表格编辑后询问是否生成图片设计提示词，不再次生成分镜表格。

专业模式消息移除通用“加入画布”入口，由各业务步骤的“应用”创建相应节点；简单模式继续保留该功能。生成图片可点击或键盘打开大图查看，视频可点击打开大尺寸播放。参数气泡删除默认值及首尾帧说明两段文案。风格按钮固定显示“风格”，已选项高亮，再次点击该项取消选择；简单模式帮助文案改为“输入提示词，或者加入参考图，即可生成对应的图片或内容”。视频模板上传分类改为产品展示、达人种草、短剧带货、真实测评的单选下拉。

项目网格卡片缩至约原面积三分之一；列表卡片约240×138，缩短宽高并使用紧凑横排。保留封面、名称和最近打开时间，历史对话行同步收紧。项目操作使用删除图标与“删除”悬浮文案，编辑入口悬浮显示“编辑”；删除仍沿用原来的从项目列表移除，不扩大为删除工作区文件。

## 确认分镜后同步显示画布节点

专业模式点击“确认分镜并同步到画布”时，先读取并保存当前编辑内容，再结束对话内的节点文档挂载，将同一脚本节点界面归还画布，选中并定位到节点，展示完整分镜表格及其生成输入框，随后进入图片设计提示词确认环节。复用已有节点与工作区文件，不重复创建脚本节点或重新调用分镜生成。定位失败时保留编辑内容并返回分镜确认状态。

确认后的对话保留分镜内容预览，不再持续占用画布节点的界面。重新放大修改时暂时使用同一节点编辑器，关闭后归还画布并更新对话预览；重新打开已确认的历史对话也不会把画布节点移动成占位状态。节点输入框的正常显示仍由画布节点选中状态控制。

## 简单模式历史保存

简单模式的用户消息、助手文字回复、生成结果引用及错误信息统一保存到项目内的浏览器会话记录，沿用首页及工作区的历史对话入口，重新打开恢复原消息、素材与简单模式。首次调用模型前先保存消息，结束后保存回复或错误；保存失败保留输入并明确提示。删除当前对话后继续发送时，即使新对话尚无文件标识，也会通过同一保存队列创建并绑定新会话，避免静默跳过保存或重复创建记录。Key 不进入历史文件，删除的旧对话不会因后台回复被自动重建。
