# 创作原型的共享交互

本设计对应 Issue #7 的原生 `apps/web` 预览例外，采用 wf-prod 的 Experience 设计职责及项目 AGENTS.md。保留原生画布和节点插件，不构建第二套原型，不代表生产集成完成。

## 输入、模式和历史

Enter 提交，Shift+Enter 换行，中文输入法选词不提交。首页将已提交的提示词、引用和模式一次性交给当前工作区；初始化完成后执行，不要求重新输入。模式选择位于右上角，发送后绑定当前会话。简单模式未指定类型时生成图片；明确的方案、剧情、分镜、图片、视频和音频意图使用对应模型。简单模式每条 AI 输出下方以图标提供引用与加入画布，悬浮显示功能名；媒体加入对应图片／视频／音频节点，普通文字加入文字节点，分镜表加入脚本节点。输入引用封面下方提供还原到输入框图标。

专业模式使用 `components/agent/professionalCreation.vue`，与简单模式分离。首次发送由已接入的文本模型分析具体情景，询问尚未明确的目的、时长、受众、主体、风格、比例等关键细节；用户可选择剧情、分镜、图片、音频或视频目标，并选择从想法、已有剧情或已有分镜开始。确认细节后由真实文本模型返回多个方案，用户可多选；需要剧情时再生成多个脚本，单选后创建文字节点。分镜使用脚本节点与十列表格。剧情与分镜均嵌入原节点的文档编辑视图，修改与画布即时同步、沿用现有保存与冲突保护；下一步先刷新读取真实节点正文，不能使用旧消息副本。参考图生成前询问，先提供角色／场景提示词供选择；视频生成再次询问，使用当前剧情、分镜与参考图，创建视频节点并连接前序节点。可在任一目标完成后停止，无需强制执行完整视频流程。失败保留选择与已创建节点，不使用示例方案替代真实响应。

细节问题由模型给出情景选项，用户勾选回答并可选择“由你推荐”；自由补充选填，已明确的细节不重复提问。参考图提示词及图片候选均可多选，逐项生成，部分失败保留成功候选。图片、视频先保留在浏览器对话记录中预览，点击应用后分别创建对应媒体节点并保存实际文件；应用不再调用生成 API，也不依赖此时仍有 Key。媒体结果 ID 绑定已创建节点，失败重试复用成功节点。进入下一阶段前须完成全部所选素材的节点保存，只使用已采用图片作为后续视频参考。

会话名称单击编辑；历史会话保存在浏览器项目中，生成媒体只在所属会话展示。创作输入区下方只显示创意案例。删除消息同时移除该消息的显示关联，不删除其它会话或已保存的画布素材。引用和删除并列，均有功能名、键盘焦点和禁用状态。

## 模型与引用

浏览器 API 配置是预览节点的唯一模型来源。未启用或没有 Key 的能力不列出；普通生成、全景、打光、多角度通过相同 NodeAi adapter 调用已接入模型。允许添加多款模型，填写类型、显示名称、供应商模型 ID、HTTPS 接口地址及 Key；Agent 与五类节点均从同一配置解析实际模型。新增配置目前限定为已接入适配器的协议族：OpenAI Chat Completions、百炼 DashScope 图像、万相异步视频、火山 Seed-Audio；不宣称支持任意第三方供应商。API 配置仅填入模型不会产生请求，供应商模型权限、协议及参数能力仍需实际调用验证。Key 及追加的模型配置仅页面内存，不能进入画布、会话或设置文件；错误应隐藏 Key，不模拟生成成功。音频使用本轮上传的 Seed-Audio 协议与参数映射，默认 WAV。供应商不支持的引用类型明确报错，保留素材与输入。

宿主画布显式注入同一 NodeAi adapter。节点收到宿主 adapter 后，该 adapter 独占模型列表和生成路由：禁用或未配置时返回空列表／明确报错，不能回退到服务端默认供应商。关闭 API 配置后先保存当前节点，再刷新四类生成组件；加载器按实际脚本字节复核缓存，避免继续复用旧版本 UMD。默认服务端模型只供没有注入 adapter 的原生宿主使用。

原型内置的文字、图片、视频、音频及媒体生成节点通过各包公开的 `component` 入口加载，与 Web 页面共同构建，不执行服务端遗留的同名 UMD 插件；拉取源码后无需手工替换已安装插件即可使用当前模型读取逻辑。其它插件继续通过原有远端加载入口执行，启用状态及节点配置仍沿用原有列表。内置组件加载失败直接显示节点加载错误，不降级加载旧 UMD。

Vite 从内置节点包的 `package.json` 读取公开 `component` 导出并建立精确别名，开发预览和构建使用同一解析规则；新增 workspace 链接尚未生成时也能打开已有项目，不依赖机器上的旧包安装状态。

所有文字、脚本、图片、音频和视频节点的共享提示词组件提供引用入口。本地与个人资产引用导入为真实上游节点；当前画布资产直接连接已有输出；其他项目资产先读取内容并复制到当前浏览器工作区，不创建跨项目磁盘依赖。连接执行类型、重复和循环校验。上传不发起模型请求。节点菜单上传使用同一选择器。

图片全景补充 2:1 与 4:1 尺寸，按[百炼 Qwen 官方协议](https://www.alibabacloud.com/help/en/model-studio/qwen-image-generation-and-editing-api-reference)校验总像素与长宽比；明确比例不会因自动尺寸选项被忽略。

## 分镜表

表格末列为“提示词”，按场景、角色、道具分别编辑。三项作为独立字段随分镜保存、导入、行输出及 Excel 导出，旧镜头没有这些字段时留空，保持原行 identity 与引用连接。脚本节点、简单模式及专业模式复用同一表头和生成要求，所有提示词使用中文。排序、复制、删除操作置于镜头号单元格，末端仍保留行输出连接。

脚本仍为文字节点的内容变体。默认以可滚动表格展示十个业务字段和角色形象描述补充列，复用文本保存及字符串输出。行有稳定 UUID，移动、修改镜头号不会改变引用身份；复制行创建新 UUID。每行作为独立字符串输出可连接兼容下游。删除行需确认连接影响，保留下游节点与素材。重新生成整表前确认并备份已有内容。Excel 导出与画布使用同一行数据，输出实际 `.xlsx` 文件，保留空字段，不包含画布连接，不调用模型。

按 Issue #4 notes 120474、121079、121455、122108 的脚本要求补齐：画布脚本节点宽 3400px，展示全部镜头行，短字段窄列、长字段宽列、单元格保持接近统一高度，长内容在单元格内滚动；点击非控件区可全屏编辑同一表格。每行首端接受图片引用，末端可连接一个或多个兼容下游。图片连到整表后选择适用镜头，可多选；引用列展示可预览、移除的真实图片。下游接收该行完整文字与关联图片，排序和改号不改变行端口 ID；图片版本变化进入行内容的更新提醒。移除行引用只断开依赖，不删除原图或下游已有结果。Excel 追加角色描述及引用图片路径列，不导出画布连线。默认端口被自定义行端口替代时不保留同 ID 的隐藏 DOM，避免连线命中错误。

## 保存与画布工具

左侧气泡默认关闭，移除独立展开／收起按钮。“显示层级”和“个人资产”点击展开对应内容，再次点击同一入口收起，点击另一入口切换内容。引用素材弹窗的本地上传使用独立“选择文件”按钮触发隐藏文件输入，不显示浏览器原生“未选择任何文件”文案。

项目、素材、会话使用已有 `useWorkspaceFiles` 浏览器事务实现，刷新恢复，保留同名及版本保护。局部设置与标签保存在同源浏览器；清除站点数据会删除这些内容，Key 刷新清空。原目录不写入。

画布底部集中撤销、重做、整理、连线可见性、适应视图、添加节点和快捷键说明，操作继续调用原生历史及布局能力。项目重命名与展开、显示层级、个人资产合并为左上角工具栏，下方展开气泡内容。层级按文字／脚本／图片／视频／音频分类，提供真实封面或文本摘要、音频预览及节点定位。脚本节点使用独立影片图标。右侧 Agent 悬浮气泡复用当前项目已开启的同一对话实例；刷新或重新打开项目时沿用最近对话，不创建第二份对话数据。首页删除右上角重复设置按钮，保留侧栏设置入口。删除地图与吸附图标，操作名称不被裁切。

## 验证边界

按项目规则使用已有类型检查、构建及浏览器人工操作，不新增测试模块。实际供应商成功生成需要有效 Key；构建通过、失效 Key 的鉴权响应或示意素材导入均不能代替该验证。

脚本导入支持 TXT、Markdown、CSV、单工作表 XLSX 与 DOCX，单文件 8MB、解压内容 32MB、镜头导入最多 1000 行。原文件先保存在当前节点目录；解析预览、列映射确认后才应用，取消或失败不改原表。公式、多工作表、PDF/OCR 和角色图片多模态识别不冒充支持。角色形象描述融合至末列角色提示词，兼容读取旧角色详情内容；编辑后统一保存为角色提示词。层级与个人资产位于左侧可折叠栏，项目操作移至右上角，地图和吸附图标移除。每条 Agent 输出均可引用，文字转换为文本附件。

## 创作与管理细节

专业模式仅提问当前语境中最重要且尚未确认的问题，最多五题，每题包括“由你推荐”在内最多五个选项。用户已经给出的内容不重复询问。模式切换吸附于输入框外部上方，用户点击编辑器或开始输入后隐藏。模型参数面板不按时间或鼠标移出自动关闭，点击外部才关闭。

浏览器 Agent 未实现服务端技能执行，隐藏技能按钮及斜杠菜单，不将技能名称当成真实执行结果。五类节点共用输入框内部左上角的引用封面区域，回形针位于输入框内部下方，继续复用真实引用连接与预览、移除能力。

主导航和画布左侧 Logo 均返回创作页；来源编辑内嵌画布通过宿主返回完整创作页。跳转前完成当前画布保存。新建专业画布在首次保存节点前不加入“我的项目”，离开时不保留空白项目；保存节点后登记项目，后续离开仍保留节点。

首页历史对话支持按对话名或项目搜索，并逐项重命名、确认删除。删除对话不删除已保存到画布的媒体。首页板块写入路由，进入工作区携带来源，退出恢复创作、历史对话、个人资产或我的项目板块；原地弹窗关闭保留所在板块。

“用户真实测评口播”“达人种草好物”使用用户提供的 AI 示例图作风格参考，提示词明确居家光线、机位、操作细节、口播结构及中文字幕。产品资料和真实体验由用户提供，不编造背书、功效或价格。

万相本地中转必须逐字保留 `X-DashScope-OssResourceResolve`。旧白名单误加连字符，导致该请求头被丢弃，OSS 临时地址未经解析即进入视频任务。现已按[百炼临时文件文档](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)修正；保留本机同源、HTTPS、供应商域名及方法限制，不将 OSS 地址强改为不可访问的公开地址。真实视频成功仍需有效 Key 验证。

## 按厂商管理 API 配置

API 设置参考原生 Toonflow 的供应商卡片、厂商选择和模型编辑结构。供应商统一管理 Key、HTTPS 基础地址及多项模型，支持添加、编辑、删除与主动获取模型列表，未列出时手工填写厂商模型 ID。保存前校验 Key、地址所属厂商、类型和重复模型；取消编辑不改已保存配置。旧配置按实际厂商地址归组，编辑时保留模型 identity，Key 仍仅页面内存。

阿里云百炼保留文字、图片、视频的既有协议；火山保留 Seed-Audio。DeepSeek、硅基流动、Kimi、智谱及 OpenAI 仅接入 Chat Completions 文字模型，不据供应商支持其它协议就宣称全部能力可用。列表由厂商实际返回，不以静态示例代替账号模型权限；智谱当前使用手动模型 ID。接口参考[DeepSeek 文档](https://api-docs.deepseek.com/)、[百炼文档](https://help.aliyun.com/zh/model-studio/)、[硅基流动文档](https://docs.siliconflow.cn/)。

本轮经人工确认只额外联动文字调用地址拼接及本地中转白名单：百炼根地址补兼容路径，其他厂商保留所填 API 基础路径；百炼专属参数不发给其它厂商。本机中转仅追加明确的厂商域名，继续限制本机同源、HTTPS 与请求方法，不开放任意代理。实际生成及模型权限仍需有效 Key 验证。

## 千问图片任务与参数气泡

Qwen 3.0／2.1 图像模型按[厂商异步协议](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)向 `image-generation/generation` 提交一次任务，设置 `X-DashScope-Async: enable`，随后通过同一基础地址的 `tasks/<task_id>` 查询状态。成功后仍解析原有 choices 图片结果并走原有保存链路，不改变提示词、参考图或参数。其它不支持异步的旧模型保留同步路由。

此改动避免长同步出图请求超过本机中转等待时间。只轮询查询，不自动重提生成；等待、查询或任务失败时保留任务编号，提示先核对厂商记录，防止重复消费。失败响应保留 HTTP 状态、厂商消息和请求编号；中转连接失败返回结构化错误，不泄露 Key，也不将未知失败映射成成功。

参数气泡使用显式可见状态，仅外部点击关闭。内部下拉留在气泡 DOM 内，选择参数、失焦、Esc、鼠标移出及点击内侧留白不关闭面板。面板和触发入口均属于外部点击的排除区域。

## 项目归档、生成参数与个人模板中心

本轮沿用 `issue-design/7` 的浏览器原型。用户已确认：项目文件夹继续保存在当前浏览器；个人模板跨项目可用；图片默认选择同一比例的小档尺寸与 9:16，视频默认 480p。

开始对话前可选择已有项目文件夹，或新建并命名浏览器项目。没有选择时，发送先打开项目选择弹窗；确认项目后才进入对话。对话、画布以及加入画布的生成素材沿用该项目目录，取消不发送。工作区继续使用已绑定项目，不在有未保存画布时切换目录。

图片数量为 1–6，默认 1。图片尺寸与视频清晰度分别保存，避免把 480P／720P 当作图片尺寸提交。图片比例与尺寸为：1:1 的 1024*1024；2:3 的 768*1152、1024*1536；3:2 的 1152*768、1536*1024；9:16 的 720*1280、1080*1920；16:9 的 1280*720、1920*1080。切换比例时采用该比例小档，已有合法尺寸保留。视频清晰度为 480P、720P、1080P，默认 480P。画布图片节点提交数量与尺寸，所有返回图片保存到节点素材目录，可通过历史记录选择。

模型仍只读取 API 配置中已启用且有 Key 的对应类型。简单模式依据输入意图或显式选择的图片／视频产物筛选，专业模式参数入口默认展示文字模型并允许切换参数类型；明确标明尚未接入的模型类型，不使用旧模型列表填充。简单模式新增可滚动风格选择，所选风格追加到实际媒体生成提示词；选择图片或视频后，该选择决定简单模式产物。

模板中心使用用户上传的六段真实视频，不再让不同案例共用一个示意视频；按后续确认移除图片模板和原图片素材。上传模板保存在浏览器独立 `personalTemplates` 工作区，跨项目显示；支持视频预览、名称、分类、提示词与可选的模型／比例／清晰度信息。模板列表采用版本校验保存，保存失败保留表单，避免覆盖其它页面的修改。清除浏览器站点数据会删除个人模板与项目，API Key 继续只存在页面内存。

模板详情适应视口，左侧媒体完整展示，右侧提示词及参数可滚动，底部仅保留“一键同款”，右上角关闭。窄屏上下排列。“一键同款”只填入提示词、参考图与明确提供的元数据，不自动生成。视频模板没有独立参考图时，从该真实视频读取参考帧；读取失败不替换草稿。有对应已配置模型时匹配模型，没有匹配时保留当前模型；未提供参数时沿用当前设置或默认值，不推断素材的生成模型。输入中的产品名称、核心卖点以深灰可编辑字段呈现。

等待时间优化仅针对本地额外延迟：视频首次查询由固定等待 15 秒改为立即查询，之后图片／视频任务间隔 5 秒查询；同一结果文件的并发读取或下载共用同一个进行中的请求。没有自动重新提交生成任务，不声称可消除厂商排队、渲染与网络传输时间。真实厂商成功生成和耗时仍需有效 Key 验证。

## 图片风格约束与专业对话留存

简单模式仅在选择图片产物时展示风格入口；切换视频隐藏入口，所选图片风格不传入视频或专业创作。每个风格对应独立的中文生成约束，除风格名称外明确线条、材质、色彩、光影或造型要求。例如卡通要求简化轮廓、适度夸张比例、明快色块与简洁阴影，避免真人摄影与写实皮肤，同时保留用户指定的主体和产品特征。“不指定风格”不追加约束。

专业模式在同一对话消息中持续展示已经给出的全部设计方案、剧情脚本、分镜脚本和设计提示词，不再随工作阶段切换而隐藏正文。正文使用 Markdown 展示，分镜表格可滚动阅读。每次产出按独立标识加入历史，后续生成不会覆盖之前的方案。剧情候选可在卡片内编辑自动保存；分镜仅保留当前同一份节点表格及会话快照，不再展示重复确认版本。旧对话已有的方案和脚本直接兼容展示，缺少快照的画布文档可从原节点恢复当前版本，读取失败明确报错，不编造缺失内容。

图片、视频和音频沿用真实生成结果文件及会话记录保存，所有结果（包括未采用的候选）在后续阶段与重新打开的对话中仍可预览；当前候选阶段继续提供选择控件。历史正文随现有会话保存队列写入浏览器项目，恢复不会自动重新调用生成接口。

## 视频模板卡片与右侧对话栏

本轮用户澄清为“仅保留视频模板素材，所有视频都保留，不保留图片素材内容”，不是只留下一个视频。中心展示全部六个原视频和个人视频模板，不再展示图片模板或提供图片模板上传；旧个人图片模板数据不做破坏性删除。卡片支持鼠标悬浮静音播放、移出暂停与键盘焦点预览，卡片仅保留视频预览和名称；提示词、参数和“一键同款”移入简单模式详情。再次应用模板直接完整替换提示词和引用素材，不叠加旧模板，不弹出替换确认。图片参考来自对应真实视频的画面。

已逐个检查视频画面，并按本轮截图对应：`productShowcase` 为重庆溜达节落地签；`productShowcaseTwo` 为300ml补水喷雾产品高光展示；`creatorRecommendation` 为达人开箱逛买；`shortDramaSales` 为香氛蜡烛甜宠短剧；`personReview` 为冷萃咖啡口播；`authenticReview` 为维C精华对镜口播。提示词按截图提取，英文开箱文案保留原文，产品名称和核心卖点字段支持直接编辑。六个源视频均实际为720×1280，因此详情元数据采用9:16、720p；时长按实际视频约10秒／15秒同步到生成滑块；截图没有生成模型信息，不编造模型，沿用当前已接入模型。

## 卡片内编辑与单份分镜表格

专业模式不再展示“本次创作目标”“从哪一步开始”这两组固定问题，由助手结合提示词和已有文字参考判断目标、起点和用户已经提供的正文。最多询问5个真正缺失的关键事项；没有待确认问题时直接生成方案。方案卡片右下角提供“应用”。剧情脚本的各个方案可直接编辑全文，输入时通过现有会话保存队列即时自动保存，切换方案不丢修改。应用使用当前编辑后的正文创建文本节点，随后直接生成分镜，不再另设“修改剧情脚本”的步骤；生成中失败可以在已创建文本节点基础上继续，不重复创建该节点。

分镜仅保留同一份可编辑节点表格，标题统一为“分镜脚本”，不再额外展示“画布版本／确认版本”正文副本。旧记录兼容恢复，重复版本收敛为当前分镜快照，其余历史候选内容仍保留。对话中的分镜文档视图隐藏通用顶部资产／下载工具栏、底部提示词和生成配置，以及表格外的导入／导出工具；画布中的正常节点工具不受影响。表格可放大全屏编辑，放大和缩小移动同一个节点视图，不创建第二份分镜数据。采用较宽的长文本列、接近统一的单元格高度，长内容在单元格内滚动，保留内容与行身份。完成表格编辑后询问是否生成图片设计提示词，不再次生成分镜表格。

专业模式消息移除通用“加入画布”入口，由各业务步骤的“应用”创建相应节点；简单模式继续保留该功能。生成图片可点击或键盘打开大图查看，视频可点击打开大尺寸播放。参数气泡删除默认值及首尾帧说明两段文案。风格按钮固定显示“风格”，已选项高亮，再次点击该项取消选择；简单模式帮助文案改为“输入提示词，或者加入参考图，即可生成对应的图片或内容”。视频模板上传分类改为产品展示、达人种草、短剧带货、真实测评的单选下拉。

项目网格卡片缩至约原面积三分之一；列表卡片约240×138，缩短宽高并使用紧凑横排。保留封面、名称和最近打开时间，历史对话行同步收紧。项目操作使用删除图标与“删除”悬浮文案，编辑入口悬浮显示“编辑”；删除仍沿用原来的从项目列表移除，不扩大为删除工作区文件。

## 确认分镜后同步显示画布节点

专业模式点击“确认分镜并同步到画布”时，先读取并保存当前编辑内容，再结束对话内的节点文档挂载，将同一脚本节点界面归还画布，选中并定位到节点，展示完整分镜表格及其生成输入框，随后进入图片设计提示词确认环节。复用已有节点与工作区文件，不重复创建脚本节点或重新调用分镜生成。定位失败时保留编辑内容并返回分镜确认状态。

确认后的对话保留分镜内容预览，不再持续占用画布节点的界面。重新放大修改时暂时使用同一节点编辑器，关闭后归还画布并更新对话预览；重新打开已确认的历史对话也不会把画布节点移动成占位状态。节点输入框的正常显示仍由画布节点选中状态控制。

## 简单模式历史保存

简单模式的用户消息、助手文字回复、生成结果引用及错误信息统一保存到项目内的浏览器会话记录，沿用首页及工作区的历史对话入口，重新打开恢复原消息、素材与简单模式。首次调用模型前先保存消息，结束后保存回复或错误；保存失败保留输入并明确提示。删除当前对话后继续发送时，即使新对话尚无文件标识，也会通过同一保存队列创建并绑定新会话，避免静默跳过保存或重复创建记录。Key 不进入历史文件，删除的旧对话不会因后台回复被自动重建。

“进入画布”使用文字按钮的自适应宽度，图标按钮的固定28px宽度不应用于该入口。Agent顶部工具栏在窄屏下允许自动换行，各按钮保持完整可见，长对话标题仍按剩余空间省略。


## 模板中心：语义检索与项目流程模板

本节为 Issue #7 当前确认的模板中心设计，替代前文卡片信息密度的旧描述，沿用原生 apps/web 预览例外与当前浏览器存储，不新增生产服务或第二套页面。布局和交互继续采用 wf-prod Experience 规范及项目 AGENTS.md；项目快照属于本轮浏览器联调原型，不代表生产服务端事务或跨设备模板服务已经完成。

### 浏览与搜索

`components/creativeCases.vue` 是唯一模板中心，复用 `templateMedia.vue`。卡片仅显示真实视频与名称，整卡为一个可键盘激活的按钮；当前卡片悬浮添加灰色蒙层，移出恢复，蒙层不接收指针。保留静音悬浮播放、移出暂停及减少动态效果偏好。桌面按至少150px卡宽自动分列、6px间距，窄屏保持双列，提示词、模型及参数不再占卡片空间。

搜索框在桌面位于分类标签同一行右侧，窄屏换行，输入关键词或自然语言后按回车／搜索按钮提交。候选取当前模式与当前分类交集，将查询及候选名称、分类、描述交给已配置的文字模型进行真实语义评估，按照0–100相关度降序排列，仅展示至少60分的明确相关项，同分保持原顺序。模型只能返回候选ID与分数，返回数据必须完整、唯一且分数合法；无效输出为失败，不回退到字符串匹配。当前按一次请求评估完整候选集合，适用于现有少量个人模板；较大规模的分批召回、embedding索引及reranker服务留给后续正式设计，不承诺无限模板规模。

复用 `generateBrowserText` 与现有文字模型配置，用户提交搜索或在搜索条件下切换分类才请求。Key只在浏览器内存，不持久化；查询和模板描述会发送给选定供应商，不发送视频、项目文件或素材。无文字模型时提示去API配置启用并填写Key。搜索期间明确显示进度，取消过期请求并忽略晚到响应；编辑查询隐藏旧结果等待重新提交，清空立即恢复当前分类全部模板。无结果、读取失败、模型请求失败分别显示，不以默认列表冒充搜索成功，失败可显式重试。

### 两种详情

简单模式沿用已有弹窗，保留完整视频、提示词、参数和“一键同款”。六个现有视频模板全部保留，未提供的生成模型不编造。项目模板也可在简单模式浏览，描述可供“一键同款”填入，生成参数缺失时沿用当前配置。

专业模式只展示带项目快照的模板，旧视频模板没有画布时不出现在专业列表。详情采用接近全屏的大弹窗，使用 `templateProjectPreview.vue` 与已有 Vue Flow 展示实际保存的多画布拓扑。允许切换画布、平移、缩放、适应视图、点击查看节点正文和已保存参数。节点以不带执行能力的只读摘要展示，不挂载远端插件、生成器、编辑器、写文件注入或画布快捷键；禁用拖拽、连线、删除及节点执行。节点间原始端口信息仍保存在快照与信息内容中，预览连接到只读摘要节点；不是可执行的原生插件画布。唯一业务操作为“复制项目”，关闭与视图导航属于浏览操作。

### 制作与独立复制

“我的项目”每张卡片提供“制作模板”操作，复用现有模板上传表单。默认采用项目名称，用户确认名称、分类、模板描述并选择真实MP4预览视频；保存到当前浏览器的个人模板中心，跨项目可用。仅支持当前浏览器项目，不触碰本机目录。空项目、损坏画布、素材缺失或文件操作失败明确报错并保留表单。

`lib/projectTemplates.ts` 通过现有 `useWorkspaceFiles` 和 `readCanvasFiles` 读取并校验项目，制作时保存所有项目文件（包含全部画布、节点配置、正文、素材及保留的历史素材），排除 `.agent` 对话、缓存与项目封面记录。内存API配置不在项目文件中，已知凭据字段不得进入快照。为避免复制后仍依赖源项目，对JSON内文件引用采用保守边界：必须是随快照保存的项目相对文件／目录；外部URL、其他项目路径、未导入素材引用均拒绝制作，要求先导入。项目级非JSON文档保留原字节，正文中的普通文字和网址不按媒体依赖解释；任意第三方插件的隐式外部依赖仍需正式承接时单独核实，不宣称全插件依赖识别。

读取后再次核对目录清单和文件摘要，项目发生变化则停止保存。快照存入 `personalTemplates/assets/<templateId>/project/`，模板索引中的项目元数据保存相对文件清单、SHA-256及画布路径。预览视频、项目快照均写完后，使用现有模板索引版本校验发布；失败只清理本次创建的目录，不覆盖已有模板。源项目后续修改不会改变模板快照。

复制先校验模板全部文件摘要和引用，再创建新的 `browser://<uuid>` 项目目录，保留节点ID、连线ID、相对路径及配置，不共享源目录。不同项目目录隔离节点及素材，副本无须回写或引用模板目录。所有文件独立写入后逐项回读摘要，再校验完整画布清单；全部成功才登记项目、以“模板名称 副本”命名并打开可编辑工作区。复制不调用生成模型，不要求已有模型Key。文件失败则清理本次文件，项目不加入列表；清理失败也明确披露，不报复制成功。完整副本已保存但导航失败时报告打开失败，保留完整项目供用户从项目列表重新打开。

### 验证与正式承接边界

本轮使用现有typecheck、构建和浏览器交互验证，不新增测试模块或模拟模型结果。浏览器持久化不等于云端保存，清除当前站点数据会删除项目和个人模板。语义相关性需配置有效文字模型进行真实查询后验证；未取得真实调用证据时只报告界面及错误状态验证，不宣称排序效果验收通过。正式服务端权限、跨端存储、任意插件依赖解析和大规模语义索引不在本轮原型实现中。


## 简单模式的首尾帧、分类参考图与素材分屏

本节对应 Issue #7 当前简单模式原型要求，替代此前取消常驻首尾帧框的适用部分；专业模式保持现有输入与工作流程。首页和 Agent 对话输入框左上角复用同一个 `simpleReferenceSlots.vue`，首帧／尾帧为摆正的小型加号卡片，参考图为三张折叠卡片。入口使用当前主题颜色，上传后在首尾帧位置展示实际图片，可预览、移除或再次选择来源；参考图入口显示已有数量。

历史卡片支持悬浮或键盘聚焦显示保存到个人资产、下载和删除。左上角复选框仅在悬浮、键盘聚焦或已选中时显示；勾选后出现批量工具栏：去画布编辑向当前项目添加素材节点，无当前项目时创建项目；新建画布添加创建独立未命名项目后添加全部素材。添加复用画布已有文件导入和自动保存，不调用模型，不触发新手样例。保存到个人资产先打开统一保存弹窗，填写名称、选择实际文件夹和多个标签后保存独立副本，同名冲突保留输入且不覆盖；下载复用平台保存入口，多文件逐项发起下载，浏览器是否允许批量下载由浏览器控制。失败报告已完成数量，不声称全部成功。

删除需要确认，只持久化隐藏历史记录，不删除画布或对话仍引用的素材文件；刷新后继续隐藏。资产库中的副本不受删除历史影响。该原型仍使用本地账号与浏览器存储，不代表生产鉴权、云端资产服务或真实供应商生成已经验收。


## AFXEN 标识、视频音频参数与个人资产库

品牌采用本轮提供的紫蓝渐变 A／播放图形及 AFXEN 字样，按参考重绘为透明 SVG；完整组合用于展开导航和助手，紧凑图形用于折叠导航，浏览器图标同步更新。无白色或黑色图片底板，随页面背景自然融合。

视频 Agent 参数增加“生成音频”的开启／关闭选择，初始开启。简单模式提交时读取当前选择快照，传入已有视频适配器的 generateAudio 字段；其协议原本支持映射到 parameters.audio，对应画布节点配置同步保存该值。切换开关不自动生成；实际音轨仍取决于供应商与所选模型，不以界面验证代替真实生成验收。

个人资产库使用独立的整页浏览视图，继续复用原有浏览器资产目录、标签 Store 和统一文件入口，不改变画布内的紧凑资产面板。初始化实际创建场景、物品、风格、音效、角色目录；已有文件夹保持不变，不填充模拟素材。右上角搜索 icon 展开搜索当前目录及其子目录的资产，新建菜单提供上传资产和新建文件夹；目录卡片点击进入，顶部路径可逐级返回。

图片、视频和音频卡片打开大预览及右侧详情，显示资产名、资产创建时间、来源和已记录的模型、提示词。新上传标记本地上传，新保存的生成历史副本带模型与生成信息；旧资产缺失的信息显示未记录，不推断不存在的来源或提示词。画布保存的已知来源显示画布素材。素材元信息与标签在浏览器持久化，移动／原有重命名／删除同步维护路径映射。

详情提供新建画布添加、删除和下载；悬浮或键盘聚焦卡片显示右上角勾选框，勾选后底部工具栏支持新建画布添加、移动到、修改标签、下载、删除。新建画布复用已有批量文件导入与保存，不调用模型；移动保留标签和元信息，同名冲突不覆盖；修改标签将所选资产统一设为当前勾选标签。上传只接收图片、视频和音频，同名文件拒绝覆盖；删除需确认，取消保留素材。下载使用原平台保存入口。各操作绑定开始时的目标目录，不因浏览路径变化而跨目录写入。

此轮仍为同一浏览器原型设计分支，未新增生产账号、云端资产接口或新的付费模型调用。真实上传素材可用于人工验证文件夹、搜索、详情、批量操作与画布导入；供应商实际生成音轨需配置可用模型后验证。


## 黑色背景、画布左侧栏与节点提示词

本轮按用户提供色样统一黑色背景为 #090909，Agent 输入框使用比背景更浅的近黑色 #1b1b1b；保留深浅主题选择，深色面板与输入内容保持可读。首页移除原装饰背景，助手原有上方中央渐变保留，其余为新黑色。首页侧栏隐藏横向溢出及可见滚动条，窄屏仍可滚动访问导航。

专业模式初始进入、从简单模式切换或点击进入画布后，Agent 默认关闭，保留画布底部原有手动开启按钮；返回简单模式时正常显示完整助手。画布不再显示用户中心和浏览器保存文字。项目名称、返回对话／退出项目／设置图标、当前画布、显示层级／个人资产组成300px左侧栏，层级默认展开；原按钮继续经过原有保存、退出确认和设置流程，不新增退出账号入口。首页和完整助手侧栏的用户中心保留。

参数面板删除标注的模型解释段落并隐藏可见滚动条，小屏仍允许必要滚动，不删除模型、比例、清晰度、音频和时长参数。首帧／参考图／尾帧区域整体向右增加12px间距。

节点提示词继续复用共享编辑器，移除内层包裹边框和底色，只保留外层圆角卡片；引用缩略图、@引用、展开编辑、模型选择、参数与生成入口不变。图片、视频、音频生成节点均增加优化提示词图标，复用当前已选择的文字模型；仅用户点击时请求模型，不自动生成图片、视频或音频。结果先在可编辑弹窗中核对，用户确认后才替换原文。未接入模型或请求失败明确报错并保留原提示词。

优化应用前核对原文和引用集合未变化，并检查全部 {{ref n}} 标记完整保留；期间编辑过原提示词或变更引用时拒绝覆盖，提示重新优化。取消或卸载中止在途请求，关闭弹窗不写入提示词。共享业务位于 nodeShared，三类插件仅声明对应类型，宿主复用现有文字生成协议，不增加独立供应商或优化服务。当前无可用文字模型Key时，只验证入口、失败保留与编辑界面，不宣称真实模型优化质量已经验证。

## 节点输入与资产归档统一规则

项目封面使用居中裁切（object-fit: cover、object-position: center）；无图片或视频时显示深灰圆角图片占位。图片／视频个人资产必须位于文件夹内：保存、上传、移动与复制共用同一校验入口。旧根目录图片／视频首次读取时移入“未分类”，同名冲突保留两份，标签和来源按真实新路径同步；已有画布与对话中的项目素材副本不移动。没有文件夹时建立“未分类”作为默认归档位置；音频仍可放根目录。

文字／脚本／图片／视频／音频节点共用输入框工具布局。左下角是模型与紧邻的参数，右下角按上传、引用、优化提示词（仅图片／视频／音频）、生成排列，图标提供功能名提示。文字和脚本的参数为内容详略与表达风格，作为实际创作要求传入模型；媒体参数沿用已接入模型的实际比例、时长、清晰度等能力。脚本上传复用现有文档／表格解析，其他上传作为本地参考素材导入，保留原有类型校验与连线规则。

引用入口提供个人资产库、当前画布资产、其他项目资产与自定义素材。自定义素材复用原有独立对话、真实模型和应用流程；从节点打开时，当前画布与新对话各占半屏，窄屏上下分屏，画布可继续移动、编辑。参考图、首帧、尾帧打开的对话默认并限定为图片素材生成，不调用视频模型，取消或失败不伪造应用成功。素材应用仍复核原项目和画布绑定。

脚本表格常态完整放在画布，不裁切其节点正文；表格右上角提供独立全屏放大入口。点击表格边框只选中脚本节点并展开其输入框，原单元格编辑与行引用保持。五类节点输入框右上角使用斜向放大图标，放大时继续编辑同一输入模型。

全局深色背景使用 #090909，Agent 输入框为 #1b1b1b，节点输入卡片沿用更浅的面板色。用户中心去除灰底填充，资产模块去除侧边长灰条；资产悬浮操作和批量工具栏图标显示功能名。项目搜索框靠右排列。

### 简单模式参考素材与连线交互

简单模式输入框增加“参考图／首尾帧”Tab，素材入口位于输入框左上角，切换Tab位于输入框底部，图片按上传顺序从左到右展示。参考图加号先选角色、道具或背景，再选本地、个人资产库或自定义素材，复用现有文件校验、独立图片生成和应用链路。标签位于图片底部三分之一灰底区域，各分类独立递增编号；背景沿用 scene 字段，既有场景名称显示为背景。末图带继续添加加号，悬浮或键盘聚焦提供替换、移除及后缀大加号。替换保留编号与顺序；首尾帧提供两个独立上传入口。两组素材在切换时保留，发送只包含当前组，非素材附件照常保留。

创作类型采用图片／视频Tab；素材子对话保持图片类型限定。隐藏创作对话的上下文圆圈和独立@按钮，键盘输入@仍可引用。折叠导航不常驻显示折叠图标，键盘聚焦仍可展开。空画布五类快捷节点纵向排列；双击打开添加节点菜单时清理浏览器文字选区，菜单文字不可选中。

五类节点生成按钮使用蓝色背景与白色箭头，禁用状态保持可辨识。通用节点容器增加16pt的无形悬浮范围，按画布缩放换算距离；靠近时显现现有连接端口的加号，沿用类型、循环与连接校验。悬浮连线时显示流动虚线，离开即恢复；减少动态效果偏好下关闭流动动画。


### 简单模式进入画布：还原当前轮次

简单模式回复下的“进入画布”与引用、删除图标同行。使用对应助手回复的 replyTo 找到本轮用户消息及参考图片／视频，不取其他轮次或当前未发送草稿。用户要求与实际发送给模型的提示词（含风格和参考说明）进入一个文字节点，参考图片／视频各自进入对应媒体节点，输入节点按实测高度加间隔排列成左侧一列，连接到右侧本轮图片／视频结果节点；多结果共享输入。结果节点通过连线引用输入，不重复粘贴一份提示词。素材复用已有工作区导入和浏览器文件保存；等待媒体预览与节点尺寸就绪后布局，失败移除本次节点和文件副本，保留原对话素材。重复进入定位已创建的该轮节点，不覆盖后续编辑。

生成时记录非敏感参数快照：供应商和模型标识及名称、比例、图片尺寸和数量、风格、视频时长／分辨率／音频与参考模式。快照与结果在浏览器中持久化，恢复时按明确字段和类型校验；不存 API Key 或完整供应商配置。新结果节点还原该次快照，即使之后更改简单模式设置也不改写历史参数。旧结果没有快照时明确提示，沿用当前简单模式参数并尝试匹配已保存的模型名称。Key 因刷新被清除时保留模型名称和参数，重新配置后才能继续生成。

新建文字／脚本／图片／视频／音频节点默认使用简单模式对应模型和可用参数；图片清晰度采用480p／720p／1080p并按比例映射像素尺寸，视频时长和分辨率等选项与简单模式一致。首帧单图模式沿用真实首帧输入，不作为普通参考误传。进入当前轮画布时不自动插入首次教学样例。

首页新建画布、添加项目和节点快捷创作直接创建默认“未命名项目”，删除前置项目命名弹窗；名称仍可在项目头部及现有重命名入口修改。


### 本地视频、素材分类与项目入口

简单模式素材入口支持本地图片和视频（单文件非空且不超过100 MB），首帧与尾帧仍限定图片。分类增加“其他”，类别及来源气泡从加号右侧展开。末图悬浮时新增按钮移动到右侧，移开后延迟0.5秒收回，鼠标移到新增按钮时继续保持。首尾帧之间的省略号悬浮变为“添加中间帧”加号，支持多个中间参考素材。

直接粘贴或引用的图片／视频在参考图模式归为“其他”，在首尾帧模式归为“中间帧”；模板一键同款统一切到参考图模式并归为“其他”。已有上传素材在 @ 弹窗当前画布列表前展示，可以选择名称引用。真实生成分别传递图片和视频，保留首尾帧用途校验；当前图片模型不接受视频参考时明确提示，不静默丢弃。视频模型沿用现有图片、视频参考能力，中间帧属于参考素材而非供应商未声明支持的固定时刻帧。

参考类型、产物类型与模型参数采用线形按钮。图片默认480p并同步实际像素尺寸；发送后隐藏简单／专业模式开关。移除简单模式顶部操作组，历史对话仍从导航访问。空对话创作区域约占可用高度3/5，下方展示模板中心；隐藏外层和结果区域滚动条，保留滚动。模板可编辑字段使用浅灰底。折叠导航点击空白区域展开。

最近项目根据实际文件恢复：有节点时进入专业画布；无节点时读取最近会话的模式并恢复简单对话；无会话的新项目使用保存的创建模式。原有非浏览器项目沿用画布入口。

### 生成历史详情与创作优选

点击生成历史图片／视频打开左右布局的详情弹窗，左侧预览媒体，右侧显示已记录的创建时间、提示词、模型名称与生成参数。缺少历史参数的旧记录显示现存信息，不编造参数。底部提供新建画布添加、去画布编辑、保存到个人资产、下载和删除历史图标，每个图标可悬浮查看功能名，复用现有操作与文件入口。节点后续生成结果也保存当次非敏感参数，不保存 Key。

创作优选增加上传入口，选择本地浏览器中的实际项目并保存其画布、节点、连线与素材快照。平台项目无需另传视频，封面优先使用已有视频或图片，没有媒体时从实际节点布局和连线绘制；详情沿用可缩放的真实编排预览，复制项目沿用文件摘要校验和独立副本。提交仍进入现有审核流程，审核通过后公开展示。普通视频模板继续选择真实MP4，通过自有按钮隐藏原生“未选择任何文件”提示。


### 创作优选作品播放与过程预览

创作优选使用横向作品卡片，展示项目内的视频／图片封面和作品名。悬浮视频卡片自动静音播放，离开暂停；卡片右下角显示“查看创作过程”图标及功能名提示。点击卡片先放大播放完整作品，底部左侧为作品名，右侧为次要“查看创作过程”按钮；也可从卡片图标直接进入过程。

创作过程为全屏只读画布，删除左侧节点列表和画布选择下拉，按原坐标、分组与连线显示节点中的图片、视频和文字。支持平移、缩放和拖拽节点查看，拖拽位置仅在当前预览保留，不回写原项目。点击节点查看画布内的只读输入框、实际参数与上游引用，复用专业画布实际节点组件。只读宿主拒绝文件写入与模型调用，不接入原项目自动保存。右上角沿用“复制项目”，复制真实画布、文字和媒体文件；副本可在专业模式中继续编辑。新上传项目优先选项目内已有视频／图片作封面，没有媒体时仍使用编排缩略图。

创作优选不再展示内置“达人开箱逛买”编排示例，读取当前浏览器“我的项目”中名称包含“达人种草”的实际项目，显示其画布、节点、连线及真实视频／图片。缺少项目时不拿示例冒充；读取失败明确报错。卡片媒体完整适配，空白部分灰色填充。

参考图／首尾帧、图片生成／视频生成各使用一个线形组合按钮，中间以“｜”分隔选择。简单模式空对话输入区按内容保留完整高度，长内容由外层滚动。中间帧独立编号为“中间帧1”“中间帧2”等，粘贴、引用与菜单上传使用一致名称。生成历史详情只保留一处“生成模型”；图片与视频受媒体区域宽高约束并完整显示，不按原图高度撑大弹窗。


### 简单模式工具入口调整

按本轮界面要求，首尾帧选择按钮仅在图片生成模式显示；切换到视频生成时回到参考图展示，已上传的帧素材保留，切回图片模式后可再次查看。模型对首尾帧的实际能力校验保持原样。

简单模式参数气泡以整个输入框底边为定位基准，在输入框下方展开，不向上翻转覆盖输入内容；高度根据剩余空间限制，内容可滚动。风格入口统一为透明底、带描边的线形按钮。简单模式 @ 弹窗只显示“当前画布”，继续列出输入框已上传素材，移除“其他画布”和“全局素材”入口。

首帧、尾帧及中间帧卡片悬浮或键盘聚焦时显示替换图片图标；替换保留原用途、列表位置和中间帧编号，沿用现有本地、个人资产及自定义素材来源。


### 创作过程节点样式与全局气泡避让

创作过程复用专业画布的原生节点组件、节点骨架、端口与输入区域。点击节点在画布内显示输入框与真实引用，不使用 body 浮层或独立气泡。保留坐标、分组、连线和复制入口；拖拽、平移、缩放仅影响查看状态。禁用修改提示词、改名、替换、删除、生成、改线及分组缩放，文件接口只读取经过校验的项目快照并拒绝全部写入，模型能力关闭，文字节点只读加载不触发迁移保存。未安装的其它节点保留只读素材回退，不执行未知插件。

气泡恢复组件原有定位方式。撤销全局输入框／媒体避让、底部预留、工作区缩小、全屏聚光遮罩和全局气泡样式覆盖，不再统一判断是否遮挡输入框。

生成速度、成片整合、分组完善及管理员工作台仍为讨论分析，不新增未确认的生成参数、剪辑能力或管理权限。


### 气泡高亮、入口引导与对话归档修订

气泡按本轮修订恢复组件原有定位和样式，不使用全局遮罩或全局避让；首页各入口教学步骤保留。

### 画布生成后台继续与分屏素材应用

应用内离开或切换画布不自动取消浏览器模型生成。媒体节点的任务按项目目录、画布文件和节点ID区分，任务状态与取消操作在同一页面会话内共享，重新进入仍可查询运行状态并防止重复提交。生成结果与生成历史保存在原项目；原画布仍打开时刷新其输出并保存，否则等待退出前保存结束后只合并原节点输出。不存在的节点不重新创建，保存冲突重新读取后有界合并，不能覆盖无关节点或写入当前另一个项目。明确停止或删除节点继续取消任务。文本请求不再因视图销毁取消，沿用原正文文件的保存与冲突保护。

这一原型规则覆盖页面内导航，不增加服务端任务调度或浏览器关闭／刷新后的恢复承诺。

分屏自定义素材的助手结果消息操作栏新增“应用”图标，复用该结果原有的应用入口与视频首／尾帧提取。回填沿用打开分屏时捕获的目标和替换对象，因此角色、道具、背景、其他及帧用途保持一致。已有按单个结果应用的按钮保留，多结果仍可逐个选择。


### 三节点画布的完整弹窗教学

创建节点步骤高亮底部添加节点按钮，提示词与生成步骤定位对应节点的输入框、模型选择及提交按钮；连接步骤展示整张画布并高亮对应图片的输出端口，说明拖至视频输入点。已有连线明确提示无需重复连接；已有图片明确标注示例素材，不冒充本次生成。弹窗可前后切换、跳过、关闭，保留灰底与蓝紫高亮，不自动建立重复节点、修改提示词或提交模型生成。首页首次进入和底部重新打开教学均使用同一流程，单节点教程保持原逻辑。


### 教学项目刷新及恢复时的弹窗触发修复

确认原有18步教学内容已存在，缺口是刷新或直接恢复教学项目时没有临时入口指令，因此只加载画布而没有打开弹窗。教学项目在专业画布就绪后自动准备并展示完整教程，首页首次创建及底部引导流程仍共用同一入口。入口初始化与自动恢复互斥，避免单节点尚未创建就提前开启或重复打开。关闭／跳过后在当前页面不反复弹出；再次点击底部引导流程可从第一步重开。普通创作项目不因本修复自动展示教学，也不改动其节点、素材和提示词。

## 双端与账号管理补充

本轮恢复 `issue-design/7-r2@d316ce3` 的工程及创作 UIUX，仅复用 `issue/7@cbb4e1d` 的双端登录、用户组及账号管理界面。沿用 `apps/`、原有创作与模型调用、浏览器项目和个人资产，不迁移 frontend/services，不引入服务器账号或数据库实现。

在 `apps/web` 使用原有 Vite 开发入口，根地址继续为用户端；同一开发地址下的 `/user/` 和 `/platform/` 固定对应端。原有 `vite build` 仍生成 `build/web`；`vite build --mode platform` 生成独立平台端 `build/platform`。创作数据不自动迁移或重新归属，新账号 UI 不改变原有浏览器存储范围。
